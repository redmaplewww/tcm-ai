# 一、中医诊断学总览

## 1.1 中医诊断学的基本内容

中医诊断学是研究如何运用四诊方法收集病情资料、并进行辨证判断的学科，包含三大部分：

| 部分 | 内容 |
|------|------|
| 诊法（四诊） | 望诊、闻诊、问诊、切诊（合称"望闻问切"） |
| 辨证 | 八纲辨证、脏腑辨证、气血津液辨证、六经辨证、卫气营血辨证、三焦辨证、病因辨证、经络辨证 |
| 病案书写 | 记录四诊资料、辨证结论、治法方药 |

《难经》："望而知之谓之神，闻而知之谓之圣，问而知之谓之工，切而知之谓之巧。"

四诊简介表：

| 诊法 | 手段 | 核心观察对象 |
|------|------|--------------|
| 望诊 | 医生视觉观察 | 全身神色形态、局部表现、舌象、小儿指纹、排出物 |
| 闻诊 | 听声音 + 嗅气味 | 语声、呼吸、咳嗽、心音；口气、汗气、痰涕、二便气味 |
| 问诊 | 询问患者/家属 | 寒热、汗、头身、二便、饮食、胸腹、耳目、睡眠、情志、经带、旧病等 |
| 切诊 | 脉诊 + 按诊 | 寸口脉象；肌肤、手足、脘腹的寒热、润燥、痞满、压痛 |

## 1.2 诊断三大原则

### 1.2.1 整体审察
- 人是有机整体：局部病变可反映整体状态，内在脏腑病变可表现于外（"有诸内必形诸外"）。
- 人与外界环境统一：四时气候、地域、社会心理因素均影响疾病。
- 诊断时既要察局部，又要审整体；既要察病，又要审人所处的环境与情志状态。

### 1.2.2 四诊合参
- 四诊从不同角度收集资料，各有价值、不可互相替代。
- 望、闻、问、切任一诊的资料都不完整，临床必须四诊并用、综合分析。
- 舌脉与症状矛盾时（如"舍脉从症""舍症从脉"），须结合全部资料判断真假。
- AI问诊系统虽以问诊为主，仍应尽量采集用户可自述/上传的舌象照片、声音、面色信息，模拟四诊合参。

### 1.2.3 病证结合
- "病"指疾病全过程的规律性概括；"证"指疾病某一阶段的病位、病性概括。
- 诊断既要辨病（如感冒、消渴、不寐），更要辨证（如风寒束表证、心脾两虚证），病证结合才能全面指导治疗。

## 1.3 "看病"的完整流程（问诊AI流程设计参照）

```
挂号分科（自述主诉初步分诊）
    ↓
四诊收集资料（望神色形态舌象 → 闻声音气味 → 问十问 → 切脉按诊）
    ↓
辨证分析（八纲定性位 → 脏腑/气血/六经/卫气营血定位 → 确立证型）
    ↓
确立治则治法（如"疏肝解郁""滋阴降火"，遵循虚则补之、实则泻之、寒者热之、热者寒之）
    ↓
处方/施治（选择代表方剂加减，或针灸、推拿等；注意配伍禁忌与体质）
    ↓
医嘱（饮食宜忌、起居调摄、情志调节、服药方法）
    ↓
随访复诊 → 调方（效不更方/效亦更方、不效则重新辨证、中病即止）
```

辨证论治三要素（AI推理链核心）：
1. **辨证**：将四诊资料归纳为某证型（证据→证型的映射）。
2. **论治**：据证确立治法（证型→治法的映射）。
3. **处方**：据治法选方遣药（治法→方剂的映射）。

# 二、望诊

望诊居四诊之首，包括望神、望色、望形态、望头面五官颈项皮肤、望舌、望排出物、望小儿指纹。

## 2.1 望神

神是机体生命活动的外在表现，以目光、面色、表情、言语、反应为观察重点。

| 神的类型 | 表现 | 临床意义 |
|----------|------|----------|
| **得神（有神）** | 目光明亮灵活、面色荣润、表情自然、神志清楚、反应灵敏、呼吸平稳 | 正气未伤，病轻，预后良好 |
| **少神（神气不足）** | 倦怠乏力、精神不振、嗜睡懒言、目光呆滞、面色少华 | 正气不足，轻证或恢复期；多见于虚证、素体虚弱 |
| **失神（无神）** | 目光晦暗瞳神呆滞、面色晦暗暴露、精神萎靡、反应迟钝、甚则神昏谵语、循衣摸床、撮空理线 | 正气大伤，精气衰竭，病重，预后不良 |
| **假神（回光返照）** | 久病重病患者突然精神转佳、颧红如妆、突然能食、突然言语清亮 | 阴阳离决的先兆，濒危征象（**AI识别到此应建议立即就医**） |
| **神乱** | 焦虑恐惧、狂躁不安、淡漠痴呆、猝然昏仆（癫、狂、痫） | 精神情志类疾病 |

假神与重病好转的鉴别：好转是逐渐的、全身性的；假神是突然的、局部的、与整体病情不符的。

## 2.2 望色（望面色）

面色分为常色（红黄隐隐、明润含蓄）与病色。五色主病总表：

| 面色 | 主病 | 机制与表现 |
|------|------|-----------|
| **青色** | 寒证、痛证、瘀血、惊风 | 寒凝气滞、经脉瘀阻。青黑主寒痛；青灰晦暗主瘀血（心胸痛）；小儿眉间鼻柱唇周发青主惊风先兆 |
| **赤色** | 热证（实热/虚热） | 满面通红为实热（阳明热盛）；午后两颧潮红娇嫩为阴虚火旺（虚热） |
| **黄色** | 虚证、湿证 | 萎黄主脾胃气虚、气血不足；黄而鲜明如橘子色主湿热黄疸（阳黄）；黄而晦暗如烟熏主寒湿黄疸（阴黄） |
| **白色** | 虚证、寒证、失血 | 㿠白虚浮主阳虚；淡白无华主气血两虚；苍白主失血或阳气暴脱 |
| **黑色** | 肾虚、瘀血、水饮 | 面黑而暗淡主肾阳虚；黑而干焦主肾阴虚；黧黑（面色黧黑）主瘀血；眼眶黑主肾虚水饮或血瘀 |

## 2.3 望形态

| 项目 | 表现 | 意义 |
|------|------|------|
| 形体强壮 | 骨骼粗大、胸廓宽厚、肌肉充实、皮肤润泽 | 气血旺盛，抗病力强 |
| 形体虚弱 | 骨骼细小、胸廓狭窄、肌肉瘦削、皮肤枯槁 | 气血不足，抗病力弱 |
| 形胖 | 胖而能食为形气有余（多痰湿）；胖而食少为形盛气虚（多痰、多气虚、易中风） | "肥人多痰湿" |
| 形瘦 | 瘦而食多为中焦有火；瘦而食少为中气虚弱；大肉消瘦（恶病质）为精气衰竭 | "瘦人多火（阴虚）" |
| 动静姿态 | 喜动多阳证、热证、实证；喜静多阴证、寒证、虚证 | 阳主动，阴主静 |
| 特殊姿态 | 蹒跚步态（行走摇摆）主肾虚或中风后遗症；半身不遂主中风；四肢抽搐主肝风内动；循衣摸床、撮空理线为失神危象 | |

## 2.4 望头面五官颈项皮肤（提要）

| 部位 | 常见异常 | 意义 |
|------|----------|------|
| 头形/囟门 | 小儿囟门迟闭（解颅）主肾精不足；囟陷主津亏失水（虚）；囟填主实热（火毒上攻） | 肾、虚实证 |
| 头发 | 发黄稀疏易落主精血不足；突然片状脱发（斑秃）主血虚受风；青年白发主肾虚或血热 | 肾其华在发、发为血之余 |
| 目 | 目赤肿痛主实热（肝火上炎）；白睛黄染主黄疸；目眶凹陷主津液耗伤；瞳仁散大主肾精耗竭危候；眼睑淡白主血虚 | 肝开窍于目 |
| 口唇 | 唇色淡白主血虚；唇色深红主热；青紫主瘀血/寒凝；口角流涎主脾虚湿盛或中风 | 脾开窍于口其华在唇 |
| 齿龈 | 牙齿干燥主胃阴伤；龈肿出血主胃火；龈肉萎缩、齿根暴露主肾虚 | 齿为骨之余、龈为胃之络 |
| 鼻 | 鼻流清涕主风寒表证；流浊涕主风热或鼻渊（胆经郁热） | 肺开窍于鼻 |
| 咽喉 | 咽红肿痛主肺胃热盛；乳蛾（扁桃体肿大化脓）主肺胃热毒；咽部嫩红肿痛不显主阴虚火旺 | |
| 颈项 | 瘿瘤（颈前肿块）主肝郁气结痰凝；瘰疬（颈侧结核串珠）主肺肾阴虚痰火；颈脉怒张主心血瘀阻/水肿 | |
| 皮肤 | 斑（平铺于皮下、抚之不碍手、压之不褪色）多主热入营血或气不摄血；疹（高出皮面、抚之碍手、压之褪色）多主风热郁表；疮疡红肿热痛为阳证痈，漫肿无头皮色不变为阴证疽 | |

## 2.5 望排出物（提要）

排出物总规律：**清稀者多虚证、寒证；黄稠秽臭者多实证、热证。**

| 排出物 | 清稀（寒/虚） | 黄稠臭秽（热/实） |
|--------|----------------|---------------------|
| 痰 | 白痰清稀—寒痰/风寒犯肺；痰多色白易咯—痰湿阻肺 | 黄稠—热痰/痰热壅肺；痰中带血丝—燥热伤肺或阴虚火旺 |
| 涕 | 清涕—风寒 | 浊涕—风热；腥臭浊涕—鼻渊 |
| 呕吐物 | 清稀无臭—胃寒 | 黄稠酸臭—胃热；夹不消化食物—食滞 |
| 大便 | 溏薄—脾虚；清稀如水—寒湿泄泻；完谷不化—脾肾阳虚 | 黄褐臭秽—湿热泄泻；脓血便—湿热痢疾 |
| 小便 | 清长—寒证/肾阳虚 | 短赤—热证/湿热 |

## 2.6 望舌（舌诊）——AI问诊高频核心

### 2.6.1 舌诊基础

- 舌质（舌体）：反映脏腑虚实、气血盛衰——候五脏病变之"本体"。
- 舌苔：反映胃气盛衰、邪气性质与深浅——候六腑病变之"表"。
- 舌面分候脏腑（传统）：舌尖候心肺、舌中候脾胃、舌边候肝胆、舌根候肾。
- **正常舌象：淡红舌、薄白苔**（舌体柔软灵活，色淡红明润，苔薄白均匀，干湿适中，又称"桃花舌"），提示气血调和、胃气充足。
- 望舌顺序：先看舌质（色→形→态），再看舌苔（色→质），综合判断。进食、染苔（牛奶白苔、橘子黄苔）、刮舌后等会影响判断，AI应提示用户自然光线下拍摄。

### 2.6.2 望舌质——舌色

| 舌色 | 特征 | 临床意义 |
|------|------|----------|
| 淡白舌 | 较正常浅淡，甚至全无血色 | 主虚证、寒证。气血两虚（淡白无华）；阳虚寒湿（淡白湿润胖嫩）。多见于贫血、营养不良、慢性失血 |
| 淡红舌 | 淡红润泽 | 正常舌象；见于病人则病轻浅，气血未伤 |
| 红舌 | 较正常红，甚者鲜红 | 主热证。舌红苔黄—实热；舌红少苔或有裂纹—虚热（阴虚火旺）；舌尖红—心火亢盛；舌边红—肝胆火盛 |
| 绛舌 | 较红舌更深，深红色 | 主热入营血（温病营血分证）、阴虚火旺重症。外感病见绛舌为热入营血；久病绛舌少苔为阴虚火旺 |
| 紫舌 | 紫暗色，或现瘀点瘀斑 | 主瘀血、寒凝。紫暗湿润为寒凝血瘀（阳虚）；紫绛干枯为热盛血瘀（热灼血凝）；淡紫或青紫湿润—气虚气滞血瘀；舌有瘀点瘀斑—内有瘀血 |

### 2.6.3 望舌质——舌形

| 舌形 | 特征 | 临床意义 |
|------|------|----------|
| 老舌 | 舌质纹理粗糙、坚敛苍老 | 主实证 |
| 嫩舌 | 纹理细腻、浮胖娇嫩 | 主虚证 |
| 胖大舌 | 舌体宽大 | 主水湿内停、痰湿热毒。淡白胖嫩多属脾肾阳虚、痰湿内停；红胖大多属脾胃湿热、痰热；舌鲜红肿胀—心脾积热 |
| 齿痕舌 | 舌边有牙齿压痕，多与胖大并见 | 主脾虚湿盛。淡白湿润齿痕—阳虚水湿；淡红齿痕—脾气虚 |
| 瘦薄舌 | 舌体瘦小而薄 | 主气血两虚、阴虚火旺。瘦薄淡白—气血两虚；瘦薄红绛干燥—阴虚火旺、津液耗伤 |
| 裂纹舌 | 舌面有明显裂沟 | 主热盛伤阴、血虚不润、脾虚湿浸。红绛裂纹—热盛伤阴；淡白裂纹—血虚；健康人先天裂纹舌无症状不作病论 |
| 点刺舌 | 芒刺、红点突起 | 主脏腑热极或血分热盛。舌尖点刺—心火亢盛；舌边点刺—肝胆火盛 |

### 2.6.4 望舌质——舌态

| 舌态 | 特征 | 临床意义 |
|------|------|----------|
| 痿软舌 | 舌体软弱无力，伸卷不灵 | 主气血俱虚、阴液亏耗。久病淡白痿软—气血俱虚；红绛痿软—阴虚火旺 |
| 强硬舌 | 舌体板硬强直、运动不灵、语言謇涩 | 主热入心包、高热伤津、痰浊内阻、中风或中风先兆（**AI遇此应建议急诊**） |
| 歪斜舌 | 伸舌偏向一侧 | 主中风或中风先兆（**建议急诊**） |
| 颤动舌 | 舌体不自主颤抖 | 主肝风内动。久病淡白颤动—血虚生风；红绛颤动—热极生风；亦见于酒精中毒 |
| 吐弄舌 | 舌伸口外不即回（吐）、反复舔口唇（弄） | 多见于小儿，主心脾有热、热毒攻心；弄舌亦见于智力发育不全 |
| 短缩舌 | 舌体卷短紧缩，不能伸出 | 危重证候。寒凝筋脉、痰浊内阻、热盛伤津、气血俱虚均可致（**建议急诊**） |

### 2.6.5 望舌苔——苔色

| 苔色 | 特征 | 临床意义 |
|------|------|----------|
| 白苔 | 苔色白 | 主表证、寒证。薄白而润—正常或风寒表证；薄白而干—风热表证初起或津伤；白厚腻—湿浊、痰饮、食积；白厚腻干—湿浊化热；积粉苔（白如积粉）—外感秽浊湿邪与热毒相结（瘟疫/湿热秽浊） |
| 黄苔 | 苔色黄 | 主热证、里证。薄黄—风热表证或热邪入里之轻证；黄腻—湿热、痰热、食积化热；黄厚干燥—里热炽盛、伤津；焦黄燥裂—热极津枯 |
| 灰黑苔 | 苔灰黑 | 主里热或里寒的重证（病重）。灰黑干燥—热极伤阴（里热炽盛）；灰黑润滑—阳虚寒湿内盛（里寒）；注意染苔（橄榄、铁剂可使苔黑） |

### 2.6.6 望舌苔——苔质

| 苔质 | 特征 | 临床意义 |
|------|------|----------|
| 厚苔 | 透过舌苔不能见到舌体 | 主邪盛入里、内有痰湿食积。苔由薄变厚—病进；由厚变薄—病退 |
| 薄苔 | 透过舌苔隐约可见舌体 | 正常或病邪轻浅（表证初起） |
| 润苔 | 苔干湿适中 | 正常或津液未伤 |
| 滑苔 | 苔面水分过多、伸舌欲滴 | 主寒证、湿证、阳虚水泛（水湿内停） |
| 燥苔 | 苔面干燥、扪之无津 | 主津液已伤；高热、大汗、吐泻后多见。燥裂—热盛伤津重症 |
| 腻苔 | 苔质颗粒细腻致密、刮之难去 | 主湿浊、痰饮、食积。白腻—寒湿/痰湿；黄腻—湿热/痰热 |
| 腐苔 | 苔质颗粒疏松粗大、如豆腐渣、刮之易去 | 主食积胃肠、痰浊内蕴（胃气败伤，邪有余） |
| 剥落苔 | 舌苔部分或全部剥落 | 主胃气阴两伤、胃阴枯竭。花剥苔（地图舌）—气阴两伤/阴虚；镜面舌（全部剥落、光滑如镜）—胃阴干涸、胃气将绝（重证）；小儿花剥苔伴过敏体质 |
| 无苔 | 全舌无苔、光亮如镜（镜面舌） | 胃阴枯竭、胃气大伤，病重 |

### 2.6.7 舌象综合辨证速查表（舌质×舌苔组合）

| 舌象组合 | 证候判断 |
|----------|----------|
| 淡红舌薄白苔 | 正常或病轻 |
| 淡白舌薄白苔 | 气血不足兼表寒 |
| 淡白胖嫩齿痕苔白滑 | 脾肾阳虚、水湿内停 |
| 红舌薄黄苔 | 风热表证/里热初起 |
| 红舌黄厚腻苔 | 湿热内蕴（脾胃湿热、肝胆湿热） |
| 红绛舌少苔/无苔 | 阴虚火旺、热入营血 |
| 镜面舌 | 胃阴枯竭、气阴大伤 |
| 红舌起芒刺 | 脏腑热极（心火、肝胆火） |
| 青紫舌（或瘀点瘀斑）苔润 | 寒凝血瘀/气滞血瘀 |
| 紫绛舌苔黄燥 | 热盛血瘀、热入血分 |
| 白厚腻苔 | 寒湿、痰湿内阻 |
| 灰黑苔润滑 | 阳虚寒湿极盛 |
| 灰黑苔干燥起裂 | 热极伤阴、真阴耗竭 |

## 2.7 望小儿指纹

适用于3岁以内小儿，观察食指掌侧桡侧缘浅表络脉（指纹），分为三关：

| 关位 | 位置 | 指纹到达的意义 |
|------|------|----------------|
| 风关 | 食指第一节（近掌侧） | 邪浅病轻 |
| 气关 | 食指第二节 | 邪入经络，病重 |
| 命关 | 食指第三节 | 邪入脏腑，病危 |
| 透关射甲 | 指纹直达指尖 | 病危重 |

指纹辨证纲领：**浮沉分表里，红紫辨寒热，淡滞定虚实，三关测轻重。**
- 纹色鲜红—外感表寒；紫红—里热；青色—疼痛、惊风；淡白—脾虚、虚证；紫黑—血络郁闭（病重）。
- 指纹浮露—病在表；沉滞—病在里。

# 三、闻诊

闻诊包括听声音和嗅气味两方面。

## 3.1 听声音

| 项目 | 异常表现 | 临床意义 |
|------|----------|----------|
| 语声 | 语声高亢洪亮、多言躁动 | 实证、热证（阳证） |
| | 语声低微断续、少言沉静 | 虚证、寒证（阴证） |
| | 声音嘶哑（金破不鸣） | 新病—外感风寒/风热犯肺（金实不鸣）；久病—肺肾阴虚、津不上承 |
| 谵语 | 神识不清、语无伦次、声高有力 | 实热扰神（热扰心神），多见于温病热入营血、阳明腑实 |
| 郑声 | 神识不清、语言重复、声音低弱 | 心气大伤、精神散乱（虚），久病重病危候 |
| 独语/错语 | 自言自语、见人语止；语言错乱 | 心气不足、神失所养或癫证 |
| 呼吸 | 气粗声高息涌 | 实热证（痰热壅肺） |
| | 气微声低息短 | 虚寒证（肺肾气虚） |
| | 哮（喉中痰鸣如哨） | 痰饮伏肺，遇感引触（哮喘） |
| | 喘（呼吸困难、张口抬肩） | 实喘—风寒袭肺/痰热壅肺（气粗声高）；虚喘—肺肾气虚、肾不纳气（气怯声低、呼多吸少） |
| | 少气（气少不足以息） | 气虚 |
| 咳嗽 | 咳声重浊紧闷 | 寒痰湿浊停聚于肺 |
| | 咳声轻清低微 | 肺气虚 |
| | 咳声不扬、痰黄稠难咯 | 热证（肺热） |
| | 干咳无痰或痰少而黏 | 燥邪犯肺或肺阴虚 |
| | 咳有痰声、量多易咯 | 痰湿阻肺 |
| | 顿咳（百日咳：阵发性痉咳、终止有鸡鸣样回声） | 风邪与伏痰搏结（儿科传染病） |
| 呕吐 | 吐势徐缓、声音微弱、吐物清稀 | 虚寒（脾胃阳虚） |
| | 吐势较猛、声音壮厉、吐物黄稠酸臭 | 实热（胃热） |
| 嗳气 | 嗳气酸腐、兼脘腹胀满 | 食滞胃脘 |
| | 嗳气频作、随情志变化、无酸腐味 | 肝气犯胃（气郁） |
| | 嗳气低沉断续、无酸腐味 | 脾胃虚弱（虚寒） |
| 呃逆 | 呃声高亢、短促有力 | 实证、热证（胃火） |
| | 呃声低沉、气怯无力 | 虚证（脾肾阳虚）；久病呃逆不止为胃气衰败之危候 |
| 太息（叹息） | 善太息（长吁短叹后觉舒） | **肝气郁结**（AI问诊高频信号） |
| 肠鸣 | 肠鸣漉漉、脘腹辘辘有声 | 水饮留滞于胃肠（痰饮）；肠鸣音亢进伴泄泻—脾虚湿盛 |

## 3.2 嗅气味

总规律：**气味酸腐臭秽者多实热；气味微腥者多虚寒。**

| 气味来源 | 臭秽/腥臭（热/实） | 腻滞无臭（寒/虚） |
|----------|----------------------|---------------------|
| 口气 | 口气酸臭—食滞胃肠；口气臭秽—胃热；口气腐臭—内痈（牙疳/肺痈） | 口气无明显异味或微腥—虚寒 |
| 汗气 | 汗出腥膻—风湿热久蕴皮肤；腋下臊臭（狐臭）—湿热郁蒸 | 汗出不臭—虚证、阳虚自汗 |
| 痰涕 | 痰涕腥臭—肺痈（咳吐脓血腥臭痰）；鼻流浊涕腥臭—鼻渊 | 痰涕无臭清稀—寒证 |
| 二便 | 大便酸臭难闻—肠有积热（热泻）；小便黄赤臊臭—膀胱湿热 | 大便溏泻微腥—脾虚寒泻；小便清长无臭—虚寒 |
| 经带 | 带下黄稠臭秽—湿热下注（黄带） | 带下清稀无臭—脾肾阳虚（白带）；带下腥—寒湿 |

# 四、问诊（问诊AI最核心章节）

## 4.1 问诊总纲：十问歌

### 4.1.1 十问歌全文

**通行版（明代张景岳《景岳全书·传忠录》首创，清代陈修园《医学实在易》增补）：**

> 一问寒热二问汗，三问头身四问便，
> 五问饮食六胸腹，七聋八渴俱当辨，
> 九问旧病十问因，再兼服药参机变。
> 妇人尤必问经期，迟速闭崩皆可见，
> 再添片语告儿科，天花麻疹全占验。

（任务给定的AI问诊版末句为"妇人尤必问经期，小儿当问麻疹斑"，意义相同。）

### 4.1.2 十问歌逐句解释（AI问诊流程设计对照）

| 序 | 问项 | 问什么 | 判断目标 |
|----|------|--------|----------|
| 一 | 问寒热 | 怕冷？发热？同时出现还是单独？热势高低、时间规律 | 辨表里、寒热 |
| 二 | 问汗 | 有汗无汗？汗出时间（醒着/睡着）、部位、性质 | 辨表里虚实、阴阳盛衰、津液存亡 |
| 三 | 问头身 | 头痛头晕？身痛麻木？疼痛部位与性质 | 辨病位（经络脏腑）、气血状态 |
| 四 | 问便 | 大便次数、质地、颜色、排便感；小便量、次、颜色、排尿感 | 辨脏腑寒热虚实（脾胃、肾、膀胱） |
| 五 | 问饮食 | 食欲、食量、口味、口渴与饮水偏好 | 辨脾胃功能、津液盛衰、寒热 |
| 六 | 问胸腹 | 胸闷心悸？胁胀脘痞腹胀？疼痛拒按喜按 | 辨气机阻滞、病位在脏在腑 |
| 七 | 问耳（聋） | 耳鸣耳聋？突发渐发？ | 辨肝肾（胆） |
| 八 | 问渴 | 口渴否？喜冷饮热饮？渴饮程度 | 辨津液存亡、寒热真假 |
| 九 | 问旧病 | 既往病史、手术史、过敏史 | 了解体质与病机基础 |
| 十 | 问因 | 发病诱因（外感、饮食、情志、劳倦）、诊治经过 | 病因辨证、避免重复用药 |
| 附 | 问服药 | 已服何药、疗效、不良反应 | "参机变"——指导处方调整 |
| 附 | 问经带（女） | 月经周期、经期、量、色、质、痛经；带下色质量味 | 妇科辨证必问 |
| 附 | 问儿科 | 出生情况、喂养、生长发育、传染病接触史（麻疹水痘等） | 儿科特点 |

**AI问诊系统提示**：问诊应按"先主诉→现病史（十问展开）→既往史→个人史（情志、饮食起居）→经带史/儿科史"顺序，避免诱导性提问，覆盖十问全部要点后进入辨证。

## 4.2 问寒热

寒热产生的总病机："阳盛则热，阴盛则寒；阳虚则寒，阴虚则热。"问寒热可判断病邪性质（寒/热）与阴阳盛衰。

### 4.2.1 寒热四种基本类型

| 类型 | 表现 | 临床意义 |
|------|------|----------|
| **恶寒发热** | 自觉怕冷，加衣被或近火取暖不能缓解，同时体温升高 | **外感表证**（外邪袭表，卫阳被遏）。恶寒重发热轻—表寒证（风寒束表）；发热重恶寒轻—表热证（风热犯表）；发热轻而恶风、有汗—太阳中风（表虚） |
| **但寒不热** | 只怕冷而不发热 | **里寒证**。新病畏寒—寒邪直中脏腑（实寒）；久病畏寒喜暖、加衣可缓—阳虚（虚寒） |
| **但热不寒** | 只发热不怕冷 | **里热证**（详见下表壮热、潮热、微热） |
| **寒热往来** | 恶寒与发热交替发作 | **半表半里证**（少阳病：往来寒热、胸胁苦满、口苦咽干目眩）；若寒战与高热交替、发有定时—疟疾 |

### 4.2.2 但热不寒细分（AI重点）

| 类型 | 特征 | 临床意义 |
|------|------|----------|
| **壮热** | 高热（39℃以上）持续不退，不恶寒，反恶热，大汗，大渴 | 里实热证炽盛（阳明经证/温病气分证） |
| **潮热** | 发热如潮汐，按时而至或按时热甚 | 见下分三类 |
| ├ 阳明潮热（日晡潮热） | 热势较高，日晡（下午3-5时，申时）热甚，兼腹胀便秘 | **阳明腑实证**（燥屎内结） |
| ├ 湿温潮热 | 午后热甚，身热不扬（初扪不热、久扪灼手），兼头身困重、脘痞苔腻 | **湿温病**（湿热交蒸） |
| └ 阴虚潮热 | 午后或入夜低热，兼五心烦热、颧红盗汗 | **阴虚证**（阴虚内热） |
| **微热** | 发热不高（37-38℃）或仅自觉发热 | 多见于内伤病，按病机分： |
| ├ 阴虚发热 | 长期低热，兼颧红、五心烦热、盗汗 | 阴虚 |
| ├ 气虚发热 | 长期低热，兼疲乏、少气懒言、自汗，**劳累后加重** | 气虚（清阳不升、阴火内生），治宜甘温除热（补中益气汤） |
| ├ 血虚发热 | 低热兼面色萎黄、唇甲色淡、头晕心悸 | 血虚 |
| └ 气郁发热 | 情志不舒时发热或加重，兼胸闷、急躁易怒、叹气 | 气郁化火（肝郁） |
| 附：小儿夏季热 | 小儿夏季长期发热兼口渴多尿、无汗，秋凉自愈 | 气阴不足、暑气熏灼 |

## 4.3 问汗

汗为津液所化。"阳加于阴谓之汗。"问汗要点：有汗无汗、汗出时间、汗出部位、汗出性质及伴随症状。

### 4.3.1 特殊汗出（无汗/有汗辨表虚实）

- 表证无汗+恶寒重—表实寒（风寒表实证，麻黄汤证）；表证有汗+恶风—表虚（太阳中风，桂枝汤证）。

### 4.3.2 汗证分类表（AI重点）

| 汗证 | 表现 | 临床意义 |
|------|------|----------|
| **自汗** | 经常日间汗出不止，活动后尤甚 | **气虚、阳虚**（卫气不固、腠理不密）；常伴神疲乏力、气短懒言、畏风 |
| **盗汗** | 睡时汗出，醒则汗止 | **阴虚**（虚热蒸津外泄）；常兼颧红、五心烦热；盗汗+自汗并见—阴阳两虚/气阴两虚 |
| **绝汗（脱汗）** | 病情危重时大汗淋漓或汗出如珠、淋漓不止，兼四肢厥冷、脉微欲绝、呼吸急促 | **阳气欲脱**之危象（亡阳），见于心衰、休克（**AI应立即建议急救**） |
| **战汗** | 先恶寒战栗，后汗出 | 伤寒邪正剧争之转折点：战汗后热退脉静—邪去正复（向愈）；汗后烦躁脉疾—正气欲脱（危） |
| **头汗** | 仅头面部汗出 | 上焦热盛（头面蒸腾）；中焦湿热（湿邪郁蒸，兼苔腻）；虚阳上越（久病头汗、气喘乏力）；进食头汗多为生理或胃热 |
| **半身汗** | 身体一侧（左或右、上或下）汗出 | 风痰/瘀痰阻络（中风先兆或中风后遗症、痿证）；营卫不调 |
| **手足心汗** | 手足心汗出明显 | 阴经郁热（阴虚内热）；脾胃湿热；阳明腑实 |
| **黄汗** | 汗色发黄染衣 | 湿热交蒸 |

## 4.4 问疼痛（问头身）

疼痛病机总纲："不通则痛"（实证）与"不荣则痛"（虚证）。

### 4.4.1 疼痛性质辨析表（AI核心规则）

| 疼痛性质 | 特征 | 临床意义 |
|----------|------|----------|
| **胀痛** | 痛而兼胀，走窜不定，时轻时重 | **气滞**（肝郁气滞之胁胀、胃脘胀痛）；头目胀痛多属肝阳上亢或肝火上炎 |
| **刺痛** | 痛如针刺，固定拒按，夜间尤甚 | **血瘀** |
| **隐痛** | 疼痛绵绵、可以忍耐、劳累后加重、喜温喜按 | **虚证**（气血阴阳之虚，不荣则痛）：隐痛见于头部—气血虚；脘腹隐痛—脾胃虚寒 |
| **重痛** | 痛而兼沉重感 | **湿邪困阻**（湿性重浊）；头重痛—风湿上犯 |
| **冷痛** | 痛而兼冷感，得温则减 | **寒证**（寒凝）：实寒（寒邪阻络，痛剧拒按）与虚寒（阳气不足，痛缓喜按） |
| **灼痛** | 痛而兼灼热感，喜凉 | **热证**（火邪窜络或阴虚火旺） |
| **绞痛** | 痛势剧烈如绞 | **实邪闭阻气机**（结石、瘀血、蛔虫、寒邪固闭）：心脉痹阻之真心痛、结石腰腹绞痛、寒凝脘腹绞痛 |
| **掣痛（引痛、彻痛）** | 抽掣牵引作痛、由一处连及他处 | **筋脉失养**或筋脉阻滞不通（肝血虚不能养筋、寒凝经脉） |
| **酸痛** | 痛而兼酸楚感 | 湿邪困阻（湿性黏滞）；亦见于肾虚（腰酸） |
| **闷痛** | 痛而兼闷胀满感 | 气机不畅：胸闷痛—胸痹（心脉痹阻） |
| **走窜痛** | 疼痛部位游走不定 | 气滞（走窜于胸胁脘腹）或风邪偏胜之行痹（走窜肢体关节） |
| **固定痛** | 痛处固定不移 | 血瘀（固定刺痛）或湿邪（固定重着） |

### 4.4.2 疼痛虚实鉴别要点

- 实痛：起病急、痛势剧、拒按、得按痛甚、持续不解。
- 虚痛：起病缓、痛势绵绵、喜按、得按则舒、时作时止、劳累后加重。

### 4.4.3 头痛经络分经（部位→经络→用药引经）

| 头痛部位 | 归经 | 主经用药（引经） |
|----------|------|------------------|
| 后头部连项（枕后） | **太阳经头痛** | 羌活、蔓荆子、川芎 |
| 前额部连眉棱骨 | **阳明经头痛** | 白芷、葛根、知母 |
| 两侧（颞部） | **少阳经头痛** | 柴胡、黄芩、川芎 |
| 巅顶部（头顶） | **厥阴经头痛** | 吴茱萸、藁本 |
| 头痛连齿 | 少阴经头痛 | 细辛、独活 |
| 头痛昏重如裹 | 太阴经（湿困） | 苍术、半夏 |

按性质辨证：头痛遇风寒加重—风寒头痛；胀痛面红—肝阳（火）头痛；昏沉重着—风湿（痰湿）头痛；隐痛劳累加重—血虚/气虚头痛；刺痛固定夜间甚—瘀血头痛。

## 4.7 问睡眠（AI问诊高频）

| 睡眠异常 | 细分 | 辨证 |
|----------|------|------|
| **失眠（不寐）** | 不易入睡（入睡困难），兼心烦多梦、腰膝酸软、潮热盗汗 | **心肾不交**（阴虚火旺，水火不济） |
| | 睡后易醒、醒后难再入睡，兼心悸健忘、纳呆乏力、面色萎黄 | **心脾两虚**（气血不足，心神失养） |
| | 时时惊醒、睡中易惊悸、兼眩晕口苦、苔黄腻 | **胆郁痰扰**（痰热内扰，胆胃不和）；若平素胆怯易惊、气短倦怠—心胆气虚 |
| | 彻夜不眠、烦躁不安，兼面赤口渴、便秘溲赤、舌红苔黄 | **痰火扰心**/肝火扰神（实热） |
| | 失眠急躁易怒、胁胀太息 | 肝郁化火 |
| | 失眠多梦、五心烦热、盗汗颧红 | 心阴虚/阴虚火旺 |
| | 脘腹胀满不适而失眠（"胃不和则卧不安"） | 食滞胃脘 |
| **嗜睡** | 困倦嗜睡、头脑昏沉、苔腻 | 痰湿困脾（湿浊内盛） |
| | 饭后困倦嗜睡、纳呆便溏 | 脾气虚弱（中气不足，清阳不升） |
| | 精神萎靡、昏睡倦怠、畏寒蜷卧 | 心肾阳衰（病重） |
| | 小儿睡中惊惕或嗜睡与烦躁交替 | 惊风先兆 |

**口诀**：不易入睡责之心肾（不交），睡后易醒责之心脾（两虚），时时惊醒责之胆（痰扰），彻夜不眠责之痰火（扰心）。

## 4.8 问饮食口味

### 4.8.1 口渴与饮水

| 表现 | 临床意义 |
|------|----------|
| 口不渴 | 不渴—寒证、湿证（津液未伤） |

| 除中 | 久病重病本不能食、突然欲食甚至暴食 | **胃气衰败的假象**（回光返照表现之一，危候） |

| 食量渐增 | 胃气渐复（病向愈）；食量渐减 | 胃气衰败（病进） |

## 4.10 问情绪（七情状态评估）

七情（怒喜思忧悲恐惊）过极致病，直接伤及相应脏腑：怒伤肝、喜伤心、思伤脾、忧伤肺、恐伤肾。AI问诊应评估：

| 情志表现 | 提示证候 |
|----------|----------|
| 烦躁易怒、面红目赤、失眠 | 肝火上炎 |
| 情志抑郁、善太息、胸胁胀闷、月经不调 | 肝气郁结 |
| 悲忧欲哭（脏躁） | 心肺阴虚（甘麦大枣汤证） |
| 思虑难解、纳呆便溏、失眠健忘 | 心脾两虚（思伤脾） |
| 惊惕不安、胆怯易惊 | 心胆气虚、胆郁痰扰 |
| 恐惧不安、腰膝酸软 | 肾气虚（恐伤肾） |
| 喜笑不休 | 心火亢盛（喜伤心） |
| 情志异常+经期相关 | 肝郁气滞（经前紧张） |

情志既是病因又是症状：长期情志不遂可致气机郁滞（气郁→化火→伤阴→血瘀痰凝），AI问诊应重点询问发病前情志诱因。

|------|------|----------|
| 白带 | 量多色白质稀、无臭 | 脾虚湿困（脾气虚）、肾阳虚（下元虚寒） |
| 黄带 | 量多色黄质黏稠、臭秽 | **湿热下注**（肝经湿热、脾虚湿热） |
| 赤带 | 带下夹血、色红黏稠 | 肝郁化热（血热）、湿热伤络；带下五色杂见臭秽难闻需排除恶性病变（**AI应提示就医检查**） |

## 4.12 问小儿

| 问项 | 内容 | 意义 |
|------|------|------|
| 出生情况 | 是否足月、顺产难产、出生体重、有无窒息缺氧 | 先天禀赋（肾精）充足与否 |
| 喂养 | 母乳/人工喂养、辅食添加、食欲 | 脾胃后天之本发育状态 |
| 生长发育 | 抬头、坐、爬、走、说话、出牙、囟门闭合时间 | 判断肾精与发育 |
| 传染病接触史 | 麻疹、水痘、腮腺炎、百日咳等接触史及预防接种史 | 出疹性热病鉴别（"天花麻疹全占验"） |
| 儿科特有症状 | 发热伴惊风先兆（眉间青、嗜睡烦躁交替）、食积（夜卧不安、便臭） | 小儿"脏腑娇嫩、形气未充；脾常不足、肝常有余" |

## 4.13 问旧病、问病因、问家族史

| 问项 | 内容 | 辨证意义 |
|------|------|----------|
| 问旧病（既往史） | 既往患病、手术、外伤、输血、过敏史 | 体质判断、病机传变基础（如哮喘病史提示痰饮伏肺） |
| 问病因（发病诱因） | 外感六淫（受凉、淋雨）、内伤七情（生气、忧郁）、饮食不节（暴食、嗜酒）、劳倦房劳、外伤 | 直接指导**病因辨证**与去除诱因的医嘱 |
| 问家族史 | 家族遗传病、传染病（肺痨）、体质倾向 | 遗传体质（如过敏体质、消渴家族史） |
| 问服药（参机变） | 已服中西药、疗效反应、不良反应 | 避免重复/冲突用药；据疗效反推证型 |

# 五、切诊

切诊包括脉诊和按诊。

## 5.1 脉诊

### 5.1.1 寸口诊法与寸关尺分候脏腑

- 寸口（气口）脉：腕后桡动脉搏动处，分寸、关、尺三部。以掌后高骨（桡骨茎突）定关，关前为寸，关后为尺。
- 诊脉用三指定位，布指疏密与身高成比例；小儿一指三部。
- 诊脉要求"平息"：医生以自己一次正常呼吸（一息）数患者脉动次数。
- 举（轻取）、按（重取）、寻（中取/左右推寻）三种指力。

| 手 | 寸 | 关 | 尺 |
|----|----|----|----|
| 左手 | **心**（心包） | **肝**（胆） | **肾**（小肠、膀胱） |
| 右手 | **肺**（胸中） | **脾**（胃） | **肾/命门**（大肠） |

口诀：**左心肝肾、右肺脾命（门）**。

### 5.1.2 正常脉象（平脉）

- **一息四五至**（一次呼吸4-5跳，约60-90次/分，成年人静息状态）。
- 三部有脉，不浮不沉，不大不小，从容和缓，节律一致，尺脉沉取有力。
- 平脉有**胃、神、根**三特点：
  - **有胃**：从容、和缓、流利（胃气充足）；
  - **有神**：柔和有力、节律整齐；
  - **有根**：尺脉沉取应指有力（肾气不绝）。
- 生理变异：年龄（小儿脉数、老人脉稍弦）、性别（女性稍快）、季节（春稍弦、夏稍洪、秋稍浮、冬稍沉）、体型（胖人稍沉、瘦人稍浮）、运动员（迟缓有力）、酒后/运动后/情绪激动（数）等。

### 5.1.3 常见28脉（按类分述）：脉象特征与主病

脉象分六类总纲：**浮脉类主表、沉脉类主里、迟脉类主寒、数脉类主热、虚脉类主虚、实脉类主实。**

#### 浮脉类（主表证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **浮** | 轻取即得，重按稍减而不空（如水漂木） | **表证**；亦见于虚阳外越（久病浮而无根为危候）。浮有力为表实，浮无力为表虚 |
| **洪** | 脉体宽大，充实有力，来盛去衰（如波涛汹涌） | **热盛**（阳明气分大热、邪热亢盛） |
| **濡** | 浮而细软，重按无力 | 虚证、湿证（脾虚湿盛、诸虚劳损） |
| **散** | 浮散无根，至数不齐，按之则无 | 元气离散、脏气衰微（危候） |
| **芤** | 浮大中空，如按葱管 | **失血、伤阴**（大失血后血容量骤减） |
| **革** | 浮而搏指，中空外坚，如按鼓皮 | 精血虚寒（亡血、失精、半产漏下） |

#### 沉脉类（主里证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **沉** | 轻取不应，重按始得（如石投水） | **里证**。沉有力为里实，沉无力为里虚 |
| **伏** | 重按推筋按骨始得，甚则伏而不见 | 邪闭、厥证、痛极（邪气内伏） |
| **弱** | 沉细无力 | **气血不足**（阳气虚衰、气血两虚） |
| **牢** | 沉按实大弦长，坚牢不移 | 阴寒积聚（癥瘕积聚、痞块） |

#### 迟脉类（主寒证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **迟** | 一息不足四至（<60次/分） | **寒证**。迟有力为实寒（寒积），迟无力为虚寒（阳虚）；运动员生理性迟缓有力不作病论 |
| **缓** | 一息四至，脉来怠缓（从容和缓为平人；病理见脉势弛缓） | 湿证、脾虚（湿性黏滞）；亦见于正常胃气 |
| **涩** | 往来艰涩不畅，如轻刀刮竹，与滑相反 | **血瘀、精伤血少、气滞**（实涩—气滞血瘀；虚涩—伤精血少） |
| **结** | 迟而时一止，止无定数（不规则间歇） | **阴盛气结、寒痰瘀血**；亦见于气血虚衰（脏气衰微） |
| **代** | 迟而中止，止有定数（有规律间歇），良久复来 | **脏气衰微**（危候）、风证痛证、七情惊恐、跌打损伤 |

#### 数脉类（主热证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **数** | 一息五至以上（>90次/分） | **热证**。数有力为实热，数无力为虚热（阴虚内热）；亦见于正常运动、情绪、小儿 |
| **疾** | 一息七至以上（>140次/分），较数更急 | 热极、阳极阴竭（元气将脱，危候） |
| **促** | 数而时一止，止无定数 | 阳盛实热、气滞血瘀痰饮（实热郁滞）；促而无力为虚脱之象 |
| **动** | 脉短如豆，滑数有力，关部尤明显 | 痛证、惊恐（阴阳相搏） |

#### 虚脉类（主虚证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **虚** | 三部举按均无力，脉来迟缓松软 | **虚证**（气血两虚，尤多见于气虚） |
| **细** | 脉细如线，但应指明显 | **气血两虚**、湿证（湿邪阻压脉道）；诸虚劳损 |
| **微** | 极细极软，似有似无，按之欲绝 | **气血大虚、阳气衰微**（亡阳、暴脱，危候） |
| **短** | 首尾俱短，不及本位 | 气虚（短而无力）或气郁（短而有力） |

#### 实脉类（主实证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **实** | 三部举按均有力，充实有力 | **实证**（实热、积滞、瘀血、痰浊壅盛）；久病见实脉为孤阳外脱之逆象 |
| **滑** | 往来流利，如珠走盘，应指圆滑 | **痰饮、食滞、实热**；青壮年气血充盛及**孕妇**可见生理性滑脉（"孕脉"） |
| **紧** | 脉来绷紧有力，状如转绳，左右弹指 | **寒证、痛证、宿食**（寒主收引，脉道拘急） |
| **弦** | 端直以长，如按琴弦，从中直过，挺然指下 | **肝胆病、痛证、痰饮、疟疾**；春季健康人微弦为平；老年脉弦为肾虚、动脉硬化之象 |
| **长** | 脉体超过本位，首尾端直 | 阳证、热证、实证；长而和缓为平人（气血充足） |

#### 其他脉

### 5.2.1 按肌肤

| 触感 | 意义 |
|------|------|
| 肌肤灼热 | 实热证（阳证） |
| 肌肤寒冷 | 寒证；冷汗淋漓肢厥—亡阳（危） |

|-----------|------|

# 六、八纲辨证

八纲：**表、里、寒、热、虚、实、阴、阳**。前六纲为具体纲领，**阴阳为总纲**（表、热、实属阳；里、寒、虚属阴）。八纲辨证是各种辨证的总纲，指导辨证的第一层判断（病位深浅—表里；疾病性质—寒热；邪正盛衰—虚实；类别归属—阴阳）。

## 6.1 表证与里证（辨病位）

| 鉴别项 | 表证 | 里证 |
|--------|------|------|
| 定义 | 六淫邪气经皮毛、口鼻侵入，正气（卫气）抗邪于肤表浅层 | 病变部位在脏腑、气血、骨髓 |
| 寒热 | 恶寒发热**并见** | 但寒不热或但热不寒（寒热单见） |
| 主症 | 头身疼痛、鼻塞流涕、喷嚏、咽痒咳嗽 | 脏腑症状突出（咳喘、心悸、腹痛、呕泻、失眠等） |
| 舌象 | 舌苔薄，舌质变化不明显 | 舌质舌苔有明显变化 |
| 脉象 | 浮脉 | 沉脉或其他 |
| 病势 | 起病急、病位浅、病程短 | 病位深、病程较长 |
| 常见证 | 风寒束表证、风热犯表证 | 各类脏腑证、里寒里热证 |

表里鉴别关键：**发热恶寒同时并见为表证；但热不寒或但寒不热为里证**。

## 6.2 寒证与热证（辨病性）

| 鉴别项 | 寒证 | 热证 |
|--------|------|------|
| 寒热喜恶 | 恶寒喜暖、四肢不温 | 发热喜凉、面红目赤 |
| 口渴 | 口不渴或渴喜热饮、饮量少 | 口渴喜冷饮、饮量大 |
| 面色 | 面色㿠白 | 面红 |
| 神态 | 静而少言、蜷卧 | 躁动不安 |
| 二便 | 小便清长、大便溏薄 | 小便短赤、大便干结 |
| 痰涕 | 痰涕清稀 | 痰涕黄稠 |
| 舌象 | 舌淡苔白润 | 舌红苔黄干 |
| 脉象 | 迟或紧 | 数或洪滑 |

病机：寒证—感受寒邪或阳虚阴盛（"阴盛则寒，阳虚则寒"）；热证—感受热邪或阳盛阴虚（"阳盛则热，阴虚则热"）。

## 6.3 虚证与实证（辨邪正盛衰）

| 鉴别项 | 虚证 | 实证 |
|--------|------|------|
| 病程 | 久病、内伤、禀赋不足 | 新病、暴病、外感初中期 |
| 体质 | 形体虚弱、精神萎靡 | 形体壮实、声高气粗 |
| 声息 | 声低息微、少气懒言 | 声高气粗、甚则谵语 |
| 疼痛 | 隐痛、喜按、时作时止 | 剧痛、拒按、持续 |
| 腹诊 | 腹软喜按、按之舒适 | 腹硬满拒按 |
| 舌象 | 舌质娇嫩、少苔无苔 | 舌质苍老、苔厚腻 |
| 脉象 | 虚细无力 | 实洪有力 |

## 6.6 半表半里证（少阳证）

- 寒热往来（恶寒与发热交替）、胸胁苦满、心烦喜呕、默默不欲饮食、口苦、咽干、目眩。
- 脉弦。治疗小柴胡汤（和解少阳）。
- 识别要点：寒热往来+口苦+胸胁苦满+脉弦。

## 6.7 寒热真假与虚实真假（重证识别，AI安全关键）

### 6.7.1 真热假寒（阳盛格阴，"热深厥亦深"）

- 病机：阳热内盛郁闭于里，阳气不能外达四肢，格阴于外。
- **真象（本质，需重按细察）**：壮热、口渴喜冷饮、咽干口臭、小便短赤、大便燥结、舌红苔黄燥、脉滑数有力（沉取有力）。
- **假象（表象）**：四肢厥冷（胸腹灼热）、脉沉伏但重按有力。
- 治法：清泻里热（白虎汤、承气汤类）。

### 6.7.2 真寒假热（阴盛格阳、戴阳证）

- 病机：阴寒极盛于内，格拒衰极之虚阳浮越于上/外。
- **真象（本质）**：四肢厥逆、下利清谷、小便清长、精神萎靡、舌淡苔白滑润、脉微细欲绝。
- **假象（表象）**：身热但**欲盖衣被**、面红但**如妆浮游不定（颧红娇嫩）**、口渴但**喜热饮且饮量不多**、脉大但**按之无力**、烦躁但疲惫欲寐。
- 治法：回阳救逆、引火归元（通脉四逆汤、白通汤类）。

### 6.7.3 真实假虚（"大实有羸状"）

- 病机：实邪壅滞（热结、痰食、瘀血）阻滞气机，反见似虚之象。
- 真象：腹满硬痛拒按、便秘、舌苔厚浊、脉沉实有力。
- 假象：沉默少言、倦怠乏力、肢体不想动（但强询之下并非真虚）。

### 6.7.4 真虚假实（"至虚有盛候"）

- 病机：正气虚甚（脾虚等），运化无力，反见似实之象。
- 真象：神疲乏力、脉虚无力、舌淡嫩。
- 假象：腹部胀满，但**时胀时减、喜温喜按**；气喘但气怯声低；便意频频但努挣乏力。

### 6.7.5 真假鉴别五大要点（AI规则）

1. **舌象最可靠**：舌红苔黄燥为真热；舌淡苔白滑为真寒。
2. **脉象重按**：假象之脉浮大但重按无力；真热之脉沉取滑数有力。
3. **口渴饮水**：真热渴喜冷饮量多；假热渴喜热饮量少。
4. **二便**：便干尿赤为热；便溏尿清长为寒。
5. **整体与局部**：假象多现于四肢、肌肤、面色（表层）；本质多反映于舌脉沉取、二便、精神状态。

| 亡阳证 | 冷汗淋漓、面色苍白、四肢厥冷、呼吸微弱、脉微欲绝 | 舌淡白润（急危，回阳救逆——四逆汤类） |

# 七、脏腑辨证（AI辨证核心）

脏腑辨证是根据脏腑的生理功能、病理表现，对四诊资料进行归纳分析，推断病变脏腑部位、性质、正邪盛衰的辨证方法，是内伤杂病辨证的**核心体系**，也是AI辨证推理的主引擎。

每个证型按"病因病机→症状→舌象→脉象→治法→代表方"结构化呈现（症状中加粗者为核心辨证要点/主症）。

# 八、其他辨证体系

## 8.1 六经辨证（外感伤寒辨证，张仲景《伤寒论》）

六经辨证以太阳、阳明、少阳、太阴、少阴、厥阴六经概括外感病的演变阶段。三阳病（太阳、阳明、少阳）多实证、热证；三阴病（太阴、少阴、厥阴）多虚证、寒证。

| 经证 | 提纲（原文要义） | 主要表现 | 病机 | 治法/代表方 |
|------|------------------|----------|------|-------------|
| **太阳病** | "太阳之为病，脉浮，头项强痛而恶寒" | 恶寒发热、头项强痛、脉浮。中风证：发热汗出恶风、脉浮缓（桂枝汤）；伤寒证：恶寒无汗、身痛、脉浮紧（麻黄汤） | 风寒袭表，营卫失和（太阳主一身之表，为六经藩篱） | 解肌祛风（桂枝汤）/发汗解表（麻黄汤） |
| **阳明病** | "阳明之为病，胃家实是也" | 经证：**壮热、大汗、大渴、脉洪大**（白虎汤）；腑证：**日晡潮热、腹胀便秘、烦躁谵语、脉沉实**（承气汤类） | 邪热入里，胃肠燥热（经证无形热盛；腑证燥屎内结） | 清热生津（白虎汤）/峻下热结（大承气汤） |
| **少阳病** | "少阳之为病，口苦、咽干、目眩也" | **往来寒热、胸胁苦满、默默不欲饮食、心烦喜呕**、口苦咽干目眩、脉弦 | 邪犯少阳，胆火内郁，枢机不利（半表半里） | 和解少阳（小柴胡汤） |
| **太阴病** | "太阴之为病，腹满而吐，食不下，自利益甚，时腹自痛" | **腹满呕吐、食不下、腹泻（自利）、时腹自痛**、口不渴、畏寒、舌淡胖苔白 | 脾阳虚弱，寒湿内盛 | 温中散寒，健脾燥湿（理中汤、四逆辈） |
| **少阴病** | "少阴之为病，脉微细，但欲寐也" | **脉微细、但欲寐（精神萎靡似睡非睡）**。寒化证：畏寒蜷卧、下利清谷、四肢厥冷、脉微欲绝（四逆汤）；热化证：心烦不得卧、口燥咽干、舌红少苔脉细数（黄连阿胶汤） | 心肾阳衰（寒化）或阴虚火旺（热化），为疾病危重阶段 | 回阳救逆（四逆汤）/滋阴清热（黄连阿胶汤） |
| **厥阴病** | "厥阴之为病，消渴，气上撞心，心中疼热，饥而不欲食，食则吐蛔，下之利不止" | **上热下寒（寒热错杂）**：消渴、气上撞心、心中疼热、饥而不欲食、吐蛔；或厥热胜复（四肢厥冷与发热交替） | 阴尽阳生、寒热错杂、肝胃气机逆乱 | 寒温并用，清上温下（乌梅丸）；厥证用四逆散/当归四逆汤 |

### 传变、合病、并病

| 概念 | 定义 | 举例 |
|------|------|------|
| 循经传 | 按六经次序相传（太阳→阳明→少阳→三阴） | 太阳病不解内传阳明 |
| 越经传 | 隔一经或隔两经相传 | 太阳病不愈直传少阳 |
| 表里传 | 相表里之经相传 | 太阳传少阴 |
| 直中 | 外邪不经三阳直犯三阴 | 直中太阴（起病即腹冷痛下利） |
| **合病** | 两经或三经症状**同时出现**（起病即见） | 太阳阳明合病（发热恶寒兼下利或喘）、三阳合病 |
| **并病** | 一经病证未罢又出现另一经病证（**先后出现**） | 太阳并阳明 |
| 传经与否的判断依据：正气强弱、邪气盛衰、治疗当否 | | |

## 8.2 卫气营血辨证（外感温热病辨证，叶天士《温热论》）

温病发展由浅入深四阶段："卫之后方言气，营之后方言血。"传变规律：卫分→气分→营分→血分（顺传）；亦可卫分直入营血（逆传心包）。

| 阶段 | 病位 | 主要表现 | 舌象 | 脉象 | 治法 | 代表方 |
|------|------|----------|------|------|------|--------|
| **卫分证** | 表（肺卫） | **发热微恶风寒、头痛、咽痛、口微渴、咳嗽**，病之初起 | 舌边尖红苔薄白干 | 浮数 | 辛凉解表（透邪外出） | 银翘散、桑菊饮 |
| **气分证** | 里（肺胃肠胆等） | **壮热不恶寒、反恶热、大汗、大渴、面赤**、或咳喘、或心烦懊憹、或腹胀便秘；湿温则身热不扬、脘痞苔腻 | 舌红苔黄燥 | 洪大滑数 | 清气泄热（清热生津） | 白虎汤；腑实用承气汤；湿温用三仁汤 |
| **营分证** | 里（心营、心包） | **身热夜甚、心烦不寐、甚则神昏谵语、斑疹隐隐**、口干反不甚渴饮 | 舌红绛无苔 | 细数 | 清营透热，养阴生津 | 清营汤；神昏配安宫牛黄丸（清心开窍） |
| **血分证** | 里（血、心肝肾） | **身热夜甚、躁扰昏狂、斑疹透露（紫黑）、吐血衄血便血尿血**、或四肢抽搐颈项强直（热极生风）、或手足心热口干、倦怠（肝肾阴伤） | 舌深绛紫暗 | 细数或弦数 | 清热凉血散血 | 犀角地黄汤（现以水牛角代）；动风用羚角钩藤汤；阴虚风动用大定风珠 |

## 8.3 三焦辨证（温病辨证，吴鞠通《温病条辨》）

三焦辨证以三焦划分温病病变部位与阶段，与卫气营血辨证纵横交错互补。

| 阶段 | 病位（脏腑） | 主要表现 | 治法 | 代表方 |
|------|--------------|----------|------|--------|
| **上焦证** | 肺、心包 | 邪袭肺卫：发热微恶寒、咳嗽（银翘散）；热壅于肺：身热汗出、咳喘口渴（麻杏石甘汤）；逆传心包：神昏谵语、舌謇肢厥（清宫汤、安宫牛黄丸） | 宣上（轻清宣透） | 银翘散、麻杏石甘汤、安宫牛黄丸 |
| **中焦证** | 脾、胃 | 胃燥：阳明燥热（壮热、面赤、便秘、苔黄燥——白虎/承气）；脾湿：太阴寒湿或湿温（身热不扬、脘痞呕恶、便溏苔腻） | 燥中（辛开苦降、清热化湿） | 白虎汤、承气汤、三仁汤、王氏连朴饮 |
| **下焦证** | 肝、肾 | 肾阴耗损：手足心热甚于手足背、口燥咽干、神倦、脉虚神倦（加减复脉汤）；肝风内动（阴虚风动）：手足蠕动或瘛疭、心中憺憺大动 | 泄下（滋阴潜阳） | 加减复脉汤、大定风珠、三甲复脉汤 |

传变规律：上焦→中焦→下焦，始于上焦、终于下焦；"治上焦如羽（非轻不举），治中焦如衡（非平不安），治下焦如权（非重不沉）。"

| **寒淫证** | 寒性凝滞收引、易伤阳气、寒主痛 | 恶寒重发热轻（表寒）；无汗、头身剧痛、脉浮紧；脘腹冷痛拒按、四肢拘急（中寒）；局部冷痛僵直（冻伤） |
| **暑淫证** | 暑性炎热升散、耗气伤津、多夹湿 | 高热汗出、口渴喜饮、气短乏力（伤暑）；猝然昏倒、大汗淋漓（中暑）；暑湿则身热不扬、肢重脘闷、呕恶便溏 |
| **湿淫证** | 湿性重浊、黏滞、趋下、阻遏气机、损伤脾阳 | 头重如裹、肢体困重、关节重着（着痹）、胸闷脘痞纳呆、便溏黏滞、苔腻、病势缠绵；湿性趋下则下肢水肿、淋浊带下、湿疹 |
| **燥淫证** | 燥性干涩、易伤津液、易伤肺 | 口唇鼻咽干燥、干咳少痰或无痰、皮肤干皲裂、小便短少、大便干结（凉燥兼表寒、温燥兼表热） |
| **火（热）淫证** | 火性炎上、易扰心神伤津耗气、生风动血、致肿疡 | 壮热面赤、烦渴饮冷、烦躁或神昏谵语、吐衄发斑、四肢抽搐、疮疡红肿热痛、便秘尿赤、舌红绛苔黄燥 |
| **七情内伤** | 直接伤脏（怒伤肝、喜伤心、思伤脾、忧伤肺、恐伤肾）、影响气机（怒则气上、喜则气缓、悲则气消、恐则气下、惊则气乱、思则气结） | 情志异常+相应脏腑症状（详见4.10） |
| **饮食劳逸** | 饮食不节伤脾胃（食滞）；劳倦伤脾气虚；房劳伤肾精 | 食滞胃脘证、脾气虚证、肾精不足证 |
| **外伤虫兽** | 金刃、跌打、虫蛇咬伤 | 局部瘀肿疼痛、出血、破伤风等 |

# 九、辨证与辨病结合

## 9.1 病、证、症的区别与关系

| 概念 | 定义 | 特点 | 举例 |
|------|------|------|------|
| **症（症状/体征）** | 患者主观感到的异常（症状）或医生检查所得的异常表现（体征），是疾病的个别表面现象 | 单一表现，无整体判断 | 发热、咳嗽、舌红、脉数 |
| **证（证候/证型）** | 疾病发展过程中某一阶段或某一类型的病理概括，包括病位、病因、病性、邪正关系 | 阶段性、整体性、动态性，是**辨证论治的直接依据** | 风寒束表证、心脾两虚证 |
| **病（疾病）** | 对疾病全过程的特点与规律的总体概括（病因、发病、传变、预后） | 全过程、规律性 | 感冒、消渴、不寐、中风 |

三者关系：**由症（多个症状+舌脉）→综合判断→证（某病的一个阶段可以出现多个证）；病的全过程由不同阶段的证组成**。"症"是辨"证"的素材，"证"是辨"病"的基础，"病"统辖"证"的演变。

AI映射关系：`症状集合（含舌脉） → 证型 → 治法 → 方剂`；同时`主诉+病程+特征症状 → 病名`。

## 9.2 同病异治与异病同治

| 概念 | 定义 | 举例 |
|------|------|------|
| **同病异治** | 同一疾病，因发病时间、地域、患者体质不同，或处于不同阶段（证不同），治法不同 | 感冒（风寒证用辛温解表——荆防败毒散；风热证用辛凉解表——银翘散；气虚感冒用益气解表——参苏饮）；同为咳嗽，痰湿用二陈汤、阴虚用沙参麦冬汤 |
| **异病同治** | 不同疾病，在发展过程中出现相同（或相似）的证，故可采用相同治法 | 久泻脱肛、子宫脱垂、胃下垂（不同病）皆见中气下陷证，均用补中益气汤；失眠与心悸均可因心脾两虚而用归脾汤 |

原理：**"证同治亦同，证异治亦异"**——辨证论治的本质是"因证施治"，病与证结合方能全面。

## 9.3 现代中医看病实际流程（AI问诊系统流程对照）

```
1. 挂号分科
   患者自述主要不适 → 预诊分科（内科/针灸/推拿/妇科/儿科/骨伤/皮科/耳鼻喉等）
   [AI对应：主诉采集与初步分诊模块]

2. 四诊收集
   望：神色形态、舌质舌苔、小儿指纹、排泄物（部分需面诊/照片）
   闻：声音、气味（部分需面诊/语音）
   问：十问歌展开——寒热汗、头身、二便、饮食口味、胸腹、耳目、睡眠、
       情志、经带、旧病、病因、服药史、家族史
   切：寸口脉三部九候、按肌肤手足脘腹（需面诊；AI可让用户自述或设备采集）
   [AI对应：结构化问诊问卷+舌象照片识别（可选）+脉象外设（可选）]

3. 辨证
   第一步 八纲辨证定性位（表里/寒热/虚实/阴阳）
   第二步 选择体系深入：内伤杂病→脏腑辨证+气血津液辨证；
           外感→六经辨证/卫气营血/三焦辨证；必要时病因辨证
   第三步 确立证名（如"肝郁脾虚证"）并说明病机
   [AI对应：规则引擎/知识图谱推理，输出候选证型与置信度]

4. 立法
   依证立治则治法：寒者热之、热者寒之、虚则补之、实则泻之、
   标本缓急、正治反治、扶正祛邪、调整阴阳、三因制宜
   [AI对应：证型→治法映射表]

5. 处方与医嘱
   选代表方加减化裁（君臣佐使），或针灸、推拿、拔罐、刮痧等；
   剂量、煎服法、饮食宜忌、起居调摄、情志疏导
   [AI对应：治法→方剂映射+安全校验（配伍禁忌十八反十九畏、妊娠禁忌、
   毒性药材、中西药相互作用）；输出建议须附"请咨询执业中医师"提示]

6. 复诊调方
   有效→效不更方或微调；无效→重新辨证（审证求因）；
   病邪渐退→中病即止、攻补兼施转调理；慢病→守方缓图、丸散膏方善后
   [AI对应：随访跟踪、疗效评价、证型演变记录]
```

## 9.4 AI问诊安全红线（建议内置于系统规则）

以下情形应立即建议线下/急诊就医，不得仅作AI辨证处理：

1. **假神/回光返照**征象（久病突然精神转佳、能食）。
2. **绝汗、亡阳亡阴**（大汗淋漓肢厥脉微）。
3. **真心痛**（剧烈胸痛持续不解、痛引肩背、大汗）——心梗风险。
4. **中风征象**（突然口眼㖞斜、半身不遂、舌强语謇、意识改变）。
5. 高热持续不退（壮热）、抽搐、神昏谵语。
6. 大出血（崩漏不止、呕血便血量多）。
7. 腹部剧痛拒按、板状腹（急腹症：肠痈、穿孔）。
8. 短缩舌、强硬舌、歪斜舌等危重舌态。
9. 妊娠期用药需求、婴幼儿重症、除中（久病突然暴食）。
10. 结、代、微、散等危重脉象描述伴明显不适者。
