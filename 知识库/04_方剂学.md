# 一、方剂学基础理论

## 1.1 方剂与治法的关系

- **方以法立，以法统方**：治法是组方的依据，方剂是治法的体现。先有"辨证→立法→遣方→用药"的完整链条。
- **八法**（程钟龄《医学心悟》）：汗、吐、下、和、温、清、消、补。
  - 汗法：解表祛邪，用于表证（如麻黄汤、桂枝汤、银翘散）。
  - 吐法：涌吐痰涎宿食，用于邪滞上脘（现代少用，如瓜蒂散）。
  - 下法：泻下里实，用于里实证（如大承气汤、麻子仁丸）。
  - 和法：和解少阳、调和肝脾/肠胃（如小柴胡汤、逍遥散、半夏泻心汤）。
  - 温法：温里祛寒（如理中丸、四逆汤、阳和汤）。
  - 清法：清热泻火（如白虎汤、黄连解毒汤、龙胆泻肝汤）。
  - 消法：消食导滞、化瘀消癥（如保和丸、血府逐瘀汤）。
  - 补法：补益气血阴阳（如四君子汤、六味地黄丸、肾气丸）。

## 1.2 组方原则：君臣佐使

首见于《素问·至真要大论》："主病之谓君，佐君之谓臣，应臣之谓使。"

| 角色 | 定义 | 说明 |
|------|------|------|
| **君药** | 针对主病或主证起主要治疗作用的药物 | 方中不可或缺，药力居首；决定方剂的主要功效方向 |
| **臣药** | ①辅助君药加强治疗主病主证；②针对重要的兼病或兼证起主要治疗作用 | 是君药的"加强部队" |
| **佐药** | ①**佐助药**：配合君臣药加强治疗，或直接治疗次要兼证；②**佐制药**：消除或减弱君臣药的毒性、烈性；③**反佐药**：与君药性味相反而能在治疗中起相成作用（如寒药热服、热药中少佐寒药防格拒） | 药味可多可少，视需要取舍 |
| **使药** | ①**引经药**：引方中诸药直达病所；②**调和药**：调和诸药药性 | 常用甘草、大枣；引经如桔梗载药上行、牛膝引血下行 |

**经典示例——麻黄汤**（《伤寒论》）：
- 君：**麻黄**——辛温发汗解表、宣肺平喘，针对风寒表实主证。
- 臣：**桂枝**——透营达卫，助麻黄发汗解表，兼解肢体疼痛。
- 佐：**杏仁**——降利肺气，与麻黄一宣一降，加强平喘（佐助）。
- 使：**炙甘草**——调和麻、杏宣降之性，缓和汗力（调和）。

**经典示例——小青龙汤**（《伤寒论》）：
- 君：**麻黄、桂枝**——发汗解表，除外寒；又温化水饮。
- 臣：**干姜、细辛**——温肺化饮，助君药散寒蠲饮。
- 佐：**五味子**——敛肺止咳（防辛散耗肺气，属"佐制"兼"相反相成"）；**白芍**——养血敛阴，防温燥伤津；**半夏**——燥湿化痰，降逆止咳。
- 使：**炙甘草**——益气和中，调和诸药。
- 配伍特点：**散中有收、开中有合**，麻黄与五味子、干姜与白芍相对而用，是"佐制""反佐"思维的代表。

**组方要点**：
1. 君药必备，臣佐使可随病情、治法灵活取舍；并非每方君臣佐使俱全。
2. 药物在方中的"角色"取决于其针对的病证主次，而非剂量大小或药材贵贱（虽然君药常相对量重）。
3. 组方还须结合患者体质、年龄、性别、季节气候、地域等因素。

## 1.3 方剂的变化规律（方剂运用的灵活性）

同一基础方通过以下三种变化衍生出新方，体现"师其法而不泥其方"：

### 1.3.1 药味加减（加减运用）
- 在主证不变、兼证变化时，加减次要药物。
- 例：**银翘散**→咽肿痛甚加马勃、玄参；**四君子汤**加陈皮为**异功散**（兼气滞），再加半夏为**六君子汤**（兼痰湿），六君子加木香、砂仁为**香砂六君子汤**（兼气滞脘胀）。
- 注意：药味加减若触及君药或改变配伍核心，则功效主治随之改变（如麻黄汤去桂枝加生姜为三拗汤，发汗力减而重在宣肺平喘）。

### 1.3.2 药量增减
- 药味不变，改变剂量比例，则方剂功效主次改变，甚至方名改变。
- 例：**小承气汤**与**厚朴三物汤**同用大黄、枳实、厚朴：小承气汤大黄量重（12g）为君——攻下热结；厚朴三物汤厚朴量重（24g）为君——行气除满。
- 例：**四逆汤**与**通脉四逆汤**药味全同，仅附子、干姜用量加重，由回阳救逆变为破阴通脉。

### 1.3.3 剂型更换
- 药味药量不变，改变剂型，则作用快慢、力量强弱改变。
- 例：理中丸（作用和缓，治中焦虚寒轻证缓证）作汤剂内服（力峻，治急证）；保和丸与保和汤。
- 一般规律："汤者荡也"力峻效速，"丸者缓也"力缓效持。

## 1.4 剂型

### 1.4.1 传统剂型
| 剂型 | 制法/特点 | 适用 |
|------|-----------|------|
| **汤剂** | 饮片加水煎煮去渣取汁；吸收快、起效速、可随证加减 | 急症、重症、病情多变者；内服外用（熏洗）皆可 |
| **散剂** | 药物研末混匀，内服（水调服/煎服）或外用；"散者散也，去急病用之"；兼具吸收快与便于携带优点 | 急证、脾胃病；发散、行气、活血类药（五苓散、平胃散、行军散） |
| **丸剂** | 药末加蜜、水、糊等黏合制成；"丸者缓也"，吸收徐缓、作用持久、便于携带贮存 | 慢性病调理、病后调养（六味地黄丸、理中丸） |
| **膏剂** | ①内服膏滋（煎煮浓缩加糖/蜜熬制，滋润补益）；②外用膏药（贴敷） | 秋冬调补、慢性虚损（膏方）；外科疮疡、风湿痹痛（黑膏药） |
| **丹剂** | 矿物药高温炼制（历史上亦泛指贵重效宏之制剂） | 外科疮疡、痈疽；部分急救开窍方（至宝丹、紫雪丹） |
| **酒剂** | 药材白酒浸提；酒能行血通络、助药力 | 风湿痹痛、跌打损伤、经络瘀阻 |
| **露剂** | 芳香类药物蒸馏所得澄明液（如金银花露） | 轻清宣透、清热生津 |
| **锭剂** | 药末加黏合剂制成纺锤形/圆柱形硬块，研末调服或磨汁外涂 | 外科疮疡、咽痛（紫金锭） |
| **条剂** | 药末加赋形剂搓成线香状药条，外用插入疮口 | 外科瘘管、窦道化腐引流 |
| **线剂** | 药线（丝线或棉线浸药）结扎/引流 | 痔瘘挂线、引流 |
| **洗剂** | 药液外洗 | 皮肤病、痔疮、阴痒 |
| **搽剂** | 药液外搽涂擦 | 风湿骨痛、跌打扭伤 |
| **熏剂** | 药物燃烧或加热熏蒸患处/穴位 | 湿疮、关节痛、艾灸类 |
| **坐药（栓剂）** | 药物制成栓状纳入阴道/肛门/鼻腔等腔道 | 阴道炎、痔疮（如野菊花栓） |
| **导药（导法）** | 药液（如蜜煎导）灌肠或纳入肛内导便 | 津亏便秘（蜜煎导方为最早导法记载） |

### 1.4.2 现代剂型
- **颗粒剂（配方颗粒/冲剂）**：单味或复方提取物制粒，沸水冲服，兼有汤剂吸收较快与成药便捷的优点，是目前"代煎汤剂"的主流形式之一。
- **胶囊剂**：药物粉末/提取物装胶囊，掩盖不良气味，稳定性好（如藿香正气软胶囊）。
- **片剂**：剂量准确、便于携带（如银翘解毒片）。
- **口服液/合剂/糖浆剂**：服用方便，适于儿童及口感要求（如急支糖浆）。
- **滴丸**：起效快、生物利用度高（如复方丹参滴丸、藿香正气滴丸，舌下含服数分钟起效）。
- **注射剂**：起效最快，用于急危重症（如参附注射液、生脉注射液、清开灵注射液）；**必须在医疗机构由专业人员使用**，过敏风险高于口服剂型。
- **气雾剂/贴膏/凝胶**等外用新剂型。

## 1.5 汤剂的优势与煎服要点

**优势**：
1. **吸收快、起效迅速**——水溶性成分直接入血发挥药效。
2. **可随证加减**——实现"一人一方、一时一方"，最贴合辨证论治个体化需求。
3. 剂量比例可灵活调整，便于体现君臣佐使的动态配伍。

**煎服要点（供知识库科普模块）**：
- 解表剂宜武火急煎，芳香易挥发之品（薄荷、砂仁、豆蔻）宜后下；金石贝壳类（石膏、龙骨、牡蛎）宜先煎；附子宜久煎（先煎30-60分钟以上减毒）；芒硝烊化冲服；阿胶烊化。
- 一般煎前冷水浸泡30-60分钟；一剂药煎2-3次合并分服。
- 服药时间：补益剂宜饭前服，驱虫泻下剂宜空腹服，对胃有刺激者宜饭后服；安神剂宜睡前服。
- 服药温度：一般温服；解表剂热服并覆被取汗；寒药治热证宜凉服，热药治寒证宜热服；真热假寒证寒药热服（反佐服法）。

## 1.6 中成药使用规范

1. **辨证使用**：中成药同样必须辨证。风寒感冒误用辛凉清热药（如双黄连）会冰遏表邪、加重病情；风热感冒误用辛温发散药（如风寒感冒颗粒）则助热生火、咽喉肿痛加剧。
2. **阅读说明书**：注意功能主治、证型、禁忌、不良反应；"禁忌"（绝对不能用）与"慎用"（权衡后遵医嘱）含义不同。
3. **特殊人群**：
   - 孕妇：含活血、峻下、破气、滑利及毒剧成分者禁用（如麝香、大黄、桃仁、红花类）；妊娠前三个月尤须谨慎；标明"孕妇禁用"绝对不用。
   - 儿童：2岁以下不建议自行服用止咳抗感冒类中成药，6岁以下慎用，均须医师指导并减量。
   - 老人、肝肾功能不全者：含朱砂（汞）、雄黄（砷）的制剂（安宫牛黄丸、朱砂安神丸等）不可过量久服。
4. **配伍与联用**：避免含"十八反、十九畏"成分的中成药联用；避免与西药随意同服（如藿香正气水与头孢类同用可致双硫仑样反应）；中西药联用一般间隔至少30分钟-1小时。
5. **疗程**：中病即止（如解表药汗出热退即停），不宜长期服用同一中成药；服药期间忌生冷、油腻、辛辣、烟酒。
6. **含毒剧药材管理**：含罂粟壳（如强力枇杷露、真人养脏汤类）、马钱子、川乌、草乌、雄黄、朱砂、蟾酥等的成药，须严格遵医嘱，不可自行购买长期使用。
7. **急重症提示**：胸痛持续不缓解、高热惊厥、昏迷等，应立即拨打急救电话就医，中成药（如速效救心丸）仅作送医前应急使用。

# 二、经典名方详解

> 体例：**出处｜组成｜功用｜主治证候｜方解（君臣佐使）｜加减变化｜现代应用**。
> 经典名方详写（标注★为重点详解方），其余方剂至少含组成、功用、主治证型、核心方解四要素。
> 本节所有方剂的运用均需执业中医师辨证指导。

## 2.1 解表剂

### 2.1.1 ★麻黄汤（《伤寒论》）——辛温发汗第一方
- **组成**：麻黄9g，桂枝6g，杏仁6g，炙甘草3g。
- **功用**：发汗解表，宣肺平喘。
- **主治**：外感风寒**表实证**：恶寒发热、头身疼痛、**无汗而喘**、舌苔薄白、脉浮紧。
- **方解**：麻黄为君，发汗解表、宣肺平喘；桂枝为臣，温经散寒、透营达卫，助麻黄发汗；杏仁为佐，降利肺气，与麻黄一宣一降以平喘；炙甘草为使，调和诸药、缓麻桂峻汗之性。
- **加减**：夹湿加白术（麻黄加术汤）；喘急痰多加苏子、桑白皮；鼻塞流涕加苍耳子、辛夷。
- **现代应用**：感冒、流感、支气管哮喘、急性支气管炎、风寒束表之荨麻疹初起等。
- **注意**：本方发汗力强，"疮家、淋家、衄家、亡血家"、表虚自汗、外感风热、体虚者均当禁用。

### 2.1.2 ★桂枝汤（《伤寒论》）——"群方之冠"，调和营卫
- **组成**：桂枝9g，芍药9g，炙甘草6g，生姜9g，大枣3枚（原方十二枚）。
- **功用**：解肌发表，调和营卫。
- **主治**：外感风寒**表虚证**（太阳中风证）：**汗出恶风**、发热头痛、鼻鸣干呕、苔白不渴、脉浮缓或浮弱。
- **方解**：桂枝为君，助卫阳、通经络、解肌发表；芍药为臣，益阴敛营，与桂枝等量相配**一散一收、营卫同调**；生姜、大枣为佐，助桂枝调和营卫、和中；炙甘草为使，调和诸药、合桂枝"辛甘化阳"、合芍药"酸甘化阴"。
- **加减**：项背强几几加葛根（桂枝加葛根汤）；兼喘加厚朴、杏仁（桂枝加厚朴杏子汤）；汗出恶风加重芍药、生姜量（桂枝加桂汤治奔豚）。
- **现代应用**：感冒、流感、低热、自汗、风湿性关节炎、过敏性鼻炎、产后及病后营卫不和之自汗恶风等。
- **麻黄汤与桂枝汤鉴别（AI问诊关键）**：
  | 项目 | 麻黄汤 | 桂枝汤 |
  |------|--------|--------|
  | 证型 | 风寒表实证 | 风寒表虚证 |
  | 汗 | **无汗** | **有汗（自汗）** |
  | 恶 | 恶寒重、无风亦恶 | 恶风、遇风则剧 |
  | 脉 | 浮紧 | 浮缓 |
  | 喘 | 常兼咳喘 | 一般不喘 |
  | 治法方向 | 发汗解表为主 | 解肌祛邪、调和营卫 |

### 2.1.3 ★小柴胡汤（《伤寒论》）——和解少阳代表方（十大名方）
- **组成**：柴胡24g，黄芩9g，人参9g，半夏9g，炙甘草9g，生姜9g，大枣4枚。
- **功用**：和解少阳。
- **主治**：①伤寒少阳证：**寒热往来**、胸胁苦满、默默不欲饮食、心烦喜呕、口苦、咽干、目眩、苔薄白、脉弦；②妇人伤寒热入血室；③疟疾、黄疸等见少阳证者。
- **方解**：柴胡为君，透泄少阳之邪、疏解气机郁滞；黄芩为臣，清泄少阳之热，与柴胡相配**一散一清**，共解少阳邪热；半夏、生姜为佐，和胃降逆止呕，人参、大枣为佐，益气健脾扶正（防邪内传，"见肝之病，知肝传脾"之旨的体现）；炙甘草为使，助参枣扶正并调和诸药。
- **配伍特点**：**和解不忘扶正，散中有收，升清降浊并施**；去滓再煎，使药性调和。
- **加减**：胸中烦而不呕去半夏、人参加瓜蒌；渴者去半夏加天花粉；腹中痛去黄芩加芍药；胁下痞硬去大枣加牡蛎；心下悸、小便不利去黄芩加茯苓。
- **衍生方**：柴胡桂枝汤（兼表证）、大柴胡汤（兼阳明里实，加枳实、大黄、芍药）、柴胡疏肝散（理气疏肝）、逍遥散（疏肝健脾养血）。

### 2.3.1 ★逍遥散（《太平惠民和剂局方》）——疏肝健脾养血（十大名方）

### 2.3.3 半夏泻心汤（《伤寒论》）——寒热平调、消痞散结

## 2.4 清热剂

### 2.4.2 龙胆泻肝汤（《医方集解》引《局方》）——清泻肝胆实火湿热
- **组成**：龙胆草6g，黄芩9g，栀子9g，泽泻12g，木通6g，车前子9g，当归3g，生地黄9g，柴胡6g，生甘草6g。

- **方解**：龙胆草为君，大苦大寒，上泻肝胆实火、下清下焦湿热；黄芩、栀子为臣，苦寒泻火燥湿；泽泻、木通、车前子为佐，导湿热下行从小便出；肝为藏血之脏，火盛必伤阴血，故佐生地、当归滋阴养血以顾肝体；柴胡为佐，疏畅肝胆之气并引药入肝胆经；甘草为使，调和诸药、护胃安中。
- **配伍特点**：**泻中有补、利中有滋、降中寓升**，祛邪不伤正。
- **注意**：方中药性多苦寒，久服败胃；脾胃虚寒、阴虚阳亢者非其所宜。传统方用木通（关木通含马兜铃酸已禁用，现多用通草或木通正品）。中成药：龙胆泻肝丸（水丸/颗粒），不宜长期服用。

### 2.4.3 葛根芩连汤（《伤寒论》）——解表清里、止泻
- **组成**：葛根15g，炙甘草6g，黄芩9g，黄连9g。
- **功用**：解表清里。
- **主治**：**协热下利**：身热下利（泻下臭秽稀水或黏滞）、肛门灼热、胸脘烦热、口干作渴、喘而汗出、舌红苔黄、脉数。
- **方解**：重用葛根为君，解肌发表、升发脾胃清阳而止利（"逆流挽舟"之意）；黄芩、黄连为臣，苦寒清热、燥湿止利；甘草为使，和中调药。
- **现代应用**：急性胃肠炎、细菌性痢疾、肠伤寒、放射性肠炎等属里热下利者。

### 2.4.4 茵陈蒿汤（《伤寒论》）——清热利湿退黄
- **组成**：茵陈18g，栀子9g，大黄6g。
- **功用**：清热利湿退黄。
- **主治**：湿热黄疸（阳黄）：一身面目俱黄、黄色鲜明如橘子色、腹微满、口中渴、小便短赤、舌苔黄腻、脉沉数。
- **方解**：茵陈为君，清热利湿、疏利肝胆、退黄要药；栀子为臣，清泄三焦湿热使从小便出；大黄为佐，泻热逐瘀、通利大便，使湿热从二便分消。
- **现代应用**：急性黄疸型肝炎、胆囊炎、胆石症、新生儿溶血性黄疸等湿热发黄者。

### 2.4.5 养阴清肺汤（《重楼玉钥》）——白喉专方
- **组成**：生地6g，麦冬4.5g，玄参4.5g，贝母2.4g，丹皮2.4g，炒白芍2.4g，薄荷1.5g，生甘草1.5g。
- **功用**：养阴清肺，解毒利咽。
- **主治**：阴虚燥热之白喉：喉间起白如腐、不易拭去、咽喉肿痛、鼻干唇燥、脉数。
- **方解**：生地为君，滋阴清热；麦冬、玄参为臣，养阴清热解毒利咽；丹皮、芍药清热凉血和营，贝母润肺化痰散结，薄荷宣肺利咽为佐；甘草为使，泻火解毒、调和诸药。
- **现代应用**：急性扁桃体炎、咽炎、白喉恢复期、口腔溃疡属阴虚燥热者。中成药：养阴清肺丸/口服液。

### 2.4.6 导赤散（简）——《小儿药证直诀》
- **组成**：生地黄、木通（现多通草代）、生甘草梢、竹叶。
- **功用**：清心利水养阴。主治心经火热证：心胸烦热、口渴面赤、口舌生疮、小便赤涩刺痛。
- **方解**：生地清热凉血滋阴为君；木通上清心经之热、下利小肠为臣；竹叶清心除烦为佐；甘草梢清热解毒并引药直达茎中为使。

## 2.5 温里剂

### 2.5.1 ★理中丸（《伤寒论》）——温中祛寒基础方
- **组成**：人参9g，干姜9g，炙甘草9g，白术9g（等分，丸剂或汤剂）。
- **功用**：温中祛寒，补气健脾。
- **主治**：①脾胃虚寒证：脘腹绵绵作痛、喜温喜按、呕吐便溏、脘痞食少、畏寒肢冷、口不渴、舌淡苔白润、脉沉细或沉迟无力；②阳虚失血；③小儿慢惊、病后喜唾涎沫、胸痹属中焦虚寒者。
- **方解**：干姜为君，温中散寒、扶阳抑阴；人参为臣，大补元气、健脾益胃（**温中补气并行**）；白术为佐，健脾燥湿；炙甘草为使，益气和中、调和诸药。
- **加减**：阳虚重加附子＝附子理中丸（中成药）；寒甚者重用干姜；兼呕吐者生姜汁半夏；下利用白术改为土炒。
- **现代应用**：慢性胃炎、消化性溃疡、慢性肠炎、功能性消化不良属脾胃虚寒者。中成药：理中丸、附子理中丸、桂附理中丸。

### 2.5.2 ★小建中汤（《伤寒论》）——温中补虚、和里缓急
- **组成**：桂枝9g，芍药18g（倍用），炙甘草6g，生姜9g，大枣4枚，饴糖30g（烊化）。
- **功用**：温中补虚，和里缓急。
- **主治**：中焦虚寒、肝脾不和之**虚劳里急**：腹中拘急疼痛、喜温喜按、神疲乏力、虚怯少气；或心中悸动、虚烦不宁、面色无华；伴四肢酸楚、手足烦热、咽干口燥。
- **方解**：饴糖为君，温中补虚、缓急止痛（重用甘温建中）；桂枝温阳气为臣，芍药益阴血、缓急止痛为臣（桂芍2:1，重在酸甘化阴缓急）；生姜、大枣为佐，温胃健脾、调和营卫；炙甘草为使，益气和中、调和诸药（与饴糖、芍药成"甘温除热"酸甘化阴之基）。
- **衍生方**：黄芪建中汤（加黄芪，气虚甚）、当归建中汤（加当归，血虚甚）。
- **现代应用**：消化性溃疡、慢性胃炎、肠易激综合征、再障、功能性发热等属中焦虚寒者。
- **注意**：呕家不可用（甘能助呕）；中满者忌。

### 2.5.3 吴茱萸汤（《伤寒论》）——肝胃虚寒、浊阴上逆
- **组成**：吴茱萸9g，人参9g，生姜18g，大枣4枚。
- **功用**：温中补虚，降逆止呕。
- **主治**：肝胃虚寒，浊阴上逆：食谷欲呕、胸膈满闷、胃脘疼痛、**巅顶头痛**、干呕吐涎沫、畏寒肢冷、舌淡苔白滑、脉沉弦或迟。
- **方解**：吴茱萸为君，温胃暖肝、降逆止呕、止痛；生姜为臣，温胃散寒、降逆止呕（用量独重）；人参为佐，补脾益气以扶虚；大枣为佐使，甘缓和中、制约吴茱萸辛燥之性。
- **现代应用**：慢性胃炎、神经性呕吐、偏头痛（厥阴头痛）、耳源性眩晕属肝胃虚寒者。

### 2.5.4 当归四逆汤（《伤寒论》）——温经散寒、养血通脉
- **组成**：当归12g，桂枝9g，芍药9g，细辛3g，炙甘草6g，通草6g，大枣8枚。
- **功用**：温经散寒，养血通脉。
- **主治**：血虚寒厥证：手足厥寒、或局部青紫冷痛、舌淡苔白、脉沉细或细而欲绝；寒入经络之腰、股、腿、足疼痛；冻疮、痛经。
- **方解**：当归为君，补心血；桂枝、芍药为臣，温经通脉、养血和营；细辛、通草为佐，温经散寒、通利血脉；甘草、大枣为使，益气健脾、养血和药。
- **现代应用**：雷诺病、血栓闭塞性脉管炎、冻疮、颈椎病、痛经、冠心病心绞痛属血虚寒凝者。

### 2.5.5 阳和汤（《外科证治全生集》）——阴疽专方
- **组成**：熟地黄30g，鹿角胶9g（烊化），白芥子6g，肉桂3g，麻黄1.5g，姜炭1.5g，生甘草3g。
- **功用**：温阳补血，散寒通滞。
- **主治**：阴疽：漫肿无头、皮色不变、酸痛无热、口不渴、舌淡苔白、脉沉细或迟细（贴骨疽、脱疽、流注、痰核、鹤膝风等）。
- **方解**：熟地为君，温补营血、填精益髓；鹿角胶为臣，温肾助阳、益精养血（**血肉有情之品**）；肉桂、姜炭为佐，温阳散寒、通畅血脉；白芥子为佐，祛除皮里膜外之痰凝；**麻黄为佐，少量辛温达卫，开腠理以散寒凝**（与熟地相配，"熟地得麻黄则补而不滞，麻黄得熟地则散而不表"）；生甘草为使，解毒并调和诸药。
- **注意**：阳证疮疡红肿热痛者禁用；麻黄量宜小，勿令发汗。

## 2.6 补益剂

### 2.6.1 ★四君子汤（《太平惠民和剂局方》）——补气健脾基础方
- **组成**：人参9g（现多用党参），白术9g，茯苓9g，炙甘草6g。
- **功用**：益气健脾。
- **主治**：脾胃气虚证：面色萎白、语声低微、气短乏力、食少便溏、舌淡苔白、脉虚弱。
- **方解**：人参为君，大补元气、健脾养胃；白术为臣，健脾燥湿；茯苓为佐，渗湿健脾（与白术相配，脾健湿去）；炙甘草为使，益气和中、调和诸药。
- **地位**：补气基本方，"气虚证第一方"。衍生方：异功散（+陈皮）、六君子汤（+陈皮、半夏）、香砂六君子汤（+木香、砂仁）、八珍汤（合四物汤）、十全大补汤（八珍+黄芪、肉桂）。
- **现代应用**：慢性胃炎、消化性溃疡、慢性肠炎、病后体虚、放化疗后体虚等脾胃气虚者。中成药：四君子丸、六君子丸、香砂六君丸。

### 2.6.2 ★四物汤（《仙授理伤续断秘方》）——补血调血基础方
- **组成**：熟地黄12g，当归9g，白芍9g，川芎6g。
- **功用**：补血调血。
- **主治**：营血虚滞证：头晕心悸、面色无华、唇甲色淡、舌淡、脉细；妇人月经不调、经闭、痛经、胎前产后诸疾。
- **方解**：熟地为君，滋阴补血、填精益髓；当归为臣，补血活血（"补中有活"）；白芍为佐，养血柔肝、敛阴和营；川芎为佐，活血行气、调畅气血（**动静结合，补血而不滞血**）。
- **加减**：血虚有寒加肉桂、炮姜；血虚有热加黄芩、丹皮，熟地改生地；欲止血去川芎，加阿胶、艾叶；兼气虚合四君子为八珍汤。
- **注意**：湿盛中满、大便溏泄者慎用（熟地滋腻）。孕妇使用须医师指导。

### 2.6.3 ★八珍汤（《瑞竹堂经验方》/《正体类要》）——气血双补
- **组成**：人参9g，白术9g，茯苓9g，炙甘草6g，当归9g，川芎6g，白芍9g，熟地黄12g，加生姜3片、大枣3枚（即**四君子汤+四物汤**）。
- **功用**：益气补血。
- **主治**：气血两虚证：面色苍白或萎黄、头晕目眩、四肢倦怠、气短懒言、心悸怔忡、饮食减少、舌淡苔薄白、脉细弱或虚大无力；病后失调、久病失血、月经量少色淡。
- **方解**：四君子补气（气能生血），四物汤补血养血，君臣相合气血双补；姜枣调和脾胃为佐使。
- **衍生方**：十全大补汤（+黄芪、肉桂）、人参养荣汤、泰山磐石散（安胎）。
- **现代应用**：贫血、术后体虚、产后虚弱、月经不调属气血两虚者。中成药：八珍丸、八珍颗粒、十全大补丸。

### 2.6.4 ★六味地黄丸（地黄丸，《小儿药证直诀》）——滋阴补肾（十大名方）
- **组成**：熟地黄24g，山茱萸12g，山药12g，泽泻9g，牡丹皮9g，茯苓9g（"地八山山四，丹泽茯苓三"）。
- **功用**：滋阴补肾。
- **主治**：肾阴亏损证：腰膝酸软、头晕耳鸣、盗汗遗精、消渴、骨蒸潮热、手足心热、牙齿动摇、足跟作痛、小便淋沥、舌红少苔、脉沉细数。
- **方解（"三补三泻"，以补为主）**：
  - 三补：熟地为君，滋阴补肾、填精益髓；山茱萸为臣，补养肝肾、涩精；山药为臣，补益脾阴、固精（**三阴并补，以补肾阴为主**）。
  - 三泻：泽泻为佐，泄肾浊（防熟地之滋腻）；丹皮为佐，清泄肝火（制山茱萸之温涩）；茯苓为佐，渗脾湿（助山药之健运）。
  - 配伍特点：**补泻兼施、以补为主；壮水之主，以制阳光**（王冰语）。
- **衍生方**：知柏地黄丸（+知母、黄柏，阴虚火旺）、杞菊地黄丸（+枸杞、菊花，肝肾阴虚目暗）、麦味地黄丸（+麦冬、五味子，肺肾阴虚）、都气丸（+五味子，肾虚气喘）、耳聋左慈丸（+磁石等，耳鸣耳聋）。
- **现代应用**：慢性肾炎、高血压、糖尿病、更年期综合征、神经衰弱等属肾阴虚者。中成药：六味地黄丸（浓缩丸/水蜜丸/颗粒）。
- **注意**：脾虚便溏、消化不良者慎服（滋腻碍脾）；肾阳虚（畏寒肢冷、便溏）者不宜，当用肾气丸类。

### 2.6.5 ★肾气丸（金匮肾气丸，《金匮要略》）——补肾助阳（"千古补肾阳方之祖"）
- **组成**：干地黄24g，山药12g，山茱萸12g，泽泻9g，茯苓9g，牡丹皮9g，桂枝3g，附子3g（炮）。
- **功用**：补肾助阳（"微微生火，少火生气"）。
- **主治**：肾阳不足证：腰痛脚软、身半以下常有冷感、少腹拘急、小便不利或小便反多、入夜尤甚、阳痿早泄、舌淡而胖、脉虚弱、尺部沉细；痰饮、水肿、消渴、脚气、转胞属肾阳虚者。
- **方解**：附子、桂枝为君，温补肾阳、化气行水（用量很轻，**于大量滋阴药中少加温阳药，"阴中求阳，则阳得阴助而生化无穷"**）；地黄、山茱萸、山药为臣，三阴并补（补阴为基础）；泽泻、茯苓、丹皮为佐，渗湿泄浊、清肝泻火（补中寓泻）。
- **衍生方**：济生肾气丸（+牛膝、车前子，水肿明显）、《济生》肾气丸；十补丸。后世右归丸（去三泻加鹿角胶、菟丝子等，纯补无泻）。
- **现代应用**：慢性肾炎、前列腺增生、糖尿病、甲状腺功能减退、更年期综合征属肾阳虚者。中成药：金匮肾气丸（桂附地黄丸）、右归丸。
- **注意**：咽干口燥、舌红少苔之肾阴虚火旺者禁用；孕妇忌服。

### 2.6.6 ★补中益气汤（《脾胃论》李东垣）——益气升阳、甘温除热（十大名方）
- **组成**：黄芪18g，炙甘草9g，人参6g，当归3g，橘皮6g，升麻6g，柴胡6g，白术9g。
- **功用**：补中益气，升阳举陷。
- **主治**：①**脾胃气虚证**：饮食减少、体倦肢软、少气懒言、面色萎黄、大便稀溏、脉虚软；②**气虚下陷证**：脱肛、子宫脱垂、久泻久痢、崩漏（气不摄血）；③**气虚发热证**：身热自汗、渴喜热饮、气短乏力（"甘温除大热"）。
- **方解**：黄芪为君，补中益气、升阳固表；人参、白术、炙甘草为臣，大补脾肺之气（"参芪术草"甘温益气）；当归为佐，养血补虚（血为气之宅，使气有所附）；陈皮为佐，理气醒脾，使补而不滞；**升麻、柴胡为佐使，升举下陷之清阳**（用量宜轻，引清气上行）。

- **主治**：**胸痹**（胸阳不振、痰气互结）：胸部隐痛、甚至胸痛彻背、喘息咳唾、短气、苔白腻、脉沉弦或紧。
- **方解**：瓜蒌为君，理气宽胸、涤痰散结（"荡涤胸中痰垢"）；薤白为臣，温通胸阳、散结下气；白酒为佐使，辛散温通、行气活血、轻扬上行（助药力直达病所）。

- **现代应用**：冠心病心绞痛、肋间神经痛、慢性支气管炎等属胸阳不振痰阻者。**突发持续胸痛须先排除心梗，立即就医**。

### 2.10.3 半夏厚朴汤（简）——《金匮要略》

## 2.11 理血剂

### 2.11.1 ★血府逐瘀汤（《医林改错》王清任）——活血化瘀第一方（十大名方）
- **组成**：桃仁12g，红花9g，当归9g，生地黄9g，川芎4.5g，赤芍6g，牛膝9g，桔梗4.5g，柴胡3g，枳壳6g，甘草6g。
- **功用**：活血化瘀，行气止痛。
- **主治**：**胸中血瘀证**：胸痛、头痛日久不愈、痛如针刺而有定处、呃逆日久不止、饮水即呛、干呕、内热瞀闷、心悸怔忡、失眠多梦、急躁易怒、入暮潮热、唇暗或两目暗黑、舌质暗红或有瘀斑瘀点、脉涩或弦紧。
- **方解**：桃仁为君，破血行滞润燥；红花、赤芍、川芎为臣，活血祛瘀；牛膝为佐，活血通经、**引血下行**；生地、当归为佐，养血活血（祛瘀而不伤正，"血化下行不作劳"）；柴胡、枳壳、桔梗为佐，**一升一降、宽胸行气**（气行则血行）；甘草为使，调和诸药、缓急止痛。
- **配伍特点**：活血与行气相伍（气血并治）；祛瘀与养血同施（活而不伤）；升降兼顾。
- **同族方**：通窍活血汤（头面瘀血）、膈下逐瘀汤（腹中瘀血）、少腹逐瘀汤（少腹瘀血、痛经）、身痛逐瘀汤（肢体痹痛）。
- **现代应用**：冠心病心绞痛、心肌梗死后、脑外伤后遗症、头痛、失眠、高脂血症、黄褐斑等属血瘀气滞者。中成药：血府逐瘀胶囊/口服液。
- **注意**：孕妇禁用；出血性疾病、月经过多者慎用。

### 2.11.2 ★补阳还五汤（《医林改错》）——补气活血通络（中风后遗症）
- **组成**：生黄芪120g（重用），当归尾6g，赤芍5g，地龙3g，川芎3g，红花3g，桃仁3g。
- **功用**：补气，活血，通络。
- **主治**：**气虚血瘀之中风**（"因虚致瘀"）：半身不遂、口眼㖞斜、语言謇涩、口角流涎、小便频数或遗尿不禁、患侧肢体萎软无力、苔白、脉缓。
- **方解**：重用生黄芪为君（4-8倍于活血药总量），大补脾胃之元气，使气旺以促血行（"气行则血行"，祛瘀而不伤正）；当归尾为臣，活血通络而不伤血；川芎、赤芍、桃仁、红花为佐，助当归活血祛瘀；地龙为佐，**通经活络、性善走窜**，周行全身以行药力。
- **现代应用**：脑梗死恢复期及后遗症、脑出血恢复期（须病情稳定后）、冠心病、坐骨神经痛等气虚血瘀者。中成药：消栓通络片、脑安胶囊等循此法。
- **注意**：中风初起、痰热壅盛、肝阳上亢（面赤脉弦有力）者禁用（防再出血）；须医师辨证后使用；黄芪量遵医嘱渐增。

### 2.11.3 生化汤（《傅青主女科》）——产后化瘀生新
- **组成**：全当归24g（重用），川芎9g，桃仁6g，炮姜2g，炙甘草2g（原方加黄酒、童便同煎，现代多去童便）。
- **功用**：养血祛瘀，温经止痛。
- **主治**：产后恶露不行、小腹冷痛（血虚寒凝、瘀血内停）。
- **方解**：重用当归为君，补血活血、化瘀生新；川芎、桃仁为臣，活血行气祛瘀；炮姜为佐，温经散寒止痛；黄酒温通血脉为佐；炙甘草为使，和中缓急。全方"化瘀生新"故名"生化"。
- **注意**：**须在产后恶露确属血虚寒凝血瘀时使用；恶露过多、有出血倾向、产褥感染（发热恶露臭秽）者禁用**；孕妇禁用。中成药：新生化颗粒（须遵医嘱）。

### 2.11.4 桂枝茯苓丸（《金匮要略》）——活血化瘀、缓消癥块
- **组成**：桂枝、茯苓、丹皮、桃仁、芍药各等分（炼蜜为丸，原方"兔屎大，每日食前一丸"；现代亦作汤剂）。
- **功用**：活血化瘀，缓消癥块。
- **主治**：瘀阻胞宫证：妊娠胎动不安、漏下不止、血色紫黑晦暗、腹痛拒按；或经闭、痛经、癥块（子宫肌瘤、卵巢囊肿、子宫内膜异位症等属瘀血内阻者）。
- **方解**：桂枝为君，温通血脉、以行瘀滞；桃仁为臣，活血破瘀、消癥；丹皮、芍药为佐，活血散瘀、清热退蒸（兼清瘀久所化之热）；茯苓为佐，渗湿健脾、消痰利水、安正气；炼蜜为丸，**缓消癥块、祛邪而不伤胎**（原为"有故无殒"之法，现多用于非孕期）。
- **现代应用**：子宫肌瘤、卵巢囊肿、盆腔炎、子宫内膜异位症、痛经等瘀阻胞宫者。中成药：桂枝茯苓丸/胶囊。孕妇使用必须严格遵医嘱。

### 2.11.5 小蓟饮子（《济生方》录自《玉机微义》）——凉血止血、利水通淋
- **组成**：生地黄30g，小蓟15g，滑石15g，木通6g（现多通草代），炒蒲黄9g，藕节9g，淡竹叶9g，当归6g，栀子9g，炙甘草6g。
- **功用**：凉血止血，利水通淋。
- **主治**：**热结下焦之血淋、尿血**：小便频数、赤涩热痛、尿中带血、舌红、脉数。
- **方解**：小蓟为君，凉血止血；生地黄为臣，凉血止血、养阴清热；蒲黄、藕节为佐，止血消瘀（止血不留瘀）；滑石、木通、淡竹叶、栀子为佐，清热利水通淋（导热下行）；当归为佐，养血活血（防诸药寒凉滞血）；甘草为使，缓急止痛、调和诸药。

### 2.11.6 黄土汤（《金匮要略》）——温阳健脾、养血止血
- **组成**：灶心黄土（伏龙肝）30g（煎汤代水），甘草9g，生地黄9g，白术9g，炮附子9g，阿胶9g（烊化），黄芩9g。
- **功用**：温阳健脾，养血止血。
- **主治**：**脾阳不足、脾不统血证**（阳虚便血）：大便下血、先便后血（远血）、或吐血、衄血、妇人崩漏、血色暗淡、四肢不温、面色萎黄、舌淡苔白、脉沉细无力。
- **方解**：灶心黄土为君，温中收涩止血；白术、附子为臣，温阳健脾（脾统血，复其统摄之权）；生地、阿胶为佐，滋阴养血止血（**制约术附温燥**）；黄芩为佐，苦寒止血坚阴（**反佐**，防温燥动血）；甘草为使，益气和中、调诸药。
- **配伍特点**：寒热并用（温阳而不伤阴血，滋阴而不碍脾阳）、标本兼顾。
- **现代应用**：消化道出血（须先就医明确诊断）、慢性再生障碍性贫血、功能性子宫出血属脾阳虚者。

### 2.11.7 十灰散、咳血方、槐花散（简）
- **十灰散**（《十药神书》）：大蓟、小蓟、荷叶、侧柏叶、白茅根、茜根、栀子、大黄、牡丹皮、棕榈皮各等分烧炭。凉血止血，治上部（血热妄行之呕血、吐血、咯血、嗽血）临时应急止血之用。
- **咳血方**（《丹溪心法》）：青黛、瓜蒌仁、海粉、山栀、诃子。清肝宁肺，凉血止血，治肝火犯肺之咳痰带血。
- **槐花散**（《普济本事方》）：炒槐花、侧柏叶、荆芥穗、枳壳。清肠止血，疏风行气，治肠风脏毒下血（便血）。

- **方解**：天麻、钩藤为君，平肝息风；石决明为臣，平肝潜阳、除热明目；栀子、黄芩为佐，清肝泻火；川牛膝为佐，引血下行（助平肝潜阳）；益母草活血利水；杜仲、桑寄生为佐，补益肝肾；夜交藤、朱茯神为佐，安神定志。

### 2.12.2 羚角钩藤汤（《通俗伤寒论》）——凉肝息风、增液舒筋

- **功用**：凉肝息风，增液舒筋。
- **主治**：**肝热生风证**（热极动风）：高热不退、烦闷躁扰、手足抽搐、甚至神昏、痉厥、舌绛而干、脉弦数。
- **方解**：羚羊角、钩藤为君，凉肝息风、清热解痉；桑叶、菊花为臣，清热平肝；鲜生地、白芍为佐，养阴增液、柔肝舒筋；川贝、竹茹为佐，清热化痰；茯神木为佐，宁心安神；甘草为使，调和诸药（与白芍相配酸甘化阴、缓急止痉）。
- **现代应用**：高热惊厥、乙脑、流脑、高血压危象属热盛动风者（急重证，须急救入院）。

### 2.12.3 镇肝熄风汤（《医学衷中参西录》）——镇肝息风、滋阴潜阳
- **组成**：怀牛膝30g，生赭石30g（先煎），生龙骨15g（先煎），生牡蛎15g（先煎），生龟板15g（先煎），生白芍15g，玄参15g，天冬15g，川楝子6g，生麦芽6g，茵陈6g，甘草4.5g。
- **功用**：镇肝息风，滋阴潜阳。
- **主治**：**类中风（肝阳上亢、气血逆乱）**：头目眩晕、目胀耳鸣、脑部热痛、心中烦热、面色如醉；或肢体渐觉不利、口角渐形㖞斜；甚至眩晕颠仆、昏不知人、移时始醒（中风先兆与中风急性期）；脉弦长有力。
- **方解**：怀牛膝为君，引血下行、补益肝肾（"治标"）；生赭石、生龙骨、生牡蛎为臣，镇肝降逆、潜阳息风；龟板、白芍、玄参、天冬为佐，滋阴潜阳（"治本"，滋水涵木）；川楝子、生麦芽、茵陈为佐，**清泄肝阳之有余、条达肝气之郁滞**（配合金石潜镇，顺肝木之性使其不反激）；甘草为使，调和诸药、护胃安中。
- **与天麻钩藤饮鉴别**：镇肝熄风汤潜镇力峻，用于**阳亢气血逆乱之类中风**；天麻钩藤饮清热安神力胜，用于**肝阳上亢之高血压眩晕头痛**。

### 2.12.4 大定风珠（《温病条辨》）——滋阴息风
- **组成**：生白芍18g，阿胶9g（烊化），生龟板12g，干地黄18g，麻仁6g，五味子6g，生牡蛎12g，麦冬18g，炙甘草12g，鸡子黄2枚（冲），鳖甲12g。
- **功用**：滋阴息风。
- **主治**：**阴虚风动证**：温病后期、真阴大亏、手足瘛疭（蠕动抽搐）、形消神倦、舌绛少苔、脉气虚弱、有时时欲脱之势。
- **方解**：鸡子黄、阿胶为君，滋阴养血、息风（血肉有情之品，填补真阴）；白芍、地黄、麦冬为臣，滋阴柔肝；龟板、鳖甲、牡蛎为佐，滋阴潜阳、重镇息风；麻仁养阴润燥，五味子酸收、收敛真阴为佐；炙甘草为使，益气和中（与白芍酸甘化阴）。

### 2.12.5 独活寄生汤（《备急千金要方》）——祛风湿、止痹痛、益肝肾、补气血
- **组成**：独活9g，桑寄生、杜仲、牛膝、细辛、秦艽、茯苓、肉桂心、防风、川芎、人参、甘草、当归、芍药、干地黄各6g。
- **功用**：祛风湿，止痹痛，益肝肾，补气血。
- **主治**：**痹证日久、肝肾两虚、气血不足证**：腰膝疼痛、痿软无力、肢节屈伸不利、或麻木不仁、畏寒喜温、心悸气短、舌淡苔白、脉细弱。
- **方解**：独活为君，祛下焦与筋骨间之风寒湿邪；细辛、防风、秦艽为臣，祛风散寒胜湿、舒筋止痛；桑寄生、杜仲、牛膝为佐，补益肝肾、强筋壮骨（牛膝兼引血下行）；四物（地、芍、归、芎）养血活血为佐（"治风先治血，血行风自灭"）；四君子去白术（参、苓、草）益气健脾为佐；肉桂心温经通脉为佐；甘草为使调和诸药。

### 2.15.4 贝母瓜蒌散（简）——《医学心悟》
- **组成**：贝母、瓜蒌、花粉、茯苓、橘红、桔梗。
- **功用**：润肺清热，理气化痰。主治**燥痰咳嗽**：咳嗽有痰、咯痰不爽、涩而难出、咽喉干燥哽痛、苔白而干。
- **方解**：贝母为君，清热润肺、化痰止咳（川贝母润；瓜蒌为臣清热涤痰宽胸；花粉生津润燥；茯苓健脾渗湿；橘红理气化痰；桔梗宣肺利咽，为诸药舟楫。

## 2.16 消食剂

### 2.16.1 ★保和丸（《丹溪心法》）——消食和胃（食积第一方）
- **组成**：山楂18g（焦），神曲6g，半夏9g，茯苓9g，陈皮3g，连翘3g，莱菔子3g。
- **功用**：消食和胃。
- **主治**：**食积停滞**：脘腹痞满胀痛、嗳腐吞酸、恶食呕逆、或大便不调、舌苔厚腻、脉滑。
- **方解**：重用山楂为君，消一切饮食积滞（尤善消**肉食油腻**之积）；神曲为臣，消食健脾（化酒食陈腐之积）；莱菔子为臣，下气消食导滞（消**面食痰浊**之积）；半夏、陈皮为佐，理气化湿、和胃止呕；茯苓为佐，健脾利湿（"食消则脾胃自和"）；连翘为佐，清解食积所生之热（**散结清热，防食积化热**）。
- **配伍特点**：消食化积与理气化湿清热并施，纯消无补，**消食剂平和之方**。
- **衍生方**：大安丸（保和丸+白术，消中兼补）；枳实导滞丸（食积湿热重，大黄、枳实、黄芩、黄连等）。
- **现代应用**：消化不良、急性胃肠炎恢复期、小儿食积。中成药：保和丸（颗粒/口服液）、大山楂丸（重山楂、神曲、麦芽，药力更平和）。

### 2.16.2 健脾丸（《证治准绳》）——健脾和胃、消食止泻（消补兼施）
- **组成**：炒白术75g，木香22g，炒黄连22g，甘草22g，白茯苓60g，人参45g，炒神曲30g，陈皮30g，砂仁30g，炒麦芽30g，山楂30g，山药30g，肉豆蔻30g（糊丸，比例制丸；汤剂按比例折减）。
- **功用**：健脾和胃，消食止泻。
- **主治**：**脾虚食积证**：食少难消、脘腹痞闷、大便溏薄、倦怠乏力、苔腻微黄、脉虚弱。
- **方解**：人参、白术、茯苓（四君子意）为君，益气健脾（**补为主**）；山药、肉豆蔻为臣，健脾止泻；山楂、神曲、麦芽为臣，消食化滞；木香、砂仁、陈皮为佐，理气醒脾（补而不滞）；黄连为佐，清热燥湿（清食积所化之热，并制诸药之温）；甘草为使，补脾和中。
- **与保和丸鉴别**：保和丸**纯消无补**（食积实证）；健脾丸**消补兼施、补重于消**（脾虚为主之食积）。
- **现代应用**：慢性消化不良、慢性肠炎、病后体弱食少。中成药：健脾丸、人参健脾丸、启脾丸。

## 2.17 驱虫与寒热并用剂

### 2.17.1 乌梅丸（《伤寒论》）——温脏安蛔、寒热并调（厥阴病主方）
- **组成**：乌梅300枚（重用），细辛84g，干姜140g，黄连224g，当归56g，炮附子84g，蜀椒56g，桂枝84g，人参84g，黄柏84g（醋渍乌梅、蒸之米下，捣泥和药、蜜丸）。
- **功用**：温脏安蛔（现多表述为"寒热并调、攻补兼施"）。
- **主治**：①**蛔厥证**：腹痛时作、烦闷呕吐、常自吐蛔、手足厥冷；②**久痢（寒热错杂之泻痢）**：腹痛腹泻、大便带黏液、久而不愈。
- **方解**：重用乌梅为君，酸收敛肝、涩肠止泻、安蛔（"蛔得酸则静"）；蜀椒、细辛为臣，温脏祛寒、杀虫（"蛔得辛则伏"）；黄连、黄柏为臣，苦寒清热下蛔（"蛔得苦则下"）；附子、干姜、桂枝为佐，温脏祛寒（辛温助阳）；人参、当归为佐，补气养血（**扶正以祛邪**）。全方**酸苦辛并投、寒热并用、攻补兼施**，为厥阴病寒热错杂证主方。
- **现代应用**：胆道蛔虫症、慢性结肠炎、肠道易激综合征、慢性痢疾等寒热错杂、正气虚弱者。中成药：乌梅丸。孕妇慎用（含附子等温燥之品）。

# 三、家庭常备中成药（OTC，AI咨询高频）

> **总原则**：
> 1. 中成药必须**辨证选用**：先分寒热虚实，再选药；用错方向（如风热证误用辛温药）不仅无效，还会**加重病情**。
> 2. 服前阅读说明书，注意禁忌证、不良反应。
> 3. 一般服用3天症状无缓解，或出现高热不退、剧烈腹痛、胸痛、呼吸困难、意识改变等，**立即就医**。
> 4. 儿童、孕妇、哺乳期、老人、肝肾功能不全者用药前须咨询医师或药师。
> 5. 不建议同时服用多种功效相近的中成药；与西药同服一般间隔30分钟以上。
> 6. 服药期间忌烟酒及辛辣、生冷、油腻食物。

# 五、AI开方建议的辨证逻辑与安全红线（知识库使用规范）

## 5.1 辨证用方三步逻辑（AI推理链）
1. **辨表里寒热虚实**（八纲）→ 如：感冒先分风寒/风热/暑湿/气虚。
2. **定证型**（脏腑气血津液辨证）→ 如：失眠分肝郁化火、心脾两虚、阴虚火旺、痰热扰心、心胆气虚。
3. **方证对应选方**（查第四章速查表）→ 如：心脾两虚失眠→归脾丸；痰热扰心失眠→黄连温胆汤。

## 5.2 安全红线（AI必须输出的提示）
1. 所有方剂与中成药建议均须附"**请在执业中医师/药师指导下使用**"提示。
2. 急重症（持续胸痛、高热抽搐、昏迷、剧烈腹痛、大出血、呼吸困难）→ **首先建议立即就医/拨打120**，不做方剂推荐。
3. 特殊人群（孕妇、哺乳期、婴幼儿、老人、肝肾功能不全者）用药 → 一律建议就医，不做直接推荐。
4. 含毒剧药材方剂（附子、乌头、罂粟壳、朱砂、雄黄、马钱子、藜芦等）→ 强调医师处方权与煎服法，标注中毒风险。
5. 药物相互作用警示（藿香正气水+头孢；中药与抗凝药、降压药联用等）→ 主动提示。
6. 误用后果示例库：风寒误用寒凉→表邪冰遏、咳嗽迁延；风热误用辛温→咽痛发热加重；脾胃虚寒误用苦寒→泄泻纳差加重；肾阴虚误用温阳→口疮失眠烦躁。
7. 疗程提示：中病即止（解表剂汗出热退即停）；补益剂感冒期停用；安神含朱砂剂不宜连续长期使用。

## 5.3 高频问诊-方剂映射示例（供AI意图识别训练）
- "吹空调受凉了，上吐下泻" → 藿香正气类（外寒内湿）。
- "喉咙痛、流黄鼻涕、发热重" → 银翘解毒片/双黄连（风热）。
- "怕冷、清水鼻涕、浑身酸痛" → 风寒感冒颗粒/感冒清热颗粒（风寒）。
- "一到半夜两三点就醒，烦躁口苦" → 丹栀逍遥/温胆类（肝郁化火/痰热）。
- "吃点凉的就拉肚子" → 附子理中丸（脾胃虚寒）。
- "吃了大餐后腹胀嗳酸" → 保和丸（食积）。
- "一到傍晚就手心脚心热、盗汗、腰酸" → 六味地黄丸（肾阴虚）。
- "气短乏力、经常感冒出汗" → 玉屏风颗粒（表虚不固，缓解期调理）。
- "心情不好就胃胀、月经前胸胀" → 逍遥丸（肝郁脾虚）。
- "头蒙如裹、恶心、天旋地转" → 半夏白术天麻汤证（风痰眩晕，就医确诊）。
