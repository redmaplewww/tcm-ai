# 一、腧穴学基础

## 1.1 腧穴的概念与分类

腧穴是人体脏腑经络之气输注于体表的特殊部位，既是疾病的反应点（按压、探查可出现压痛、结节、条索、皮肤温度/电阻变化），也是针灸、推拿等外治法的刺激点。

**三大分类：**

| 类别 | 定义 | 特点 | 举例 |
|---|---|---|---|
| **经穴（十四经穴）** | 分布于十二正经与任脉、督脉（合称十四经）上的腧穴 | 有固定名称、固定定位和明确主治；是腧穴的主体。现行国家标准（GB/T 12346）共收录经穴 362 个（2006 版为 361，2021 版将印堂归入督脉后为 362） | 合谷、足三里、百会 |
| **奇穴（经外奇穴）** | 不属于十四经系统、但有固定名称与定位的经验效穴 | 多数对某些病症有特殊疗效 | 太阳、安眠、四神聪、十宣、八邪、八风、胆囊穴、阑尾穴、定喘、夹脊、子宫穴、腰眼 |
| **阿是穴** | 既无固定名称，亦无固定定位，以压痛点或其他病理反应点作为穴位 | "以痛为腧"（源于《千金要方》"阿是之法"）；多用于筋伤病、痛证 | 落枕、扭伤时的局部压痛点 |

## 1.2 腧穴的作用与主治规律

**腧穴的三大基本作用：**
1. **近治作用**：所有腧穴均可治疗其所在部位及邻近组织器官的病症（如睛明治目疾、中脘治胃病）。
2. **远治作用**：十四经穴尤其是四肢部（肘膝以下）腧穴，可治疗本经循行所过处及所属脏腑的远隔部位病症（如合谷治头面病——"面口合谷收"，足三里治胃脘痛）。
3. **特殊作用**：某些穴有双向良性调节（内关既治心动过速又治心动过缓；天枢既止泻又通便）与相对特异性主治（至阴矫正胎位、大椎退热、人中急救）。

**分经主治规律：**
- 手三阴经：胸病——肺经治肺、喉（咳喘、咽喉痛）；心包经治心、胃（心痛、心悸、呕逆）；心经治心、神（心痛、失眠、癫狂）。
- 手三阳经：头面五官病、热病——大肠经治头面（齿痛、鼻病）；三焦经治侧头、耳、胁肋；小肠经治头项、耳病（项强、耳聋）。
- 足三阳经：头面五官病、神志病、热病——胃经治前头、口齿、胃肠；胆经治侧头、耳、肝胆病；膀胱经治后头、项背腰、脏腑（背俞穴）。
- 足三阴经：胸腹（脏腑）病、妇科病、前阴病。
- 任脉：回阳、固脱、强壮（多治局部及脏腑虚寒）；督脉：中风、昏迷、热病、头面病（"督脉为病，脊强反折"）。

**分部主治规律：**
- 头面颈项部：神志病、五官病、热病。
- 胸腹背腰部（脏腑俞募）：相应脏腑病。
- 四肢部（肘膝以下五输、原络郄穴）：本经脏腑病、远隔部位病、急性病、全身性病症。

## 1.3 特定穴

特定穴是十四经穴中具有特殊治疗作用、冠以特定称号的一类腧穴，共十类（五输、原、络、郄、背俞、募、下合、八会、八脉交会、交会）。

### 1.3.1 五输穴（井、荥、输、经、合）

十二经在四肢肘膝以下各有井、荥、输、经、合五个特定穴，按经气由小到大、由浅入深排列："所出为井，所溜为荥，所注为输，所行为经，所入为合"。
- **主治规律（难经）**："井主心下满，荥主身热，输主体重节痛，经主喘咳寒热，合主逆气而泄。"临床概而言之：**井穴多用于急救、热证、神志病（点刺出血）；荥穴用于热证；输穴用于关节痛、湿病；经穴用于咳喘寒热；合穴用于脏腑病（六腑下合穴尤著）**。
- 五行属性：阴经"井木、荥火、输土、经金、合水"；阳经"井金、荥水、输木、经火、合土"。据此衍生补母泻子法（如肺虚补其母穴太渊，肺实泻其子穴尺泽）。

| 类别 | 概念与用途 | 内容 |
|---|---|---|

## 1.4 腧穴定位方法

### 1.4.1 骨度分寸法（"度"为等分，男女老幼通用）

以患者本人的骨节标志作为主要标志，将人体各部折量为若干等份（寸），是腧穴定位的基础方法。

| 部位 | 起止点 | 折量寸 |
|---|---|---|
| 头部 | 前发际正中至后发际正中 | **12寸** |
| 头部 | 眉间（印堂）至前发际正中 | 3寸 |
| 头部 | 第7颈椎棘突下（大椎）至后发际正中 | 3寸 |
| 头部 | 前额两发角（头维）之间 | 9寸 |
| 头部 | 耳后两乳突（完骨）之间 | 9寸 |
| 胸腹 | 胸剑联合中点（歧骨）至脐中 | **8寸** |
| 胸腹 | 脐中至耻骨联合上缘（曲骨） | **5寸** |
| 胸腹 | 两乳头之间 | 8寸（女性可用锁骨中线替代） |
| 胸腹 | 天突至歧骨（胸剑联合） | 9寸 |
| 背腰 | 肩胛骨内缘（近脊柱侧点）至后正中线 | 3寸 |
| 背腰 | 肩峰缘至后正中线 | 8寸 |
| 上肢 | 腋前、后纹头至肘横纹（平肘尖） | 9寸 |
| 上肢 | 肘横纹至腕掌侧远端横纹 | **12寸** |
| 下肢 | 耻骨联合上缘至股骨内上髁上缘 | 18寸 |
| 下肢 | 胫骨内侧髁下方（阴陵泉）至内踝尖 | **13寸** |
| 下肢 | 股骨大转子至腘横纹 | 19寸 |
| 下肢 | 腘横纹至外踝尖 | **16寸** |
| 下肢 | 外踝尖至足底 | 3寸 |

> 定背腰部腧穴以椎骨棘突计数：低头颈部最高棘突为 C7（大椎）；两肩胛下角平 T7；两髂嵴最高点连线平 L4（腰阳关约平 L4 棘突下）；两季肋（第12肋游离端）约平 L2-L3。本知识库中背俞穴标注如"肺俞（T3）"即平第3胸椎棘突下旁开1.5寸。

### 1.4.2 手指同身寸法（以患者本人手指为标准）

| 名称 | 标准 | 适用 |
|---|---|---|
| **中指同身寸** | 屈指，中指中节桡侧两端纹头之间为 1 寸 | 四肢部直寸、背部横寸 |
| **拇指同身寸** | 拇指指间关节的宽度为 1 寸 | 四肢部直寸 |
| **横指同身寸（一夫法）** | 食、中、无名、小指四指并拢，以中指近端指间关节横纹水平的四指宽度为 **3 寸** | 下肢、下腹部直寸及背部横寸 |

> 注意：同身寸仅是粗估，实际定位须以骨性/肌性解剖标志与骨度分寸为准；儿童、肥胖或消瘦者差异大，针刺前须触诊核实。

### 1.4.3 简便定位举例

- 列缺：两手虎口交叉，食指尖所指桡骨茎突上方凹陷处。
- 风市：直立垂手，中指尖所指大腿外侧处。
- 百会：两耳尖连线与头正中线交点。

# 二、常用穴位详解

> **【孕妇禁忌穴——醒目标注】** 孕妇**禁针或慎针**的常用穴：**合谷、三阴交、肩井、昆仑、至阴、缺盆**及腰骶部、小腹部诸穴（关元、气海、中极、曲骨、子宫穴、八髎、秩边、腰阳关等）。其中至阴、昆仑在常规妇产科操作中用于**矫正胎位（至阴艾灸，须在医师指导下进行）与催产（禁用于保胎者）**，机制为兴奋子宫平滑肌——故妊娠期一般状态下属禁忌，切勿作为普通治疗穴使用。妊娠 3 个月以内者下腹、腰骶部禁针；3 个月以上者上腹部亦不宜针刺。
>
> **【禁灸穴概念】** 古籍记载禁灸穴（如哑门、风府、人迎、睛明、丝竹空、承泣等头面五官部及邻近动脉处）源于直接灸（瘢痕灸）易造成损伤、影响功能与容貌。现代临床以温和灸为主，传统"禁灸"已部分放宽，但**颜面部、五官区域、大血管走行处、黏膜处、妊娠期腰骶小腹部仍不宜直接灸或强刺激灸**。
>
> **【深刺危险区——总警示】** 胸、背、项、缺盆部穴位（风池、风府、哑门、肩井、天突、胸背部俞穴、期门、日月等）针刺过深可致**气胸、延髓损伤、脏器损伤**，必须由执业医师按标准方向与深度操作；不明穴、危穴不得自行针刺。

# 三、针刺法

> **总警示：以下全部操作须由执业针灸医师进行。AI 系统仅可输出知识层面内容与安全提示，不得输出可被非专业人员直接执行的深部、危险部位针刺指令。**

## 3.1 毫针刺法

### 3.1.1 针前准备
- 针具：一次性无菌毫针（0.16~0.38mm×13~125mm，临床常用直径0.30mm、长40mm），检查针尖（有无钩毛）、针身（有无锈蚀弯曲）、针柄。
- 体位：尽量卧位，防止晕针与断针后活动；暴露刺激部位，使患者肌肉放松、体位持久稳定。
- 消毒：穴位皮肤（75%乙醇/碘伏）、医者手指、针具一次性使用。
- 核对：**妊娠？出血性疾病？安装心脏起搏器/心律失常（电针）？晕针史？进食与疲劳状态？**任一阳性须调整方案或暂停。

### 3.1.2 进针法（单手与双手进针，双手配法四种）

| 方法 | 操作 | 适用部位 |
|---|---|---|
| **指切进针法（爪切法）** | 左手拇指或食指指甲切压穴位旁，右手持针紧靠指甲缘刺入 | **短针**，四肢及痛点 |
| **夹持进针法** | 左手拇、食指夹消毒干棉球裹针身下端，针尖露出1~2分，右手捻动针柄，双手配合刺入 | **长针**，腰臀丰厚处（环跳、秩边） |
| **舒张进针法** | 左手拇、食指撑开穴位处皮肤使其绷紧，右手刺入 | **皮肤松弛处**，腹部（天枢、关元） |
| **提捏进针法** | 左手拇、食指将穴位处皮肤捏起，右手从捏起处刺入 | **皮肉浅薄处**，印堂、地仓、攒竹 |

### 3.1.3 针刺角度与深度

| 角度 | 定义 | 适用 |
|---|---|---|
| 直刺 | 针身与皮肤呈90° | 大部分肌肉丰厚处（四肢、腹部、腰部） |
| 斜刺 | 呈45°左右 | 肌肉较薄处或内有重要脏器处（**背部俞穴、肋间穴位如期门、日月——防气胸**） |
| 平刺（横刺、沿皮刺） | 呈15°~25° | 皮肉浅薄处（头部百会、四神聪、印堂、透穴） |

深度原则：年老体弱、小儿、形瘦、阳证新病宜浅刺；青壮年、形盛、阴证久病可适当深刺；头面胸背及四肢末端宜浅，臀股肌肉丰厚处可深。**凡危险区（胸背、项部、眼区、颈前）一律按上表规范深浅，宁浅勿深。**

### 3.1.4 行针与得气

- **基本手法**：
  - **提插法**：针尖进入一定深度后，进行上下、进退的纵向运动。提插幅度大、频率快，刺激量大；反之刺激量小。
  - **捻转法**：将针来回旋转捻动，捻转角度大、频率快，刺激量大。**捻转幅度一般控制在180°~360°，不可单向连续捻转，以免肌纤维缠绕针身致滞针。**
- **辅助手法**：循法（沿经轻按）、弹法（轻弹针柄）、刮法（指甲刮针柄）、摇法、飞法、震颤法，以催气、行气、守气。
- **得气**：针刺入后施以行针手法，患者出现**酸、麻、胀、重**感，医者指下有**沉紧、如鱼吞钩饵**之感。古称"气至"。"刺之要，气至而有效"。得气快弱与体质、病情、取穴准确度相关；不得气可循按导气、调整深浅方向或留针候气。**得气感与疗效相关，但强求"剧痛"是错误的；剧烈疼痛应调针。**

### 3.1.5 留针与出针

- 留针：一般留针20~30分钟，其间行针1~2次；顽证、痛证可延长；小儿及不便留针者可浅刺疾出。
- 出针：先以左手拇、食指按消毒干棉球压于针旁，右手捻动针柄缓慢退至皮下再快拔出；出针后按压针孔防出血（**眼区、头皮血管丰富区按压1~2分钟**）。检查针数，防止遗漏。

## 3.2 针刺补泻手法（简述）

| 手法 | 补法 | 泻法 |
|---|---|---|
| **捻转补泻** | 捻转角度小（<180°~360°）、用力轻、频率慢、操作时间短；拇指向前左转为主（顺经） | 角度大、用力重、频率快、时间长；拇指向后右转为主 |
| **提插补泻** | 先浅后深，重插轻提，提插幅度小、频率慢 | 先深后浅，轻插重提，幅度大、频率快 |
| **疾徐补泻** | 进针慢（徐内），少捻转，出针快（疾出）并速按针孔 | 进针快（疾内），多捻转，出针慢（徐出）并摇大针孔 |
| **迎随补泻** | 针尖顺着经脉循行方向刺入（随而济之） | 针尖逆着经脉循行方向刺入（迎而夺之） |
| **呼吸补泻** | 呼气时进针，吸气时出针 | 吸气时进针，呼气时出针 |
| **开阖补泻** | 出针后迅速揉按针孔（闭其门） | 出针时摇大针孔而不立即按压（开其门） |
| **平补平泻** | 进针得气后均匀地提插捻转，不留或短留针 | （同一法，适用于虚实不显或虚实夹杂） |

复式手法：烧山火（分层徐进紧按，得温热感，治虚寒）与透天凉（速按紧提，得凉感，治实热）为代表，操作复杂，由专科医师掌握。**现代循证研究提示补泻手法存在生理效应差异，但不同手法间的疗效差异证据尚不一致。**

## 3.3 针刺异常情况的预防与处理

### 3.3.1 晕针（最常见）

- **原因**：体质虚弱、精神紧张、饥饿、疲劳、大汗大泻大出血后、体位不当、刺激过强。
- **表现**：针刺中患者突然出现头晕、眼花、心慌、恶心欲吐、面色苍白、出冷汗、四肢厥冷；重者神志昏迷、卒倒、血压下降、脉微欲绝。
- **处理流程（必须牢记）**：
  1. **立即停止针刺，将针全部起出**；
  2. 使患者去枕**平卧，头稍低**，松开衣领，注意保暖，饮温开水或糖水，静卧片刻多可恢复；
  3. 重者指掐或针刺**水沟、素髎、内关、合谷、足三里**，灸**百会、关元、气海**；
  4. 仍不缓解者，予吸氧、监测生命体征，必要时实施现代急救（建立静脉通道、抗休克），呼叫急救。
- **预防**：首次针灸、体弱、空腹、疲劳者取卧位、轻刺激、少穴位；询问晕针史；针刺中密切观察，凡诉头晕心慌即刻处理。

### 3.3.2 其他异常情况

| 异常 | 原因 | 处理 |
|---|---|---|
| **滞针** | 患者紧张致肌肉痉挛；单向捻转过度致肌纤维缠绕 | 嘱放松、延长留针；循按穴位周围或弹击针柄；附近再刺一针宣散；因单向捻转者向相反方向捻回；仍不能出针勿强拔，热敷片刻再起 |
| **弯针** | 进针后体位移动、肌肉骤缩、针柄受外力碰撞 | **不得再行提插捻转**；顺针身弯曲方向缓慢分段拔出；若因体位改变所致，恢复原体位后起针 |
| **断针（折针）** | 针具质量差、针身锈蚀、行针用力过猛、肌肉强烈痉挛、体位变动 | 嘱患者**切勿移动**、保持镇静；断端显露者用镊子夹出；断端与皮肤相平者挤压针孔周围使断端露出再夹取；完全没入者**立即外科处理（X线定位手术）** |
| **血肿** | 刺伤小血管（尤其眼区、头皮、面部） | 先**冷敷止血**，24小时后**热敷促吸收**；小血肿可自行消退 |
| **气胸（最危险并发症）** | 胸背部及锁骨上窝（缺盆）穴针刺过深伤肺 | 突发胸痛、胸闷、干咳、呼吸困难、发绀；**立即起针、半卧位、吸氧、避免搬动、即刻转急诊/外科**，张力性气胸需穿刺排气。**预防：胸背穴斜刺浅刺，掌握深度，留针期间避免咳嗽深吸气体位变动** |
| **刺伤延髓/脊髓** | 哑门、风府、风池向上过深；大椎、命门等深刺 | 剧烈头痛、呕吐、肢体瘫痪、意识障碍——**立即起针，急转神经外科**。预防：项部穴针尖朝鼻尖/下颌方向，严格深度 |
| **刺伤内脏** | 期门、日月过深伤肝胆；中脘深刺伤胃（饱餐后）；章门深刺伤脾肾 | 内出血表现为腹痛、压痛、反跳痛、休克——**立即转外科** |
| **后遗感** | 出针后局部酸胀不适 | 一般数小时至1~2天自行消失，可局部热敷 |

## 3.4 针刺禁忌（系统级安全规则，AI 应检索引用）

1. **过于饥饿、疲劳、精神高度紧张者，不宜立即针刺；体弱者刺激不宜过强，尽量卧位。**
2. **孕妇**：腰骶部、腹部及**合谷、三阴交、昆仑、至阴、肩井**等穴禁针；有流产史者慎针。
3. **小儿**：囟门未闭合者，头顶部（百会、四神聪、囟会）**禁刺**；小儿不留针或浅刺疾出。
4. **皮肤感染、溃疡、瘢痕、肿瘤部位**局部不宜针刺。
5. **有出血倾向者（血小板减少、血友病、服用抗凝药如华法林）**慎用针刺，禁用刺络放血、刺络拔罐。**针刺前必须问清抗凝药使用史。**
6. 眼区、项部、胸背部腧穴严格掌握角度深度（见各穴表）。
7. 自发性出血损伤后出血不止者，不宜针刺。
8. 尿潴留患者针下腹部穴前应先叩诊膀胱底或排尿，防止刺伤充盈膀胱。

## 3.5 电针法

- 定义：毫针刺入得气后，在针柄上接通微量电流波，以针与电综合刺激代替手法行针。
- **波型与适应**：连续波（密波>30Hz可抑制感觉/运动神经，镇静止痛；疏波可兴奋肌肉）、疏密波（止痛、促进气血循环、消炎消肿，最常用）、断续波（提高肌肉韧带张力，治痿证、瘫痪）。
- 适应：各种痛证、痹证、瘫痪、麻痹、肌肉劳损、五官科病症等；韩济生研究表明**低频(2Hz)电针主要促进脑啡肽、β-内啡肽释放，高频(100Hz)主要促进强啡肽释放**，可按疼痛类型选择参数。
- 禁忌与注意：**严重心脏病、安装心脏起搏器/除颤器者禁用或慎用**；电流不可通过心脏（避免双侧内关对置强电流）、脑干、脊髓；调节电流从零渐增，防止突然强刺激致肌肉强烈收缩弯针、晕针。
- 参数参考：频率2~100Hz，强度以患者能耐受的明显酸胀感为度，通电15~30分钟。

## 3.6 耳针与耳穴压豆

- 耳穴分布规律：耳廓形似**倒置胎儿**，头面向下、臀足向上；与头面相应的穴位在耳垂，与内脏相应者多在耳甲艇、耳甲腔。
- 常用耳穴（本知识库重点）：
  - **神门**（三角窝后1/3上部）：镇静、止痛、安眠——失眠、痛证首选。
  - **交感**（对耳轮下脚前端与耳轮交界处）：调节自主神经、解痉止痛——内脏绞痛、胃肠功能紊乱。
  - **内分泌**（屏间切迹内耳甲腔前部）：调节内分泌——月经不调、更年期综合征、痤疮、甲状腺病症。
  - **皮质下**（对耳屏内侧面）：镇静安神、止痛——失眠、多梦、神经衰弱。
  - **心、肝、脾、肺、肾**（耳甲腔/耳甲艇内对应区域）：按脏取用（心悸、失眠；眩晕、高血压；纳差、腹胀；咳喘、皮肤病；腰痛、耳鸣、遗尿）。
  - 其他常用：胃（胃痛）、三焦（水肿便秘）、肾上腺（过敏、炎症、低血压）、枕（头痛头晕后遗）、缘中/脑点（遗尿、崩漏）、耳尖（放血退热、降压、目赤）、交感+内分泌（痛经）。
- **耳穴压豆（贴压）**：王不留行籽/磁珠贴于耳穴，每日按压3~5次、每穴1~2分钟，3~5天换贴（夏季缩短），双耳交替。适应：失眠、戒烟、减肥辅助、近视、痛证、经前紧张、妊娠呕吐（须医师指导选穴）。
- 注意：严格消毒防耳廓感染（**耳软骨膜炎处理困难**）；耳廓冻伤、炎症部位禁贴；孕妇慎用（子宫、内分泌、盆腔等穴禁用）；胶布过敏者改用低敏胶布。

## 3.7 头皮针（头针）

- 刺激头部特定区线（按大脑皮质功能定位在头皮的投影），广泛用于脑源性疾病。
- 常用刺激区（焦氏头针体系）：**运动区**（顶颞前斜线，上点在前后正中线中点后0.5cm、下点在眉枕线与鬓角发际前缘交点；上1/5治对侧下肢及躯干瘫痪，中2/5治上肢，下2/5治运动性失语、面瘫）、**感觉区**（运动区后移1.5cm平行斜线）、足运感区、晕听区、言语区；国际标准化头针线（如顶中线MS5、顶颞前斜线MS6等）。
- 操作：平刺进针至帽状腱膜下，快速捻转（200次/分以上，2~3分钟）或接电针，配合患肢活动（动留针）。
- 适应：中风偏瘫、失语、面瘫、小儿脑瘫、帕金森病、眩晕、耳鸣、失眠等。
- 注意：囟门未闭、头部感染溃疡瘢痕处禁针；严格消毒防感染；注意患者耐受度，脑出血急性期（须病情稳定后）按医师评估实施。

## 3.8 穴位埋线

- 将可吸收线体（羊肠线、PGA线等）埋入穴位，形成持久柔和刺激（"以线代针"），一般**2~4周治疗1次**。
- 适应：肥胖症、慢性胃肠病、便秘、痛经、癫痫辅助、过敏性鼻炎、腰腿痛等慢性病。
- 注意：严格无菌操作；线体不可暴露皮肤外；发热、感染、糖尿病患者慎用；**孕妇腹部腰骶部禁用**；个别患者对线体过敏出现红肿硬结，需就诊处理；同一穴位反复埋线应避开上次线体吸收区。

# 四、灸法

## 4.1 灸法的分类

灸法是以艾绒等药物灼烫、温熨体表穴位，借温热与药力防治疾病的方法。分类如下：

### 4.1.1 艾炷灸

艾炷为艾绒捏成的圆锥状小体，每燃尽一炷称"一壮"。

- **直接灸（明灸）**：将艾炷直接放在皮肤上施灸。
  - **瘢痕灸（化脓灸）**：艾炷置穴位上燃尽，局部烫伤、无菌化脓、灸疮愈合留瘢。用于某些慢性顽固性疾病（哮喘、肺痨、瘰疬等）。施灸前局部涂蒜汁粘附，灸后贴淡水膏促化脓，灸疮期间保持清洁防感染。**因痛苦大且留瘢，须征得患者同意并由专科医师实施；体弱、老年、糖尿病（伤口难愈）者不用。**
  - **无瘢痕灸**：艾炷燃剩2/5左右、患者灼痛时移去，换炷再灸，皮肤红晕不起泡为度。用于虚寒性疾病。
- **间接灸（隔物灸）**：

| 方法 | 操作 | 适应症 |
|---|---|---|
| **隔姜灸** | 鲜姜切片（约0.3cm，针刺数孔）垫艾炷 | 虚寒性呕吐、腹痛、泄泻、风寒湿痹、面瘫 |
| **隔蒜灸** | 鲜蒜片垫艾炷 | 痈疽初起、瘰疬、肺痨、毒虫咬伤 |
| **隔盐灸** | 净食盐填平脐窝（神阙），上置艾炷 | **寒证腹痛、吐泻、中风脱证、四肢厥冷（回阳固脱）** |
| **隔附子饼灸** | 附子研末酒调做饼垫艾炷 | 阳虚证（畏寒、遗尿、阳痿）、疮疡久溃不敛 |

### 4.1.2 艾条灸（悬灸）

| 方法 | 操作 | 适用 |
|---|---|---|
| **温和灸** | 艾条距皮肤2~3cm固定熏烤，温热无灼痛，每穴10~15分钟至皮肤红晕 | 最常用，虚寒证、保健 |
| **雀啄灸** | 艾条一上一下如雀啄般移动 | 昏厥急救、儿童疾患（注意防烫伤） |
| **回旋灸** | 艾条平行往复回旋熏烤 | 面积较大的风湿痹痛、软组织劳损、皮肤病 |

### 4.1.3 温针灸与温灸器

- **温针灸**：毫针刺入得气留针时，将艾绒裹于针柄或套1~2cm艾条段点燃，热力通过针身传入。适用于**寒凝经脉、风湿痹痛**（肩周炎、腰痛、膝痛）。注意：针柄艾段下垫硬纸片/棉纸防火灰掉落烫伤；**胸背部慎用，面部不用**。
- **温灸器灸**：艾灸盒、温筒灸等器具施灸，用于面积大、小儿、惧灸者，温度均匀安全。

## 4.2 灸法的作用

1. **温经散寒**：适用于寒凝血滞、经脉痹阻之痛经、痹证、腹痛、泄泻、冻疮等（"寒者温之"）。
2. **扶阳固脱**：治疗阳气虚脱之大汗淋漓、四肢厥冷、脉微欲绝（中风脱证重灸神阙、关元）；以及遗尿、脱肛、阴挺等阳气不固之证。
3. **消瘀散结**：用于瘰疬、乳痈初起、疮疡久溃不敛等（温热使气血流通、凝滞消散）。
4. **防病保健**："若要身体安，三里常不干"——常灸**足三里、关元、气海、命门、神阙（隔盐灸）**激发正气、延年益寿；风门、足三里灸预防感冒。

## 4.3 灸法的适应症与禁忌（安全规则）

**适应**：虚证、寒证、阴证为主——阳虚畏寒、风寒湿痹、寒性胃痛腹痛泄泻、宫寒痛经、阳痿遗尿、虚脱、慢性咳喘（缓解期）、疮疡阴证、保健强身。

**禁忌与慎用（醒目标注）**：
1. **实热证、阴虚发热者慎用或禁灸**（高热、吐衄、咯血、中风闭证、大热烦渴、舌红少津）。
2. **面部、五官区域、大血管走行处、黏膜处不宜直接灸**（防瘢痕、防损伤）；皮薄肌少筋肉结聚处、妊娠期妇女**腰骶部和小腹部**不宜施灸。
3. 极度疲劳、过饥过饱、酒醉、大汗淋漓、大渴、情绪剧烈波动时暂不施灸。
4. 无自制能力的精神异常者、感觉障碍（糖尿病周围神经病变等对温度不敏感）者慎灸，防烫伤而不自知。
5. 皮肤破损、感染、水疱处不灸。
6. 灸后处理：施灸过量出现小水疱可任其自然吸收；水疱大者消毒后用无菌针具从底部刺破放液，涂烫伤膏/甲紫，保持干燥防感染；瘢痕灸灸疮化脓期间局部清洁换药。

# 五、拔罐、刮痧及其他外治法

## 5.1 拔罐法

以罐为工具，燃火、抽气等造成负压吸附于体表，产生温热刺激与瘀血反应，以温经通络、祛湿散寒、行气活血、消肿止痛。

### 5.1.1 操作方法分类

| 方法 | 操作 | 适用 |
|---|---|---|
| **留罐（坐罐）** | 罐吸拔后留置**5~15分钟**（一般10分钟左右，皮肤潮红即可） | 最常用，风寒湿痹、感冒咳嗽 |
| **走罐（推罐）** | 罐口与皮肤涂润滑剂（凡士林、油性介质），吸拔后沿肌肉走向往返推移 | 面积大、肌肉丰厚处——腰背、大腿（感冒、项背痛、肥胖辅助） |
| **闪罐** | 罐拔住后立即起下，反复吸拔至皮肤潮红 | 面瘫、肌肤麻木、虚弱不宜留罐者（面部常用） |
| **刺络拔罐（放血拔罐）** | 皮肤消毒后三棱针/采血针点刺数下，再拔罐吸出少量血液（3~5ml以内） | 急性扭伤瘀血、热证（咽痛耳尖刺络）、神经性皮炎、丹毒样表现需辨证。**出血性疾病、凝血障碍、服抗凝药者禁用** |
| **药罐** | 罐内盛药液（竹罐药煮）或药末贴敷结合拔罐 | 风湿痹痛 |

### 5.1.2 适应症
- 风寒湿痹（肩背痛、腰腿痛）、感冒、咳嗽（风寒束肺）、颈肩综合征、落枕、软组织劳损扭伤（48小时后，瘀血可刺络拔罐）、胃脘痛（寒性）、腹痛泄泻、毒蛇咬伤排毒（局部拔罐辅助急救）、带状疱疹后遗神经痛辅助。

### 5.1.3 禁忌症（醒目标注）
1. **皮肤破损、溃疡、水肿、过敏、传染性皮肤病处**不拔罐。
2. **出血性疾病、血小板减少、血友病、服抗凝药者**禁用（尤其刺络拔罐）。
3. **孕妇腰骶部、腹部禁拔**；女性月经期慎拔腹部。
4. 大血管搏动处（颈动脉、腹主动脉区）、心尖搏动区、眼、口、鼻等五官及乳头、阴部禁拔；骨骼凹凸不平、毛发过多处不易吸拔。
5. **高热、抽搐、痉挛者**；严重心血管疾病、心力衰竭、极度衰弱、消瘦、皮肤失去弹性者慎用或禁用。
6. 急性外伤骨折、静脉曲张、肿瘤局部禁拔。

### 5.1.4 注意事项
- 防烫伤（投火/闪火法酒精勿滴落）；留罐中密切观察，患者诉明显灼痛或过度紧绷应提前起罐。
- 起罐：一手按罐旁皮肤使空气进入，罐自然脱落，**不可硬拽**。
- 罐斑：紫黑色（瘀血、寒凝血瘀）、鲜红（热证）、色淡（虚证）可作辨证参考；罐斑未消退处暂不复拔。
- 出现水疱：小者消毒纱布保护待吸收；大者消毒后针刺放液、涂烫伤膏、无菌包扎。
- **拔罐后勿立即洗澡（尤其冷水澡）**，注意保暖避风，饮温水。

## 5.2 刮痧法

用刮痧板（牛角、砭石、陶瓷等）蘸刮痧介质（油类），在体表反复刮拭，使皮肤出现红色粟粒状或暗红色出血点（"出痧"），以宣通气血、发汗解表、舒筋活络、清热排毒。

- **操作**：刮板与皮肤呈45°，单一方向（自上而下、由内向外）刮拭，每部位20~30次至出痧；力度先轻后重，以患者可耐受为度；颈背、肩臂、肘窝、腘窝等部常用。
- **出痧解读（辅助辨证，供 AI 参考）**：红润微痧——病邪轻浅；鲜红成片——多热证；紫红、紫黑痧点痧斑——瘀滞较重、病久入络；青紫色斑块——多寒凝；出痧快而多者多实证，不易出痧者多虚证。痧象一般**3~7天消退**，同一部位待痧退后再刮。
- **适应症**：感冒发热、中暑（暑热闭郁）、头痛、颈肩背痛、落枕、咽喉肿痛（少商放痧结合）、乳痈初期、亚健康疲劳等实证、热证、表证。
- **禁忌（醒目标注）**：出血性疾病（血小板减少性紫癜、白血病、血友病）、凝血功能障碍者禁刮；皮肤破损、感染、溃疡、瘢痕、不明肿块及恶性肿瘤局部禁刮；**孕妇腹部、腰骶部禁刮**；严重心脑血管疾病、肝肾功能不全、全身浮肿者禁刮或慎刮；过度饥饱、过渴、大疲劳时暂不刮；久病年老极虚者、小儿囟门未闭者头颈部慎刮；外科手术瘢痕处慎刮。
- **刮后注意**：2小时内不洗澡、局部避风寒；饮温开水；饮食清淡，忌生冷辛辣。

## 5.3 穴位贴敷

药物研末调糊（醋、姜汁、酒等）贴敷穴位，药物经皮吸收加穴位刺激双重作用。

### 5.3.1 三伏贴（"冬病夏治"）

- **原理**：夏季三伏天（初伏、中伏、末伏）自然界与机体阳气最盛，毛孔开泄，将辛温祛寒药物贴敷背部腧穴，温阳利气、驱散内伏寒痰，"春夏养阳"，冬病夏治。
- **常用穴位**：肺俞、膏肓、定喘、大椎、风门、脾俞、肾俞、天突、膻中（按病选3~5对）。
- **常用药物**：白芥子、细辛、甘遂、延胡索、麻黄、肉桂等以姜汁调糊（各地配方不一）。
- **适应症**（中医辨证属阳虚为主或寒热错杂以寒为主、秋冬反复发作者）：**慢性支气管炎、支气管哮喘、慢性咳嗽、慢阻肺（COPD）、过敏性鼻炎、慢性鼻炎、反复呼吸道感染、体虚易感冒、虚寒型慢性胃肠炎、痛经（寒凝血瘀型）、关节冷痛**等。
- **禁忌与注意**：孕妇禁用；发热、急性感染期、咯血禁用；皮肤破损、湿疹及严重皮肤过敏者禁用；阴虚火旺、糖尿病（皮肤易损难愈）慎用；贴敷成人一般0.5~2小时、儿童0.5~1小时（或遵医嘱），局部灼热刺痛难忍提前揭除；贴后皮肤潮红、水疱为常见反应，大疱按烫伤处理；三伏贴为"治未病"辅助手段，不能替代哮喘、COPD的规范药物治疗。

### 5.3.2 三九贴
"夏养三伏、冬补三九"，数九寒冬贴敷温阳散寒，与三伏贴配合巩固（适应症类同，侧重冬季发作期预防）。

## 5.4 穴位按摩（成人推拿穴位按压要点）

- 常用手法：按法（垂直下压）、点法（指点压）、揉法、一指禅推法、拿法（捏而提之）、擦法、摩腹。
- 常见应用：按揉**太阳、风池**缓解头痛；按**内关**止晕止呕（晕车）；按**足三里**缓解胃痛助消化；掐**人中/合谷**应急醒神；**涌泉**擦法助眠引火下行。
- 注意：力度由轻到重，以酸胀得气为度；皮肤破损、骨折、骨结核、肿瘤、急性传染病、严重心脏病者禁局部按摩；孕妇腰腹部禁按摩。

## 5.5 小儿推拿

小儿推拿特定穴多分布于两臂（前臂"三关六腑天河水"线性穴）与头面、手部，手法轻快柔和。

**外感四大法（感冒基础方）**：
- **推攒竹（开天门）**：两眉正中至前发际直线，两拇指自下而上交替直推50~100次——疏风解表、开窍醒神。
- **推坎宫（分推坎宫）**：自眉头起沿眉弓向眉梢分推50~100次——外感发热、头痛。
- **揉太阳**：按揉眉后凹陷处50~100次——头痛、发热、目赤。
- **拿风池**：拿捏颈后枕骨下凹陷3~5次或揉30次——发汗解表。

**清热要穴**：
- **清天河水**：前臂正中，腕横纹（总筋）至肘横纹（曲泽）成一直线，食中二指自腕向肘直推100~300次——清热解表、泻火除烦，用于外感发热、低热、夜啼。
- **退六腑（退下六腑）**：前臂尺侧，肘尖至阴池（腕横纹尺侧）成一直线，自肘向腕直推100~300次——清热凉血解毒，用于高热、实热证（虚寒证、腹泻者慎用）。
- **推三关**（对照）：前臂桡侧，阳池至曲池成一直线，自腕向肘推——温阳散寒、益气活血（虚寒证用），与退六腑一温一清配伍调节寒热。

**消化系统常用**：补脾经（拇指螺纹面旋推）、清胃经、揉板门、运内八卦、摩腹（顺时针通便、逆时针止泻）、捏脊（自长强向上捏提至大椎3~5遍，调阴阳、理气血、强身）、推下七节骨（泄泻实证热证）、推上七节骨（止泻虚证）、揉龟尾、按揉足三里。

- 适应：小儿感冒发热、咳嗽、泄泻、便秘、厌食、疳积、夜啼、斜颈（早期）等。
- 禁忌：急性传染病、严重心脏病、骨折、皮肤破损感染、出血性疾病患儿禁用；饥饿或过饱后不宜立即推拿；操作介质（滑石粉/姜汁/温水）保护皮肤。

## 5.6 中药熏洗与溻渍（简述）

- **中药熏洗**：药物煎汤，趁热先熏后洗患部（全身熏蒸称"药浴"）。适应：痔疮（五味消毒/苦参汤类坐浴）、外阴瘙痒、风湿痹痛、足跟痛、踝关节扭伤恢复期（活血化瘀方）、湿疹（急性渗出期不宜烫洗）。注意：控制水温（一般38~42℃，糖尿病及感觉障碍者测温防烫伤）；皮肤破损、化脓、传染性皮肤病慎用；熏蒸注意通风防晕厥，心脑血管病者时间宜短。
- **溻渍（湿敷）**：多层纱布浸透药液湿敷患处，冷溻清热解毒（急性皮炎红肿渗出），热溻温经散寒（慢性筋骨痛），每次20~30分钟。注意保持湿润、清洁。

# 六、针灸现代研究与国际应用

## 6.1 WHO 针灸适应症相关报告

- **1979年**：WHO 曾推荐 **43 种适合针灸治疗的病症**（涵盖上呼吸道疾病（急性鼻窦炎、鼻炎、感冒、急性扁桃体炎）、呼吸系统（急性支气管炎、支气管哮喘）、眼科（急性结膜炎、中心性浆液性脉络膜视网膜病变、近视-儿童）、口腔科（牙痛、拔牙后疼痛、齿龈炎、急慢性咽炎）、胃肠系统（呃逆、急慢性胃炎、胃酸过多、慢性十二指肠溃疡、急性/慢性结肠炎、腹泻、便秘、麻痹性肠梗阻）、神经系统肌肉骨骼（头痛、偏头痛、三叉神经痛、面瘫早期、卒中后偏瘫、周围神经疾病、脊髓灰质炎早期、梅尼埃病、神经源性膀胱、夜遗尿、肋间神经痛、颈臂综合征、冻结肩、网球肘、坐骨神经痛、腰痛、骨关节炎）等）——该清单偏专家共识性质。
- **2002/2003年**：WHO 发布《Acupuncture: Review and Analysis of Reports on Controlled Clinical Trials（针灸：对照临床试验报告的回顾与分析）》，系统回顾约 **281 项对照临床试验**，将测试过的疾病分为四类：
  1. **第一类：已通过对照试验证明针灸治疗有效的疾病**（各译本收录24~28条不等）：包括**放疗/化疗不良反应（恶心呕吐）、术后恶心呕吐、术后疼痛、胆绞痛、原发性痛经、头痛、耳痛、面部疼痛（含颅下颌关节病）、颈痛、牙科疼痛（含颞下颌功能障碍）、肩关节周围炎、肾绞痛、类风湿关节炎、坐骨神经痛、扭伤、网球肘、中风、抑郁症（部分类型）、急性细菌性痢疾、原发性高血压、原发性低血压、白细胞减少症、癫痫、引产、恶心呕吐（含妊娠晨吐）**等。
  2. **第二类：针灸可能有效、值得进一步研究的疾病**（约60余条，如过敏性鼻炎、慢性胃炎、便秘、失眠、抑郁焦虑、骨关节炎疼痛、痛经、戒断综合征等）。
  3. **第三类：仅个别报道、可尝试使用针灸的疑难病症**。
  4. **第四类：从现有证据看不适用或仅有个别支持性报道的病症**。
  报告同时强调：**针灸的不良反应发生率远低于许多常规药物，前提是操作者训练有素**。
- **2022年**：广州中医药大学许能贵、杜元灏等团队在《英国医学杂志》（BMJ）发表全球首个**针灸临床证据图谱**，纳入 12 个疾病领域 77 种疾病、1402 个随机对照试验、205 个结局指标，为当前最全面的针灸证据综合（证据显示针灸对中风后失语、 Bell 面瘫、纤维肌痛等显示潜在优势，对部分疾病的证据强度受试验质量限制）。

## 6.2 针灸镇痛机制研究（知识库科普模块）

现代研究将针灸镇痛解释为**外周—脊髓—中枢多层面、递进式、多靶点**的网络机制：

1. **外周局部机制（腺苷—A1受体）**：Goldman N, Chen M, Fujita T, … Nedergaard M. *"Adenosine A1 receptors mediate local anti-nociceptive effects of acupuncture."* **Nature Neuroscience, 2010;13(7):883-888**。发现：针刺使小鼠局部组织**腺苷浓度升高约24倍**；腺苷激活传入神经末梢的 **A1受体** 产生局部镇痛；**敲除A1受体后针刺镇痛效应消失**；给予A1受体激动剂可复制镇痛效应；用药物抑制腺苷降解（延长腺苷半衰期）可使镇痛作用**延长约3倍**。该研究首次在分子层面证明针刺镇痛的局部化学机制（针刺→组织损伤释放ATP→降解为腺苷→A1受体抑制痛觉传入），也解释了咖啡因（腺苷受体拮抗剂）可能削弱针刺镇痛效应。
2. **脊髓节段机制（闸门控制学说）**：Melzack 与 Wall 于1965年提出**闸门控制学说（Gate Control Theory）**——脊髓背角存在"闸门"，粗纤维（Aβ，非伤害性触压觉）传入可兴奋抑制性中间神经元、"关闭闸门"，从而阻断细纤维（C纤维）疼痛信号上传；针刺/艾灸的酸胀重感（非伤害性传入）通过节段性抑制减弱痛觉传导，也是经皮神经电刺激（TENS）的理论基础。
3. **中枢下行抑制机制（内源性阿片肽）**：针刺可激活**导水管周围灰质—延髓头端腹内侧核（PAG-RVM）下行抑制系统**，促进**脑啡肽、β-内啡肽、强啡肽**等内源性阿片肽释放（脑脊液中可检出），并涉及5-羟色胺、去甲肾上腺素、内源性大麻素等递质。中国学者**韩济生院士**团队数十年系统研究证明：针刺30分钟可产生全身性镇痛并有后效应；**低频(2Hz)电针主要促进脑啡肽与β-内啡肽释放，高频(100Hz)电针主要促进强啡肽释放**，并据此研制了韩氏穴位神经刺激仪（HANS）；纳洛酮（阿片受体拮抗剂）可部分翻转针刺镇痛，是其重要药理学证据。
4. **脑成像研究**：功能磁共振（fMRI）与PET研究显示，针刺可调制与疼痛处理相关的脑区（岛叶、前扣带回、丘脑、边缘系统及默认模式网络）活动；不同穴位、真假针刺的脑响应模式存在差异（如哈佛医学院马省理工团队 Vim Patwardhan / Vitaly Napadow 等系列工作），为穴位相对特异性提供了影像学线索，但影像结果的重复性仍是研究热点。
5. **其他机制**：针刺调节下丘脑-垂体-肾上腺（HPA）轴与免疫功能（炎症因子如IL-6、TNF-α下调——2020年以来"细胞因子风暴"调节研究）、改善局部微循环、结缔组织机械信号转导（Langevin 研究）等。
6. **客观提示**：高质量系统评价同时指出，**针刺与假针刺的效应差值在部分适应症中有限**，安慰剂/期望效应与穴位特异性之争仍在持续；证据分级与真实世界研究是当前方向。

## 6.3 针灸的国际传播与标准化

- **传播概况**：中医药（含针灸）已传播至**全球196个国家和地区**（人民日报、国家卫健委及世界中医药学会联合会口径）；据世界卫生组织统计，**113个成员国认可针灸等中医药诊疗方式，29个成员国为中医药制定了相关法律法规，20个成员国将针灸等纳入医疗保险体系**；全球接受过中医药、针灸、推拿等治疗的人数估计已达世界总人口的三分之一以上。美国、德国、澳大利亚、瑞士等国已将针灸纳入部分保险支付（如美国部分保险覆盖慢性腰痛针灸，退伍军人事务部提供针灸服务）。
- **标准化进展**：
  - **ISO/TC 249（国际标准化组织中医药技术委员会）**：2009年成立，秘书处设在中国，现有成员体40余个。截至2025—2026年已正式发布中医药国际标准**135项左右（135~137项）**、另有数十项在研，其中80余项由中国专家牵头制定；已发布标准涵盖**一次性无菌针灸针（ISO 17218:2014，中医药领域第一个ISO国际标准）**、人参种子种苗、中药材术语、艾灸器具、拔罐器具、中医诊疗设备、安全针灸操作规范等。
  - WHO 传统医学国际疾病分类（ICD-11）首次纳入"传统医学病证分类"章节（2019年世界卫生大会通过），为针灸病证编码与统计提供国际框架。
  - 世界卫生组织西太区曾发布《针灸临床研究指南》《针灸培训与安全规范》等区域性技术文件。
  - 我国国家标准：GB/T 12346《经穴名称与定位》（2006版361穴、2021版362穴）、GB/T 21709《针灸技术操作规范》系列（涵盖毫针、艾灸、拔罐、刮痧、三棱针、耳针、头针、穴位贴敷等分册）、GB/T 30232《针灸学通用术语》等，构成本知识库定位与操作术语的基础依据。
- **国外研究动态**：美国国立卫生研究院（NIH）设国家补充与整合健康中心（NCCIH）持续资助针灸研究；多项大规模随机对照试验（如慢性腰痛、偏头痛预防、膝骨关节炎针灸试验）发表于JAMA、Annals of Internal Medicine等主流期刊，形成"证据与争鸣并存"的研究格局。
