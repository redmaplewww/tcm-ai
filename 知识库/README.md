## 知识库的核心设计（面向AI工程化）

1. **症状→证型→治法→方剂→中药 全链路结构化**：02（辨证）、04（用方）、03（用药）、06（按病贯通）四份文件互为索引，表格统一格式，可直接解析为知识图谱三元组。
2. **安全体系三级嵌套**：
   - 一级：红旗症状立即转诊清单（06章第六章，13类急症）
   - 二级：用药硬校验（03章：十八反/十九畏/妊娠禁忌/中西药相互作用）
   - 三级：输出话术规范（只做健康咨询与参考，不诊断不开方）
3. **证据分层表述**：传统理论与现代循证证据（07章）分开呈现，避免AI回答"把理论当事实"或"全盘否定"两个极端。
