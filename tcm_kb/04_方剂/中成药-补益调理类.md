# 家庭常备中成药（OTC）：虚证调理类

> 使用总原则见《中成药-感冒咳嗽类》。补益类必须辨明气血阴阳之虚，方向相反者禁用；**感冒发热期一律停用补益剂**（"闭门留寇"）。

| 中成药 | 适用证型 | 适用症状 | 禁忌/注意 |
|--------|----------|----------|------------|
| **补中益气丸** | 脾胃气虚、中气下陷 | 体倦乏力、食少腹胀、气短懒言、久泻、脏器下垂感 | **感冒发热期间停用**（"闭门留寇"）；阴虚火旺（潮热盗汗、口干舌红）禁用；实热证禁用 |
| **玉屏风颗粒** | 表虚不固、易感风邪 | 自汗、怕风、**反复感冒**（预防调理） | 外感期间不宜；实热自汗不宜 |
| **六味地黄丸** | 肾阴虚 | 腰膝酸软、头晕耳鸣、盗汗、手足心热、口燥咽干、舌红少苔 | **肾阳虚（畏寒肢冷、夜尿多、便溏）禁用**——误用更伤阳气；脾虚便溏者慎服（滋腻碍脾）；感冒时停用；不宜与感冒药同服 |
| **知柏地黄丸** | 阴虚火旺 | 潮热盗汗、耳鸣遗精、口干咽痛、小便短赤（阴虚+明显虚火） | 脾虚便溏、消化不良者慎用；虚寒证禁用 |
| **杞菊地黄丸** | 肝肾阴虚（目涩） | 眩晕耳鸣、**视物昏花、眼睛干涩**、畏光流泪 | 脾虚便溏慎用；实热目赤（急性结膜炎）非其所宜 |
| **金匮肾气丸（桂附地黄丸）** | 肾阳不足 | 腰痛脚软、下半身常有冷感、小便不利或夜尿多、**畏寒** | **肾阴虚（口干咽燥、潮热盗汗）禁用**；孕妇忌服；感冒时停用；含附子，勿过量 |
| **归脾丸** | 心脾两虚、气血不足 | 心悸失眠、健忘、食少乏力、面色萎黄；脾不统血之月经过多 | 实热证、痰湿壅盛者不宜；感冒时停用 |
| **逍遥丸** | 肝郁脾虚 | 情绪低落或烦躁、胸胁胀痛、**月经不调**、经前乳房胀痛、食欲不振 | 阴虚阳亢者慎用；孕妇遵医嘱 |
| **加味逍遥丸（丹栀逍遥丸）** | 肝郁化火 | 逍遥丸证兼**烦躁易怒、潮热颧红、口苦、月经先期量多** | 虚寒体质不宜；孕妇遵医嘱 |
| **乌鸡白凤丸** | 气血两虚兼肝肾不足（妇科） | 月经不调、行经腹痛、腰膝酸软、面色萎黄、带下（**妇科虚证**调理） | **实证、湿热证（带下黄臭、腹痛拒按、经血紫暗有块）禁用**；感冒发热时停用；孕妇遵医嘱；月经量多者经期停用 |
| **十全大补丸** | 气血两虚重症 | 面色苍白、气短心悸、头晕自汗、体倦乏力、四肢不温 | 阴虚火旺者禁用；感冒时停用；实热证禁用 |
| **生脉饮** | 气阴两亏 | 心悸气短、自汗（夏季汗多乏力、病后体虚） | 实热证、痰湿者不宜；感冒发热时停用 |
| **阿胶（复方阿胶浆）** | 气血两虚之贫血 | 面色萎黄或苍白、头晕乏力、心悸失眠、月经量少 | 脾胃虚弱、消化不良者慎用（滋腻）；感冒时停用；糖尿病注意含糖 |

## 补益方向鉴别要点（AI问诊辅助）
- **气虚**（乏力、气短、自汗、食少）→ 补中益气丸、玉屏风颗粒（易感冒者）。
- **血虚**（面色萎黄、头晕心悸、月经量少色淡）→ 归脾丸（兼失眠健忘）、复方阿胶浆。
- **气血两虚** → 八珍丸类、十全大补丸、乌鸡白凤丸（妇科）。
- **肾阴虚**（腰酸、盗汗、手足心热、舌红少苔）→ 六味地黄丸；火旺明显（咽痛潮热）→ 知柏地黄丸；目涩 → 杞菊地黄丸。
- **肾阳虚**（畏寒、夜尿多、腰膝冷）→ 金匮肾气丸；**与肾阴虚方向相反，禁互用**。
- **肝郁脾虚**（情绪相关、月经不调、胁胀）→ 逍遥丸；化火（烦躁口苦）→ 加味逍遥丸。
- **气阴两虚**（汗多神疲、气短口干，夏季及热病后）→ 生脉饮。

## 用药逻辑与误用后果（AI必须输出）
1. **虚则补之，方向不可错**：肾阴虚误用金匮肾气丸（温阳）→ 更伤阴液、口疮失眠烦躁；肾阳虚误用六味地黄丸（滋阴）→ 更伤阳气、畏寒便溏加重。
2. **感冒发热期停用**：补益剂外感期间服用＝"闭门留寇"，恋邪碍解表。
3. **实证、湿热证禁补**：乌鸡白凤丸用于湿热带下、经血紫暗有块之实证＝助邪碍病。
4. **滋腻碍脾**：六味地黄丸、阿胶类脾虚便溏、消化不良者慎服。
5. **疗程提示**：补益调理起效缓，须规律服用；症状改善后不宜无限期续服，建议定期复诊评估；服药期间忌生冷、油腻、辛辣、烟酒。
6. **就医红线**：不明原因消瘦、贫血进行性加重、月经量多致头晕心悸者，须先就医查明原因，不可单纯"进补"了事。

## 高频问诊-用药映射示例（供AI意图识别）
- "一到傍晚就手心脚心热、盗汗、腰酸" → 六味地黄丸（肾阴虚）。
- "怕冷、夜尿多、腰膝发凉" → 金匮肾气丸（肾阳虚）。
- "气短乏力、经常感冒出汗" → 玉屏风颗粒（表虚不固，缓解期调理）。
- "动不动就累、吃饭不香、说话没力气" → 补中益气丸（脾胃气虚）。
- "心悸失眠、健忘、面色差、月经量多色淡" → 归脾丸（心脾两虚）。
- "心情不好就胃胀、月经前胸胀" → 逍遥丸（肝郁脾虚）。
- "夏天出汗多、浑身没劲、口干" → 生脉饮（气阴两虚）。
- "头晕乏力、面色苍白、月经量少" → 复方阿胶浆/八珍类（气血两虚）。

## 服药须知
1. 补益类宜饭前或空腹温服（遵说明书）；规律服用，不宜时断时续。
2. 服用期间忌生冷、油腻、辛辣、烟酒，以免碍补。
3. 不与感冒药同服；感冒发热期一律停用，愈后再续。
4. 孕妇、哺乳期、儿童进补须先咨询医师或药师。

> **安全提示**：孕妇、哺乳期使用补益类中成药（尤其含活血成分者）须先咨询医师或药师；儿童进补须医师指导。
