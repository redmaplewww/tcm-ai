# 家庭常备中成药（OTC）：感冒类与咳嗽类

> **总原则**：
> 1. 中成药必须**辨证选用**：先分寒热虚实，再选药；用错方向（如风热证误用辛温药）不仅无效，还会**加重病情**。
> 2. 服前阅读说明书，注意禁忌证、不良反应。
> 3. 一般服用3天症状无缓解，或出现高热不退、剧烈腹痛、胸痛、呼吸困难、意识改变等，**立即就医**。
> 4. 儿童、孕妇、哺乳期、老人、肝肾功能不全者用药前须咨询医师或药师。
> 5. 不建议同时服用多种功效相近的中成药；与西药同服一般间隔30分钟以上。
> 6. 服药期间忌烟酒及辛辣、生冷、油腻食物。

## 一、感冒类

| 中成药 | 适用证型 | 适用症状 | 禁忌/注意 |
|--------|----------|----------|------------|
| **风寒感冒颗粒** | 风寒感冒（表实证） | 恶寒重、发热轻、无汗、头痛身痛、鼻塞流**清涕**、咳吐白痰 | 风热感冒（咽痛、黄涕、发热重）**禁用**——误用助热，致咽喉肿痛加剧、发热加重；高血压、心脏病慎用 |
| **感冒清热颗粒** | 风寒感冒（兼有郁热） | 恶寒发热、头痛身重、鼻流清涕、咳嗽咽干 | 风热感冒不宜；含糖型糖尿病患者选无糖型 |
| **正柴胡饮颗粒** | 外感风寒轻证 | 发热恶寒、无汗、头痛、鼻塞、喷嚏、流清涕 | 风热证不宜 |
| **九味羌活丸/颗粒** | 外感风寒夹湿 | 恶寒发热、无汗、头痛**重**、肢体酸楚疼痛（湿重） | 风热感冒禁用；阴虚津亏者慎用 |
| **银翘解毒片（丸/颗粒）** | 风热感冒（银翘散方） | 发热较重、微恶风、咽喉**红肿疼痛**、咳嗽痰黄、口渴、舌尖红 | **风寒感冒禁用**——误用寒凉冰遏表邪，恶寒加重、病程迁延；脾胃虚寒便溏者慎用 |
| **双黄连口服液** | 风热感冒（热毒较盛） | 发热、咽痛、咳嗽（金银花、黄芩、连翘） | 风寒感冒禁用；素体脾胃虚寒（便溏胃冷）者慎用；不宜与含藜芦药物同用 |
| **连花清瘟胶囊** | 风热感冒/流感（热毒袭肺） | 发热恶寒、肌肉酸痛、鼻塞流涕、咳嗽、头痛、咽干咽痛，流感见上述证候者 | 风寒感冒禁用；含大黄，脾胃虚寒便溏者慎用/可能出现轻泻；不宜长期 |
| **桑菊感冒片** | 风热感冒初起（咳重热轻） | 咳嗽、咽干、咽痛、低热、口微渴 | 风寒咳嗽禁用 |
| **小柴胡颗粒** | 邪在少阳/感冒迁延（寒热往来） | 寒热往来（一会冷一会热）、口苦咽干、食欲不振、心烦喜呕、感冒反复低热 | 阴虚火旺者慎用；风寒感冒初起无往来寒热者不对证 |
| **藿香正气水（口服液/软胶囊/滴丸）** | 暑湿感冒/寒湿吐泻（胃肠型感冒） | 头痛昏重、脘腹胀痛、呕吐泄泻、恶寒发热（空调受寒+饮食生冷后吐泻） | **水剂含40%-50%酒精**：服头孢类、甲硝唑、替硝唑等期间**绝对禁用**（双硫仑样反应可致命）；服后不宜驾车；酒精过敏者、儿童选口服液/滴丸（不含醇）；湿热泻（肛门灼热、便臭秽）不宜 |
| **板蓝根颗粒** | 热毒壅盛之咽痛、流感预防（风热证） | 咽喉肿痛、口咽干燥（流行性感冒、咽炎见风热证者） | 风寒感冒禁用；脾胃虚寒（便溏）慎用；**不主张健康人群长期大量服用**预防 |
| **玉屏风颗粒** | 表虚不固（预防调理） | 自汗恶风、体虚**反复感冒**的预防调理（治本，非即时治感冒） | 外感发烧期间不宜进补服用（"闭门留寇"），宜平时调理用 |
| **参苏丸** | 气虚感冒 | 恶寒发热、头痛鼻塞、痰白乏力、气短自汗（老年、体虚者感冒） | 实热证不宜 |

### 风寒/风热鉴别速查（AI问诊核心逻辑）
| 鉴别点 | 风寒 | 风热 |
|--------|------|------|
| 恶寒发热 | 恶寒重、发热轻 | 发热重、微恶风 |
| 汗 | 无汗 | 有汗或微汗 |
| 鼻涕 | 清稀白 | 黄稠 |
| 咽喉 | 不红不痛（或微痒） | 红肿疼痛 |
| 痰 | 白稀 | 黄稠 |
| 口渴 | 不渴或喜热饮 | 口渴喜凉饮 |
| 舌苔 | 薄白 | 薄黄、舌尖红 |
| 用药方向 | 辛温解表（风寒感冒颗粒、感冒清热颗粒） | 辛凉解表（银翘解毒片、双黄连、连花清瘟） |

## 二、咳嗽类

| 中成药 | 适用证型 | 适用症状 | 禁忌/注意 |
|--------|----------|----------|------------|
| **通宣理肺丸** | 风寒束表、肺气不宣 | 感冒咳嗽、咯痰不畅、发热恶寒、鼻塞流清涕、头痛无汗（**风寒咳嗽**） | 风热咳嗽（黄痰咽痛）禁用；阴虚干咳、肺热咳嗽不宜；运动员慎用（含麻黄） |
| **杏苏止咳颗粒** | 风寒/凉燥咳嗽 | 咳嗽痰稀、鼻塞咽干（凉燥伤肺） | 风热咳嗽禁用 |
| **急支糖浆** | 风热犯肺/痰热壅肺 | 外感风热所致咳嗽、发热恶寒、**痰黄黏稠**、胸闷咽痛 | 风寒咳嗽（白稀痰）不宜；含糖，糖尿病慎用；服药期间忌辛辣 |
| **蜜炼川贝枇杷膏** | 风热/燥热咳嗽、肺燥咳嗽 | 咳嗽痰黄或干咳、咽干喉痒、声音沙哑 | 风寒咳嗽（痰白清稀）**不宜**；含糖量高，糖尿病患者慎用；不宜与温补类中药同服 |
| **橘红丸（颗粒/片）** | 痰热咳嗽 | 咳嗽痰多、**痰黄黏稠**、胸闷口干 | 风寒咳嗽、阴虚燥咳禁用；气虚咳喘不宜久服 |
| **二陈丸** | 湿痰咳嗽 | 咳嗽痰多、色白易咯、胸闷恶心 | 燥痰（痰黏难出）、阴虚咳嗽慎用 |
| **养阴清肺丸（口服液/膏）** | 阴虚肺燥 | 咽干咽痛、干咳少痰或无痰、**夜间加重**、口鼻干燥 | 痰湿咳嗽（痰多白腻）禁用；风寒咳嗽禁用；糖尿病注意含糖剂型 |
| **强力枇杷露** | 痰热伤津之久咳 | 久咳劳嗽、干咳少痰 | **含罂粟壳：不可久服、有成瘾性，儿童、孕妇、哺乳期禁用，严格按说明书疗程** |
| **苏黄止咳胶囊** | 风咳（感冒后咳嗽/咳嗽变异性哮喘） | 阵发性呛咳、咽痒即咳、干咳无痰、遇冷空气/异味加重 | 少数人服后恶心胃部不适；孕妇慎用（遵医嘱） |

> **安全提示**：咳嗽持续超过2周、咯血、高热、呼吸困难者须就医；2岁以下儿童不建议自行服用止咳抗感冒类中成药。
