# 家庭常备中成药（OTC）：肠胃类

> 使用总原则见《中成药-感冒咳嗽类》。中成药必须**辨证选用**，寒热用错方向会加重病情。

| 中成药 | 适用证型 | 适用症状 | 禁忌/注意 |
|--------|----------|----------|------------|
| **保和丸** | 食积（实证） | 脘腹胀满、嗳腐吞酸、厌食呕恶、大便酸臭（**吃多了**） | 脾虚食积（久病体弱食少便溏）宜改健脾丸类；哺乳期遵医嘱 |
| **大山楂丸** | 轻度食积、食欲不振 | 食积腹胀、消化不良 | 胃酸过多者慎用；含糖，糖尿病慎用 |
| **香砂养胃丸** | 胃阳不足、湿阻气滞 | 胃脘胀满不适、隐痛、嗳气泛酸、纳呆便溏、四肢倦怠 | 胃阴虚（口干舌红少苔）不宜；胃火炽盛（灼热泛酸口臭）不宜 |
| **气滞胃痛颗粒** | 肝郁气滞之胃痛 | 脘胁胀痛、**情绪波动后加重**、嗳气频作、胸闷叹息 | 脾胃虚寒（喜温喜按）者不对证；孕妇慎用 |
| **附子理中丸** | 脾胃虚寒 | 脘腹**冷痛**、喜温喜按、呕吐泄泻、手足不温（**吃凉的就难受**） | **湿热泻（肛门灼热、便臭秽）禁用**——误用如火上浇油；感冒发热时不宜；孕妇慎用；高血压者遵医嘱（含附子） |
| **参苓白术散（丸/颗粒）** | 脾虚湿盛 | 食少便溏、体倦乏力、慢性腹泻、食后腹胀 | 湿热泻禁用；阴虚火旺者不宜 |
| **麻仁润肠丸（麻仁丸）** | 肠燥便秘（肠胃积热、津亏） | 大便秘结、**热秘**（便干难解、小便短赤、口干） | **虚寒性便秘（畏寒肢冷、喜热饮、便不干结却无力排出）慎用**；孕妇慎用（含大黄、火麻仁，遵医嘱）；久服可致结肠黑变病，不宜长期依赖 |
| **葛根芩连片（微丸）** | 湿热泄泻 | 泄泻腹痛、便黄而黏、肛门灼热、烦热口渴 | **寒湿泻（清稀如水、腹痛喜温）禁用**；脾胃虚寒者不宜 |
| **四神丸** | 脾肾阳虚之五更泻 | 黎明腹泻（五更泻）、久泻不止、腰酸肢冷 | 湿热泻、痢疾初起禁用 |
| **开胸顺气丸** | 气滞食积 | 胸胁胀满、胃脘疼痛、嗳气呕恶、大便秘结 | 孕妇禁用；体弱者慎用（含槟榔、牵牛子，攻下力强） |

## 肠胃类中成药寒热鉴别要点（AI问诊辅助）
- **寒证腹泻**：大便清稀如水、腹痛喜温喜按、手足不温 → 附子理中丸、四神丸方向。
- **热证腹泻**：便黄黏臭、肛门灼热、口渴 → 葛根芩连片方向（寒证禁用）。
- **食积**：嗳腐吞酸、大便酸臭、暴食后脘胀 → 保和丸、大山楂丸。
- **脾虚腹泻**：久泻、食少乏力、食后腹胀 → 参苓白术散、健脾丸类。
- **胃痛（情绪相关）**：脘胁胀痛、情绪波动后加重、嗳气叹息 → 气滞胃痛颗粒。
- **胃胀（虚寒型）**：胃脘胀满隐痛、便溏倦怠 → 香砂养胃丸。
- **便秘**：热秘（便干口干尿黄）→ 麻仁润肠丸；虚寒秘（畏寒便不干却无力）慎用麻仁丸；便秘应先调整饮食生活方式，长期依赖含大黄制剂可致结肠黑变病，无效须就医。

## 用药逻辑与误用后果（AI必须输出）
1. **先辨寒热虚实再选药**：附子理中丸误用于湿热泻＝"火上浇油"；葛根芩连片误用于寒湿泻＝更伤脾阳、腹泻加重。
2. **食积与脾虚食积有别**：暴食实证用保和丸（纯消）；久病体弱食少便溏用健脾丸/香砂六君丸类（消补兼施）。
3. **腹泻观察红线**：一般服用3天无缓解，或出现高热、剧烈腹痛、便血、呕血、明显脱水（口渴、尿少、乏力）→ 立即就医；婴幼儿、老年腹泻尤须及时就医。
4. **五更泻辨证**：黎明腹泻、腰酸肢冷属脾肾阳虚 → 四神丸；湿热泻、痢疾初起禁用。
5. **疗程提示**：泻下、消导类中病即止，不宜久服；服药期间忌生冷、油腻、辛辣、烟酒。

## 高频问诊-用药映射示例（供AI意图识别）
- "吃点凉的就拉肚子" → 附子理中丸（脾胃虚寒）。
- "吃了大餐后腹胀嗳酸" → 保和丸（食积）。
- "拉肚子、大便很臭、肛门火辣辣" → 葛根芩连片（湿热泻）。
- "天不亮就拉肚子、腰酸怕冷" → 四神丸（脾肾阳虚五更泻）。
- "大便干、好几天一次、口干尿黄" → 麻仁润肠丸（热秘）。
- "一生气就胃胀疼、打嗝" → 气滞胃痛颗粒（肝郁气滞）。
- "胃隐隐胀、不想吃饭、大便稀、没力气" → 香砂养胃丸/参苓白术散（虚寒/脾虚湿盛）。
- "胸胁胀满、胃疼、大便干结" → 开胸顺气丸（气滞食积，攻下力强，遵医嘱）。

## 服药须知
1. 与西药同服一般间隔30分钟以上。
2. 不建议同时服用多种功效相近的中成药（如保和丸+大山楂丸+健脾丸同服）。
3. 儿童、孕妇、哺乳期、老人用药前咨询医师或药师；2岁以下幼儿慎用。
4. 一般服用3天症状无缓解即就医。

> **安全提示**：剧烈腹痛、呕血、便血、持续呕吐腹泻致脱水者，须立即就医（须排除急腹症）；含附子、槟榔、牵牛子等成分者严格遵说明书与医嘱。
