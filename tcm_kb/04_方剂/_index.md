## 数据字段说明（formulas.json）
| 字段 | 含义 |
|------|------|
| name | 标准方名／中成药通用名（如"银翘散"、"连花清瘟胶囊"） |
| category | 方剂分类（如"解表剂-辛温解表"、"补益剂-补阴"、"中成药-解表"） |
| source | 出处（经典典籍／药典OTC） |
| composition | 组成药物（与源文件一致） |
| functions | 功用 |
| indications | 主治症状 |
| syndromes | 对应标准中医证型名（与诊断学证名一致） |
| otc | 经典方false／中成药OTC true |
| cautions | 禁忌与注意事项（含源文件全部禁忌信息） |
| notes | 配伍特点、鉴别要点、衍生方等 |
