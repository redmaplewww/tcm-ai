# 方剂总论

> **声明：本文件为中医知识库建设调研资料，供AI系统知识库使用，不构成处方建议。**
> 方剂的临床应用必须建立在辨证论治基础上，须由执业中医师指导使用。文中剂量为《方剂学》教材通行参考剂量（单位：g），仅供知识库检索，不作为用药依据。
> 资料来源：普通高等教育中医药规划教材《方剂学》、百度百科、国家卫健委及各省药监局科普资料、新华网、中国药学会等公开资料（2026年9月调研核验）。

## 1. 方剂与治法的关系

- **方以法立，以法统方**：治法是组方的依据，方剂是治法的体现。先有"辨证→立法→遣方→用药"的完整链条。
- **八法**（程钟龄《医学心悟》）：汗、吐、下、和、温、清、消、补。
  - 汗法：解表祛邪，用于表证（如麻黄汤、桂枝汤、银翘散）。
  - 吐法：涌吐痰涎宿食，用于邪滞上脘（现代少用，如瓜蒂散）。
  - 下法：泻下里实，用于里实证（如大承气汤、麻子仁丸）。
  - 和法：和解少阳、调和肝脾/肠胃（如小柴胡汤、逍遥散、半夏泻心汤）。
  - 温法：温里祛寒（如理中丸、四逆汤、阳和汤）。
  - 清法：清热泻火（如白虎汤、黄连解毒汤、龙胆泻肝汤）。
  - 消法：消食导滞、化瘀消癥（如保和丸、血府逐瘀汤）。
  - 补法：补益气血阴阳（如四君子汤、六味地黄丸、肾气丸）。

## 2. 组方原则：君臣佐使

首见于《素问·至真要大论》："主病之谓君，佐君之谓臣，应臣之谓使。"

| 角色 | 定义 | 说明 |
|------|------|------|
| **君药** | 针对主病或主证起主要治疗作用的药物 | 方中不可或缺，药力居首；决定方剂的主要功效方向 |
| **臣药** | ①辅助君药加强治疗主病主证；②针对重要的兼病或兼证起主要治疗作用 | 是君药的"加强部队" |
| **佐药** | ①**佐助药**：配合君臣药加强治疗，或直接治疗次要兼证；②**佐制药**：消除或减弱君臣药的毒性、烈性；③**反佐药**：与君药性味相反而能在治疗中起相成作用（如寒药热服、热药中少佐寒药防格拒） | 药味可多可少，视需要取舍 |
| **使药** | ①**引经药**：引方中诸药直达病所；②**调和药**：调和诸药药性 | 常用甘草、大枣；引经如桔梗载药上行、牛膝引血下行 |

**经典示例——麻黄汤**（《伤寒论》）：
- 君：**麻黄**——辛温发汗解表、宣肺平喘，针对风寒表实主证。
- 臣：**桂枝**——透营达卫，助麻黄发汗解表，兼解肢体疼痛。
- 佐：**杏仁**——降利肺气，与麻黄一宣一降，加强平喘（佐助）。
- 使：**炙甘草**——调和麻、杏宣降之性，缓和汗力（调和）。

**经典示例——小青龙汤**（《伤寒论》）：
- 君：**麻黄、桂枝**——发汗解表，除外寒；又温化水饮。
- 臣：**干姜、细辛**——温肺化饮，助君药散寒蠲饮。
- 佐：**五味子**——敛肺止咳（防辛散耗肺气，属"佐制"兼"相反相成"）；**白芍**——养血敛阴，防温燥伤津；**半夏**——燥湿化痰，降逆止咳。
- 使：**炙甘草**——益气和中，调和诸药。
- 配伍特点：**散中有收、开中有合**，麻黄与五味子、干姜与白芍相对而用，是"佐制""反佐"思维的代表。

**组方要点**：
1. 君药必备，臣佐使可随病情、治法灵活取舍；并非每方君臣佐使俱全。
2. 药物在方中的"角色"取决于其针对的病证主次，而非剂量大小或药材贵贱（虽然君药常相对量重）。
3. 组方还须结合患者体质、年龄、性别、季节气候、地域等因素。

## 3. 方剂的变化规律（方剂运用的灵活性）

同一基础方通过以下三种变化衍生出新方，体现"师其法而不泥其方"：

### 3.1 药味加减（加减运用）
- 在主证不变、兼证变化时，加减次要药物。
- 例：**银翘散**→咽肿痛甚加马勃、玄参；**四君子汤**加陈皮为**异功散**（兼气滞），再加半夏为**六君子汤**（兼痰湿），六君子加木香、砂仁为**香砂六君子汤**（兼气滞脘胀）。
- 注意：药味加减若触及君药或改变配伍核心，则功效主治随之改变（如麻黄汤去桂枝加生姜为三拗汤，发汗力减而重在宣肺平喘）。

### 3.2 药量增减
- 药味不变，改变剂量比例，则方剂功效主次改变，甚至方名改变。
- 例：**小承气汤**与**厚朴三物汤**同用大黄、枳实、厚朴：小承气汤大黄量重（12g）为君——攻下热结；厚朴三物汤厚朴量重（24g）为君——行气除满。
- 例：**四逆汤**与**通脉四逆汤**药味全同，仅附子、干姜用量加重，由回阳救逆变为破阴通脉。

### 3.3 剂型更换
- 药味药量不变，改变剂型，则作用快慢、力量强弱改变。
- 例：理中丸（作用和缓，治中焦虚寒轻证缓证）作汤剂内服（力峻，治急证）；保和丸与保和汤。
- 一般规律："汤者荡也"力峻效速，"丸者缓也"力缓效持。

## 4. 剂型

### 4.1 传统剂型
| 剂型 | 制法/特点 | 适用 |
|------|-----------|------|
| **汤剂** | 饮片加水煎煮去渣取汁；吸收快、起效速、可随证加减 | 急症、重症、病情多变者；内服外用（熏洗）皆可 |
| **散剂** | 药物研末混匀，内服（水调服/煎服）或外用；"散者散也，去急病用之"；兼具吸收快与便于携带优点 | 急证、脾胃病；发散、行气、活血类药（五苓散、平胃散、行军散） |
| **丸剂** | 药末加蜜、水、糊等黏合制成；"丸者缓也"，吸收徐缓、作用持久、便于携带贮存 | 慢性病调理、病后调养（六味地黄丸、理中丸） |
| **膏剂** | ①内服膏滋（煎煮浓缩加糖/蜜熬制，滋润补益）；②外用膏药（贴敷） | 秋冬调补、慢性虚损（膏方）；外科疮疡、风湿痹痛（黑膏药） |
| **丹剂** | 矿物药高温炼制（历史上亦泛指贵重效宏之制剂） | 外科疮疡、痈疽；部分急救开窍方（至宝丹、紫雪丹） |
| **酒剂** | 药材白酒浸提；酒能行血通络、助药力 | 风湿痹痛、跌打损伤、经络瘀阻 |
| **露剂** | 芳香类药物蒸馏所得澄明液（如金银花露） | 轻清宣透、清热生津 |
| **锭剂** | 药末加黏合剂制成纺锤形/圆柱形硬块，研末调服或磨汁外涂 | 外科疮疡、咽痛（紫金锭） |
| **条剂** | 药末加赋形剂搓成线香状药条，外用插入疮口 | 外科瘘管、窦道化腐引流 |
| **线剂** | 药线（丝线或棉线浸药）结扎/引流 | 痔瘘挂线、引流 |
| **洗剂** | 药液外洗 | 皮肤病、痔疮、阴痒 |
| **搽剂** | 药液外搽涂擦 | 风湿骨痛、跌打扭伤 |
| **熏剂** | 药物燃烧或加热熏蒸患处/穴位 | 湿疮、关节痛、艾灸类 |
| **坐药（栓剂）** | 药物制成栓状纳入阴道/肛门/鼻腔等腔道 | 阴道炎、痔疮（如野菊花栓） |
| **导药（导法）** | 药液（如蜜煎导）灌肠或纳入肛内导便 | 津亏便秘（蜜煎导方为最早导法记载） |

### 4.2 现代剂型
- **颗粒剂（配方颗粒/冲剂）**：单味或复方提取物制粒，沸水冲服，兼有汤剂吸收较快与成药便捷的优点，是目前"代煎汤剂"的主流形式之一。
- **胶囊剂**：药物粉末/提取物装胶囊，掩盖不良气味，稳定性好（如藿香正气软胶囊）。
- **片剂**：剂量准确、便于携带（如银翘解毒片）。
- **口服液/合剂/糖浆剂**：服用方便，适于儿童及口感要求（如急支糖浆）。
- **滴丸**：起效快、生物利用度高（如复方丹参滴丸、藿香正气滴丸，舌下含服数分钟起效）。
- **注射剂**：起效最快，用于急危重症（如参附注射液、生脉注射液、清开灵注射液）；**必须在医疗机构由专业人员使用**，过敏风险高于口服剂型。
- **气雾剂/贴膏/凝胶**等外用新剂型。

## 5. 汤剂的优势与煎服要点

**优势**：
1. **吸收快、起效迅速**——水溶性成分直接入血发挥药效。
2. **可随证加减**——实现"一人一方、一时一方"，最贴合辨证论治个体化需求。
3. 剂量比例可灵活调整，便于体现君臣佐使的动态配伍。

**煎服要点（供知识库科普模块）**：
- 解表剂宜武火急煎，芳香易挥发之品（薄荷、砂仁、豆蔻）宜后下；金石贝壳类（石膏、龙骨、牡蛎）宜先煎；附子宜久煎（先煎30-60分钟以上减毒）；芒硝烊化冲服；阿胶烊化。
- 一般煎前冷水浸泡30-60分钟；一剂药煎2-3次合并分服。
- 服药时间：补益剂宜饭前服，驱虫泻下剂宜空腹服，对胃有刺激者宜饭后服；安神剂宜睡前服。
- 服药温度：一般温服；解表剂热服并覆被取汗；寒药治热证宜凉服，热药治寒证宜热服；真热假寒证寒药热服（反佐服法）。

## 6. 中成药使用规范

1. **辨证使用**：中成药同样必须辨证。风寒感冒误用辛凉清热药（如双黄连）会冰遏表邪、加重病情；风热感冒误用辛温发散药（如风寒感冒颗粒）则助热生火、咽喉肿痛加剧。
2. **阅读说明书**：注意功能主治、证型、禁忌、不良反应；"禁忌"（绝对不能用）与"慎用"（权衡后遵医嘱）含义不同。
3. **特殊人群**：
   - 孕妇：含活血、峻下、破气、滑利及毒剧成分者禁用（如麝香、大黄、桃仁、红花类）；妊娠前三个月尤须谨慎；标明"孕妇禁用"绝对不用。
   - 儿童：2岁以下不建议自行服用止咳抗感冒类中成药，6岁以下慎用，均须医师指导并减量。
   - 老人、肝肾功能不全者：含朱砂（汞）、雄黄（砷）的制剂（安宫牛黄丸、朱砂安神丸等）不可过量久服。
4. **配伍与联用**：避免含"十八反、十九畏"成分的中成药联用；避免与西药随意同服（如藿香正气水与头孢类同用可致双硫仑样反应）；中西药联用一般间隔至少30分钟-1小时。
5. **疗程**：中病即止（如解表药汗出热退即停），不宜长期服用同一中成药；服药期间忌生冷、油腻、辛辣、烟酒。
6. **含毒剧药材管理**：含罂粟壳（如强力枇杷露、真人养脏汤类）、马钱子、川乌、草乌、雄黄、朱砂、蟾酥等的成药，须严格遵医嘱，不可自行购买长期使用。
7. **急重症提示**：胸痛持续不缓解、高热惊厥、昏迷等，应立即拨打急救电话就医，中成药（如速效救心丸）仅作送医前应急使用。
