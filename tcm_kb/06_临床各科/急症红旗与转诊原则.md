# 急症处理与转诊原则（AI问诊安全的关键）

## 1. 必须立即建议就医／急诊的红旗症状总清单

### （1）立即拨打120／急诊（危及生命）【level: emergency】

| 系统 | 红旗症状 | 可能疾病 | 处置要点 |
|---|---|---|---|
| 心血管 | **胸痛胸闷持续>15～20分钟不缓解**，压榨感紧缩感，向左臂、下颌、后背、上腹放射；伴大汗、恶心、濒死感、面色苍白、晕厥 | 急性心肌梗死、不稳定型心绞痛 | 立即停止活动静卧、含服硝酸甘油（血压允许时）、立即120；勿自行驾车去医院 |
| 神经 | **口角歪斜、单侧肢体无力麻木、言语含糊、视物成双、剧烈眩晕伴行走不稳**（FAST原则：脸-臂-语，任一阳性） | 急性脑卒中 | 记录发病时间，立即120（时间窗内溶栓取栓）；勿"等它自己好"、勿扎针放血 |
| 神经 | **突发"一生中最剧烈"的爆炸样头痛**、或头痛伴喷射性呕吐、颈项强直、意识障碍 | 蛛网膜下腔出血、脑出血、脑膜炎 | 立即120，保持气道通畅头偏一侧 |
| 呼吸 | **严重呼吸困难、口唇发绀、端坐呼吸、说话不能成句、喘息持续不缓解** | 哮喘持续状态、气胸、心衰、肺栓塞 | 立即120；哮喘者可用急救吸入剂 |
| 消化 | **呕血、大量便血／黑便伴心慌冷汗晕厥** | 上消化道大出血 | 禁食、立即120 |
| 妇产 | **停经＋剧烈腹痛（尤其单侧）＋阴道流血或晕厥** | 异位妊娠破裂（宫外孕） | 立即120，育龄女性腹痛必问月经史 |
| 妇产 | **孕期阴道流血、流液（早破水）、剧烈腹痛、头痛眼花抽搐** | 流产、胎盘早剥、子痫 | 立即急诊产科 |
| 过敏 | **皮疹伴声嘶、吞咽呼吸困难、面部口唇重度肿胀、头晕血压下降** | 过敏性休克、喉头水肿 | 立即120；肌注肾上腺素（有条件时） |
| 代谢 | **意识模糊、呼气烂苹果味、恶心呕吐腹痛（糖尿病者）；或心慌大汗手抖进而昏迷** | 糖尿病酮症酸中毒／高渗；低血糖昏迷 | 立即120；低血糖清醒者速给糖 |
| 儿科 | **高热惊厥>5分钟或反复发作、精神萎靡、呼吸急促鼻煽三凹征发绀、前囟凸起或明显凹陷（脱水）** | 肺炎重症、颅内感染、脱水 | 立即急诊；惊厥时侧卧防误吸 |
| 儿外科 | **婴儿阵发性哭闹＋呕吐＋果酱样血便／腹部包块** | 肠套叠 | 立即急诊（时间窗内空气／水压灌肠复位） |
| 外科 | **外伤大出血、开放性骨折、胸部重击后呼吸困难** | 创伤 | 压迫止血、制动、立即120 |

### （2）24小时内尽快就医（可能严重或需尽快确诊）【level: urgent】

- 高热≥39℃持续不退，或发热超过3天不缓解，或老人／婴幼儿／孕妇／免疫低下者发热。
- 剧烈腹痛持续>6小时不缓解、或伴板状腹（穿孔）、转移性右下腹痛（阑尾炎）、停止排便排气（肠梗阻）、黄疸伴发热（胆道感染）。
- 水肿＋尿量明显减少＋恶心呕吐（肾功能恶化）；尿频尿急尿痛＋高热腰痛（急性肾盂肾炎）。
- 咳嗽咯血、反复鼻衄不止、皮肤大片瘀斑；无痛性全程肉眼血尿（泌尿系肿瘤）；排便习惯改变、便血、大便变细（肠癌筛查）。
- 进行性消瘦（6个月内体重下降>5%）、乏力贫血、无痛性进行性黄疸（肝胆胰肿瘤）、体表肿块迅速增大。
- 持续心悸伴黑矇晕厥；新发或加重的双下肢水肿伴夜间不能平卧（心衰）。
- 头痛进行性加重伴视物模糊／呕吐（颅内压增高）；新发剧烈眩晕伴耳鸣听力骤降（突发性耳聋72小时黄金期）。
- 40岁以上新发上腹痛／规律改变、吞咽困难（胃镜）；**绝经后任何阴道出血（子宫内膜癌排查）**；**接触性出血（宫颈癌筛查）**。
- 精神行为异常、自伤自杀念头、癫痫发作（首次或频率改变）。
- 关节红肿热痛伴高热（化脓性关节炎）；糖尿病足破溃。
- 动物咬伤（狂犬病风险，须规范处置与疫苗接种）、烧烫伤（面积大或深度者）。

### （3）建议门诊明确诊断后再行中医调理（不可先入为主按"功能病"处理）【level: see_doctor】

- 慢性咳嗽>2～3周（胸片／CT）、慢性腹泻与便秘交替（肠镜）、长期低热盗汗消瘦（结核／肿瘤筛查）。
- 月经紊乱（先验孕＋性激素＋超声）、不孕（夫妇同查）、带下异常（白带常规）。
- 甲状腺肿大结节（甲功＋超声分级）、乳腺肿块（乳腺超声／钼靶）、腹部包块（影像）。
- 贫血貌、反复出血倾向（血常规＋凝血）、长期乏力（甲功、血糖、肝肾功能）。

## 2. AI问诊场景的安全话术要点

1. 回答前先筛查红旗症状（本清单）；命中即优先输出就医建议，并说明"为什么"与"去哪个科"。
2. 辨证信息不全时（舌象脉象缺无），说明辨证局限，仅提供方向性建议，建议面诊。
3. 所有方药表述附带"须执业中医师辨证指导"声明；不主动给出具体剂量。
4. 孕妇、哺乳期、婴幼儿、老人、肝肾功能不全者用药，一律升级为"必须就医"。
5. 中西药同用提醒相互作用（典型：消渴丸含格列本脲、华法林与丹参当归、贯叶连翘制剂与多种西药；含朱砂雄黄制剂不可久服）。
6. 拒绝回答"能否替代医院治疗／停西药"的诱导，明确表示不能替代。

## 3. 治未病与慢病调理的适用边界（摘要）

详见《肿瘤辅助与治未病边界》：
- **中医优势区**：未病先防（体质调理）、既病防变（慢病稳定期协同）、瘥后防复、功能性疾病症状管理、慢病共病整体调理。
- **红线区（不可替代现代医学）**：急危重症、感染重症与法定传染病、恶性肿瘤根治性治疗、精神分裂症／双相／中重度抑郁／癫痫、需外科手术疾病、孕产急症与全部妊娠期用药、任何病因未明的进行性症状（先诊断后调理）。
