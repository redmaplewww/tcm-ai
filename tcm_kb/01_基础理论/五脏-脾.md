# 脾

脾为“**仓廪之官，五味出焉**”，属土，阴中之至阴，与胃共为“后天之本”。

## 主要生理功能

### 主运化

脾将饮食水谷化为精微并将精微转输全身。

- **运化水谷（食物）**：消化吸收，化生气血，故脾为“**气血生化之源**”“**后天之本**”。
- **运化水液（水湿）**：吸收、输布水液，防止水湿停聚。脾虚生湿、湿困脾运，互为因果。

### 主统血

脾气统摄血液在脉中运行，防止逸出脉外。脾不统血则便血、尿血、崩漏、肌衄（皮下出血）等慢性出血。

### 脾气主升

- **升清**：将水谷精微上输心肺头目，“脾以升为健”。
- **升举内脏**：维持内脏位置的相对恒定。脾气下陷（中气下陷）则内脏下垂（胃下垂、肾下垂、脱肛、子宫脱垂）。

## 生理特性

脾气主升、喜燥恶湿（“脾恶湿”，湿邪易困阻脾阳）。

## 脾的系统联系

| 项目 | 内容 |
|---|---|
| 在体合肉、主四肢 | 脾运化水谷精微充养肌肉四肢，脾虚则肌肉消瘦、四肢乏力 |
| 其华在唇 | 口唇色泽反映脾之盛衰 |
| 开窍于口 | 食欲口味与脾相关，脾热口甘、脾虚口淡乏味 |
| 在志为思 | 思虑过度伤脾（思则气结），致不思饮食、脘腹胀闷 |
| 在液为涎 | 涎为口津，脾虚失约则口涎自出 |
| 表里关系 | 脾与胃相表里（足太阴脾经与足阳明胃经） |
