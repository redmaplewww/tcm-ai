# 阴阳学说

## 阴阳的基本概念

**定义**：阴阳是宇宙中相互关联的事物或现象对立双方属性的概括。它既可以标示相互对立的事物或现象（如天与地、水与火），又可以标示同一事物内部对立的两个方面（如气与血、脏与腑）。

阴阳是中国古代哲学的一对重要范畴，最初含义指日光的向背（向日为阳，背日为阴），后引申为一切相互对立、相互关联的属性范畴。

## 阴阳的属性划分

划分标准：**凡运动的、外向的、上升的、温热的、明亮的、兴奋的、无形的属阳；凡静止的、内守的、下降的、寒凉的、晦暗的、抑制的、有形的属阴。**

| 属性 | 阳 | 阴 |
|---|---|---|
| 方位 | 上、外、左、南、天 | 下、内、右、北、地 |
| 时间 | 白昼、春夏 | 黑夜、秋冬 |
| 温度 | 温热 | 寒凉 |
| 光亮 | 明亮 | 晦暗 |
| 运动状态 | 动、升、兴奋、亢进 | 静、降、抑制、衰退 |
| 形态 | 无形 | 有形 |

**要点**：

1. **阴阳的相对性**：阴阳属性不是绝对的，可通过与对立面比较而确定；在一定条件下可相互转化；阴阳之中复有阴阳（如昼为阳、上午为阳中之阳、下午为阳中之阴）。
2. **阴阳的无限可分性**：“阴阳者，数之可十，推之可百……”。
3. **划分的前提是相互关联**：不相关联的事物无法分阴阳。

## 阴阳学说的基本内容

### 阴阳对立制约

阴阳双方相互对立、相互制约、相互消长。如寒与热、动与静相互制约；自然界寒暑消长；人体阴阳相互制约维持“阴平阳秘”。

- 病理应用：阴阳制约不足则一方偏盛（阳盛则热、阴盛则寒）；治疗“寒者热之、热者寒之”即以制约为据。

### 阴阳互根互用

阴阳双方相互依存、互为根本，任何一方都不能脱离另一方而单独存在。

- “孤阴不生，独阳不长”；“无阳则阴无以生，无阴则阳无以化”。
- **互用**：相互对立的阴阳双方相互资生、促进。典型如**气与血**：气无形而动属阳，血有形而静属阴；气能生血、行血、摄血，血能载气、养气（“气为血之帅，血为气之母”）。
- 病理：阴损及阳、阳损及阴，最终阴阳互损；“阴中求阳、阳中求阴”治法即据此而设。

### 阴阳交感互藏

- **交感**：阴阳二气在运动中相互感应而交合。天气下降、地气上升，天地交感化生万物（“二气交感，化生万物”）；人体心肾相交即阴阳交感的体现。
- **互藏**：阴阳双方中的任何一方都蕴含着另一方，阳中含阴、阴中含阳。互藏是交感相错的动力根源，也是阴阳转化的内在依据。

### 阴阳消长平衡

阴阳双方处于不断的增长或消减的运动变化之中，并在一定范围内维持动态平衡。

- 形式：**阴消阳长、阳消阴长**（互为消长，由对立制约导致）；**阴阳皆长、阴阳皆消**（互为消长，由互根互用导致）。
- 生理举例：四季寒暑更替、昼夜阴阳消长、人体阳气“平旦生、日中隆、日西虚”。
- 病理：消长超越正常限度即出现阴阳偏盛偏衰。

### 阴阳相互转化

对立互根的阴阳双方，在一定条件下可以向其相反的方向转化。

- 条件：“物极”阶段、“重”或“甚”的程度——“**重阴必阳，重阳必阴**”“**寒极生热，热极生寒**”“重寒则热，重热则寒”。
- 病理举例：外感寒邪入里化热（寒证转热证）；高热病人大汗后阳随汗泄转见面色苍白、四肢厥冷（热证转寒证）。

> **附：阴阳自和**——阴阳双方自动维持和恢复其协调平衡状态的趋势与能力，是疾病自愈的内在机制。

## 阴阳学说在中医学中的应用

### 说明人体的组织结构

| 部位 | 属阳 | 属阴 |
|---|---|---|
| 身躯 | 上部、背部、体表、四肢外侧 | 下部、腹部、体内、四肢内侧 |
| 脏腑 | 六腑 | 五脏（心为“阳中之阳”，肺“阳中之阴”，肝“阴中之阳”，肾“阴中之阴”，脾“阴中之至阴”） |
| 经络 | 十二正经中手足三阳经 | 手足三阴经；督脉为阳，任脉为阴 |
| 气血津液 | 气（无形而动） | 血、津液（有形而静） |

### 说明人体的生理功能

- “阴平阳秘，精神乃治；阴阳离决，精气乃绝”——健康是阴阳协调的动态平衡。
- 物质与功能的对立统一：阴精（物质基础）与阳气（功能活动）互根互用。

### 阐释疾病的病理变化

| 病机 | 含义 | 表现 | 证候性质 |
|---|---|---|---|
| **阳盛则热** | 阳邪亢盛，热象突出 | 高热、面红、烦渴、脉洪数 | 实热证 |
| **阴盛则寒** | 阴邪亢盛，寒象突出 | 畏寒肢冷、脘腹冷痛、脉沉迟 | 实寒证 |
| **阳虚则寒** | 阳气亏虚，温煦失职 | 畏寒喜暖、肢冷踡卧、神疲、脉迟无力 | 虚寒证 |
| **阴虚则热** | 阴液亏虚，虚热内生 | 五心烦热、潮热盗汗、颧红、脉细数 | 虚热证 |
| **阴阳互损** | 阴损及阳、阳损及阴，终致阴阳两虚 | 阳虚日久累及阴液、阴虚日久累及阳气 | 阴阳两虚证 |
| **阴阳格拒** | 阴盛格阳→真寒假热（面红如妆、身反不恶寒）；阳盛格阴→真热假寒（热深厥深） | 假象与本质不符 | 重证 |
| **阴阳亡失** | 亡阳（大汗淋漓、四肢厥冷、脉微欲绝）；亡阴（汗出如油、烦躁、身热） | 生命垂危 | 危重证 |

### 指导疾病的诊断

- **阴阳是八纲辨证的总纲**：表、热、实属阳；里、寒、虚属阴。
- 望诊：色泽鲜明属阳，晦暗属阴。
- 闻诊：声高气粗属阳，声低息微属阴。
- 切诊：寸口脉部位分寸（阳）、关、尺（阴）；脉至浮、数、滑、实属阳，沉、迟、涩、虚属阴。
- “善诊者，察色按脉，先别阴阳”——审别阴阳是诊断的总纲领。

### 指导疾病的治疗

1. **确定治疗原则**
   - **阴阳偏盛（实证）——损其有余（实则泻之）**：阳盛则热→“热者寒之”（清热）；阴盛则寒→“寒者热之”（散寒）。若阳盛伤阴或阴盛伤阳，应兼顾其虚（清热兼滋阴、散寒兼助阳）。
   - **阴阳偏衰（虚证）——补其不足（虚则补之）**：阴虚不能制阳（虚热）→滋阴以制阳，“**壮水之主，以制阳光**”（阳病治阴）；阳虚不能制阴（虚寒）→扶阳以抑阴，“**益火之源，以消阴翳**”（阴病治阳）。根据阴阳互根，可“**阴中求阳**”“**阳中求阴**”（张景岳：“善补阳者，必于阴中求阳，则阳得阴助而生化无穷”）。
   - **阴阳双补**、**回阳救逆**、**救阴固脱**用于阴阳两虚、亡阳亡阴。
2. **概括药物性能（药性分阴阳）**
   - **四气**：温、热属阳；寒、凉属阴。
   - **五味**：辛、甘（淡）属阳；酸、苦、咸属阴。
   - **升降浮沉**：升、浮属阳；降、沉属阴。
