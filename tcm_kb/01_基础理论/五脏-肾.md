# 肾

“肾者主蛰，封藏之本，精之处也。”肾属水，阴中之阴，为“**先天之本**”。

## 主要生理功能

### 藏精，主生长发育、生殖与脏腑气化

- 肾精包括**先天之精**（禀受父母，生育繁殖之源）与**后天之精**（水谷精微充养）。
- **主生长发育**：齿、骨、发的生长与肾精盛衰相关——女子七岁肾气盛更换牙齿，二七天癸至月事以时下……男子八岁肾气实，二八天癸至精气溢泻（《素问·上古天真论》）。
- **主生殖**：天癸（肾精充盛到一定程度产生的促生殖物质）的至与竭决定生殖能力盛衰。
- **主脏腑气化**：肾阴肾阳为一身阴阳之根本——“**命门**”学说：“五脏之阴气，非此不能滋；五脏之阳气，非此不能发”。故肾为“**先天之本**”。

### 主水

肾气主司和调节全身水液代谢（肾的气化作用贯穿水液代谢始终——蒸腾气化、升清降浊、司膀胱开合）。

### 主纳气

肾摄纳肺所吸入的清气，防止呼吸表浅。“**肺为气之主，肾为气之根**”，肾不纳气则呼多吸少、动则喘甚。

## 肾的系统联系

| 项目 | 内容 |
|---|---|
| 在体合骨、主骨生髓 | 肾精生髓养骨，肾精不足则小儿囟门迟闭、骨软无力，成人骨质脆弱 |
| 其华在发 | “发为血之余”，肾其华在发，肾虚发白早脱 |
| 开窍于耳及二阴 | 肾精亏虚则耳鸣耳聋；前阴司排尿与生殖，后阴司排泄，肾气不固则尿频遗尿、五更泄泻 |
| 在志为恐 | 恐伤肾，“恐则气下”，遗尿滑精 |
| 在液为唾 | 唾为肾精所化，咽唾可养肾精 |
| 表里关系 | 肾与膀胱相表里（足少阴肾经与足太阳膀胱经） |
| 脑与齿 | “脑为髓之海”，肾生髓通脑；“齿为骨之余”，肾虚齿摇 |
