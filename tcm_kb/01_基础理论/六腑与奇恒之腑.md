# 六腑

## 胆

- **贮藏与排泄胆汁**：胆汁由肝之余气化生，胆排泄胆汁助脾胃运化（肝主疏泄控制其排泄）。
- **主决断**：胆主判断决定，与勇怯相关（“胆怯”则善惊易恐、失眠多梦）。
- 胆形态中空属六腑，但贮藏胆汁（精汁）不受传水谷，又属**奇恒之腑**——胆为“中正之官，决断出焉”。

## 胃

- **主受纳、腐熟水谷**：胃接受容纳饮食并初步消化，故称“**水谷之海**”，为“仓廪之官，五味出焉”（与脾共称）。
- **胃主通降、以降为和**：胃气下行传小肠大肠。胃失和降则恶心呕吐、嗳气呃逆。
- 生理特性：**喜润恶燥**（与脾喜燥恶湿相对）。
- **胃气**的重要性：“人有胃气则生，无胃气则死”，诊脉须察胃气之有无。

## 小肠

- **主受盛化物**：接受胃下传的食糜进一步消化（化物）。
- **主泌别清浊**：将食糜分为精微（吸收，经脾转输）与糟粕（食物残渣下传大肠，水液渗入膀胱）。
- **小肠主液**：小肠泌别清浊参与水液代谢，“利小便所以实大便”（分利水湿治泄泻）之依据。

## 大肠

- **主传化糟粕（主津）**：接收小肠食物残渣，吸收多余水分（燥化），形成粪便排出。大肠虚寒则泄泻，大肠实热则大便秘结。

## 膀胱

- **贮尿排尿**：膀胱气化排泄尿液。“膀胱者，州都之官，津液藏焉，气化则能出矣”。膀胱失约则尿频遗尿，膀胱气化不利则癃闭（小便不通）。

## 三焦

- **概念**：分布于胸腹腔的一个大腑（“孤府”），是上焦、中焦、下焦的合称，为元气通行与水液运行的通道。
- **主持诸气，通行元气**：元气根于肾，经三焦布达全身。
- **运行水液（水道）**：“三焦者，决渎之官，水道出焉”——水液代谢的通道。
- **部位划分及其功能特点**：
  - **上焦如雾**（横膈以上，心肺敷布气血津液如雾露之溉）。
  - **中焦如沤**（膈至脐，脾胃腐熟运化水谷如发酵之状）。
  - **下焦如渎**（脐以下，肾膀胱大肠排泄糟粕水液如沟渠）。

# 奇恒之腑

| 奇恒之腑 | 功能要点 |
|---|---|
| 脑 | “脑为髓之海”“元神之府”，主精神思维、感觉运动。但中医脏象学说以心统神，脑的功能分属五脏（心藏神、肝藏魂、肺藏魄、脾藏意、肾藏志） |
| 髓 | 骨髓、脊髓、脑髓，肾精所化，养骨充脑 |
| 骨 | 肾主骨，骨架支撑、藏髓 |
| 脉 | “脉为血之府”，气血运行通道，心主脉 |
| 胆 | 藏胆汁，兼具腑与奇恒之腑双重身份 |
| 女子胞（子宫） | 主持月经、孕育胎儿。与肾及天癸、冲任二脉（“冲为血海，任主胞胎”）、心肝脾（血液调节）关系密切 |

# 脏腑之间的关系

## 脏与脏的关系（择要）

| 关系 | 主要内容与生理联系 | 病理举例 |
|---|---|---|
| **心与肺** | 心主血、肺主气；宗气贯心脉行血。气为血之帅，血为气之母 | 肺气虚致心血瘀阻（咳喘伴心悸唇紫） |
| **心与脾** | 血液生成（脾为气血生化之源）与血液运行（心行血、脾统血） | 心脾两虚：心悸失眠+食少倦怠、月经过多 |
| **心与肝** | 血液（肝藏血调节血量、心主行血）与神志（心主神、肝调情志） | 心肝血虚：失眠多梦、视物模糊 |
| **心与肾** | **心肾相交（水火既济）**：心火下温肾水，肾水上济心火；精神互用；君相安位 | 心肾不交：失眠、心烦、腰膝酸软 |
| **肺与脾** | 气的生成（肺主呼吸之气+脾主水谷之气）；水液代谢（脾运化+肺通调） | 脾肺气虚：咳喘痰多清稀、食少便溏 |
| **肺与肝** | 气机升降协调：肝气升发、肺气肃降 | 肝火犯肺（木火刑金）：胁痛咳血 |
| **肺与肾** | 水液代谢（肺为水之上源、肾为主水之脏）；呼吸（肺为气之主、肾为气之根）；金水相生（阴液互滋） | 肺肾阴虚：干咳、潮热盗汗 |
| **肝与脾** | 肝主疏泄助脾运化（木疏土）；肝藏血、脾统血 | 肝脾不调：情绪波动后腹痛泄泻；肝不藏血与脾不统血并见出血 |
| **肝与肾** | **肝肾同源（乙癸同源、精血同源）**；藏泄互用；阴阳互滋互制 | 肝肾阴虚：头晕目眩、耳鸣、腰膝酸软 |
| **脾与肾** | 先天后天相互资生：肾精赖水谷充养，脾阳赖肾阳温煦 | 脾肾阳虚：五更泄泻、水肿 |
| **肝与肺、脾与胃等升降相因** | 脾主升清、胃主降浊；肝升肺降，共同调畅气机 | 升降失常则呕恶、泄泻并见 |

## 腑与腑的关系

六腑以“传化物”为共同功能，虚实交替、通降为顺——饮食的消化、吸收、排泄是六腑分工协作、连续过程（胃受纳腐熟→小肠受盛化物泌别清浊→大肠传化糟粕；胆汁助消化；膀胱与三焦司水液）。“**六腑以通为用，以降为顺**”。

## 脏与腑的关系（表里关系）

一脏一腑、一阴一阳、一表一里，通过经脉互相络属配合：

| 脏（里，阴） | 腑（表，阳） | 生理配合 | 病理举例 |
|---|---|---|---|
| 心 | 小肠 | 心阳温煦小肠，小肠泌别清浊 | 心移热于小肠：口舌生疮+小便赤涩灼痛（导赤散证） |
| 肺 | 大肠 | 肺气肃降助大肠传导，大肠通畅利于肺气肃降 | 腑气不通加重咳喘；通便可平喘（肺与大肠相表里） |
| 脾 | 胃 | 脾主运化升清、胃主受纳降浊，燥湿相济，共为后天之本 | 脾胃不和：食少、呕吐、腹胀便溏 |
| 肝 | 胆 | 肝主疏泄分泌胆汁，胆依附于肝排泄胆汁；肝主谋虑、胆主决断 | 肝胆湿热：黄疸、胁痛、口苦 |
| 肾 | 膀胱 | 肾气固摄与气化控制膀胱开合 | 肾气不固则遗尿；肾阳虚气化不利则癃闭 |
| 心包 | 三焦 | 经脉相络属 | —— |
