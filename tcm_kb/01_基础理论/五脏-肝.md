# 肝

肝为“**刚脏**”，主升主动，体阴而用阳，属木，阴中之阳。

## 主要生理功能

### 主疏泄

肝气具有疏通、条达、升发、畅泄气机的作用，表现为：

1. **调畅气机**：气的升降出入有序。肝失疏泄则气机郁滞（胸胁胀痛）或升发太过（肝气上逆、肝阳上亢）。
2. **促进脾胃运化与胆汁分泌排泄**：协调脾胃升降，分泌排泄胆汁助消化。
3. **调畅情志**：情志活动以气机调畅为基础，“肝喜条达而恶抑郁”。
4. **调节生殖功能**：调理冲任，调节女子月经与男子排精（“女子以肝为先天”）。
5. **调节津血运行**：气行则血行津布。

### 主藏血

肝贮藏血液、调节血量、防止出血。

- “人卧血归于肝”（动则血运于诸经，静则血归于肝脏）。
- 肝藏血失职则月经量多甚则崩漏；肝血不足则目涩视物模糊、肢体麻木、月经量少。

## 生理特性

肝为“**刚脏**”，主升主动，体阴而用阳；为“**罢极之本**”（耐受疲劳的根本）。

## 肝的系统联系

| 项目 | 内容 |
|---|---|
| 在体合筋 | 肝血养筋，“膝为筋之府”；肝血虚则筋脉拘急、肢体麻木、手足震颤；热极生风则四肢抽搐、角弓反张 |
| 其华在爪 | “爪为筋之余”，肝血盛衰可察爪甲荣枯 |
| 开窍于目 | “肝受血而能视”，肝血不足则目涩夜盲；肝经风热则目赤痒痛 |
| 在志为怒 | 怒伤肝，“怒则气上”，肝阳上亢易怒 |
| 在液为泪 | 肝血不足则两目干涩；肝经湿热则目眵增多、流泪 |
| 表里关系 | 肝与胆相表里（足厥阴肝经与足少阳胆经） |
