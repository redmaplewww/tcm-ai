# 心

心为“**君主之官，神明出焉**”（“主明则下安”），为“五脏六腑之大主”，属火，阳中之阳。

## 主要生理功能

### 主血脉

包括主血与主脉两方面。

- 心气推动血液在脉中运行，输送营养全身。
- 生理表现：面色红润光泽、舌色淡红荣润、脉象和缓有力、心胸畅达。
- 病理：心气虚则面色无华、脉细弱或结代；心血瘀阻则面色晦暗、唇舌紫暗、心前区刺痛。

### 主藏神（心主神明）

心具有主宰人体生命活动及精神意识思维活动的功能。

- 广义之神（生命活动总宰）与狭义之神（精神思维情志）皆总统于心。
- 病理：心神不宁则失眠多梦；痰迷心窍则神昏癫狂。

## 心的系统联系

| 项目 | 内容 |
|---|---|
| 在体合脉 | 全身血脉皆属于心 |
| 其华在面 | 心气血盛衰可从面部色泽反映 |
| 开窍于舌 | “心开窍于舌”“舌为心之苗”，心病可见舌疮、舌强语謇 |
| 在志为喜 | 喜有益心，过喜则伤心（喜则气缓） |
| 在液为汗 | “汗为心之液”，心气虚自汗，心阴虚盗汗 |
| 表里关系 | 心与小肠相表里（手少阴心经与手太阳小肠经互相络属） |

## 附：心包络（心包）

心外之膜，护心代心受邪，“心不受邪，包络代受”。
