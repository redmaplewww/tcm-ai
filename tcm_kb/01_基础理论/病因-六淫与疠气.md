# 病因学说概述

**定义**：病因是导致疾病发生的原因，又称致病因素。中医探求病因的方法主要是“**审证求因**”（辨证求因）——根据疾病的临床表现反推病因。

**病因分类**（现代教材分类法）：

| 类别 | 主要内容 |
|---|---|
| 外感病因 | 六淫、疠气 |
| 内伤病因 | 七情内伤、饮食失宜、劳逸失度 |
| 病理产物性病因 | 痰饮、瘀血、结石 |
| 其他病因 | 外伤、诸虫（寄生虫）、药邪、医过、先天因素 |

（内伤病因与病理产物性病因详见《病因-内伤与病理产物.md》）

# 六淫

**定义**：风、寒、暑、湿、燥、火（热）六种正常的自然气候称“**六气**”；当六气发生太过、不及，或非其时而有其气（如春应温而反寒），以及气候变化过于急骤，人体正气不足、抵抗力下降时，六气成为致病因素，称“**六淫**”（淫，太过、侵淫之意），又称“六邪”。

## 六淫致病的共同特点

1. **外感性**：多从肌表、口鼻侵入，所致疾病统称“外感病”，发病初多见表证。
2. **季节性**：春季多风病、夏季多暑病、长夏多湿病、秋季多燥病、冬季多寒病。
3. **地域性**：西北多燥病、东南多湿热病、久居潮湿多湿病。
4. **相兼性**：两种以上病邪同时侵犯人体（风寒感冒、风寒湿痹、湿热泄泻）。
5. **转化性**：在一定条件下可相互转化（寒邪入里化热、湿郁化热）。

## 风邪

| 致病特点 | 释义与表现 |
|---|---|
| **风为阳邪，其性开泄，易袭阳位** | 风性轻扬升散，善行数变，使腠理开泄；常侵犯头面（头痛、口眼歪斜）、肌表（汗出、恶风）、阳经 |
| **风性善行而数变** | 病位游走不定（风痹/行痹，关节游走疼痛）；发病急、变化快（风疹块骤起骤消） |
| **风性主动** | “风胜则动”，可见眩晕、震颤、抽搐、颈项强直（如破伤风角弓反张） |
| **风为百病之长** | 风邪为六淫中最主要致病因素，是外邪致病的先导，寒湿燥热多依附于风而侵袭人体（风寒、风热、风湿）；风邪致病最多、最广 |

## 寒邪

| 致病特点 | 释义与表现 |
|---|---|
| **寒为阴邪，易伤阳气** | “阴胜则阳病”，寒邪最易损伤阳气；外寒伤肌表卫阳（恶寒），直中脾胃伤脾阳（脘腹冷痛、呕吐泄泻），心肾阳衰（畏寒踡卧） |
| **寒性凝滞** | 寒邪使气血凝结阻滞，不通则痛——疼痛是寒邪致病的重要特征（“寒性凝滞而主痛”），如头身关节冷痛（痛痹/寒痹）、心脉痹阻真心痛 |
| **寒性收引** | 收缩牵引，气机收敛，腠理闭塞，经脉挛急——恶寒无汗、脉紧、肢体屈伸不利、筋脉拘挛抽搐 |

> “中寒”（直中）与“伤寒”（伤于肌表）之分；寒邪入里可化热（“入里化热”）。

## 暑邪

| 致病特点 | 释义与表现 |
|---|---|
| **暑为阳邪，其性炎热** | 夏季火热之气所化，伤人多见一派阳热症状：高热、心烦、面赤、脉洪大 |
| **暑性升散，易耗气伤津** | 升散即上升发散，致腠理开泄多汗；汗出过多则伤津（口渴喜饮、尿短黄），气随津泄则气虚（气短乏力、突然昏倒—中暑/暑厥） |
| **暑多挟湿** | 暑季气候炎热多雨潮湿，暑邪常兼挟湿邪（身热不扬、四肢困重、胸闷呕恶、便溏）——“暑必挟湿”之说 |
| **明显的季节性** | 暑邪独见于夏至以后、立秋以前，纯属外邪而无内暑（“暑无内伤”为一般说法） |

## 湿邪

| 致病特点 | 释义与表现 |
|---|---|
| **湿为阴邪，易阻气机，损伤阳气** | 湿性类水属阴，留滞脏腑经络，阻遏气机（胸闷脘痞、小便短涩、大便不爽）；湿邪最易困脾，损伤脾阳（泄泻、水肿） |
| **湿性重浊** | “重”即沉重、重着——头重如裹、周身困重、四肢酸楚沉重（湿痹/着痹）；“浊”即秽浊——分泌物排泄物秽浊不清（面垢、眵多、大便溏垢、下痢黏液、湿疹流水、妇女带下腥秽） |
| **湿性黏滞** | 一是症状的黏滞性（口黏口甜、舌苔腻、大便黏滞不爽、小便涩滞不畅）；二是病程的缠绵性（起病隐缓、病程较长、反复发作或缠绵难愈，如湿温、湿痹、湿疹） |
| **湿性趋下，易袭阴位** | 湿邪类水有下注之性，多伤人体下部（下肢水肿、下部疮疡、带下、淋浊）；“伤于湿者，下先受之” |

## 燥邪

| 致病特点 | 释义与表现 |
|---|---|
| **燥性干涩，易伤津液** | 燥邪伤人，津液亏耗，出现干涩症状：口鼻干燥、咽干口渴、皮肤干涩皲裂、毛发不荣、小便短少、大便干结 |
| **燥易伤肺** | 肺为娇脏、喜润恶燥，燥邪多从口鼻而入，最易耗伤肺津，宣降失司——干咳少痰、或痰黏难咯、痰中带血、喘息胸痛；“温燥”（初秋尚热，燥与热合）与“凉燥”（深秋近冬，燥与寒合）之分 |

## 火热邪

| 致病特点 | 释义与表现 |
|---|---|
| **火为阳邪，其性炎上** | 火热之邪燔灼亢奋，多见阳热症状（高热、恶热、烦渴、汗出、脉洪数）；火性趋上，尤易上扰神明、侵犯人体上部（心烦失眠、狂躁妄动、面红目赤、口舌生疮、牙龈肿痛） |
| **易扰神明** | 火热入营血扰心神，轻则心烦失眠，重则狂躁不安、神昏谵语 |
| **易伤津耗气** | 迫津外泄、消灼津液（口渴喜冷饮、咽干舌燥、小便短赤），“壮火食气”，热盛耗气（体倦乏力少气） |
| **易生风动血** | “热极生风”——高热伤津，筋脉失养，肝风内动（四肢抽搐、角弓反张、目睛上吊）；“火热迫血妄行”——灼伤血络，各种出血（吐血、衄血、便血、尿血、斑疹） |
| **易致肿疡** | 火热之邪入血聚于局部，腐蚀血肉发为痈肿疮疡（局部红肿热痛，“痈疽原是火毒生”） |
| **火性急迫** | 发病急骤，传变迅速 |

# 疠气

**定义**：疠气是一类具有强烈致病性和传染性的外感病邪，又称“疫毒”“疫气”“异气”“戾气”“毒气”（吴又可《温疫论》称“戾气”）。

**致病特点**：

1. **发病急骤，病情危笃**：疠气致病比六淫更猛烈，来势凶猛，变化多端。
2. **传染性强，易于流行**：可通过空气、食物、接触等多种途径在人群中传播（“无问老少，触之即病”）。
3. **一气一病，症状相似**：一种疠气引起一种疫病，同一疠气致病临床症状相似（如痄腮、霍乱、疫痢）。

**影响疠气产生的因素**：气候反常、环境破坏、饮食不洁、社会动荡、预防隔离不当等。

## 速查要点

| 项目 | 核心结论 |
|---|---|
| 六淫特点 | 风为百病之长、善行数变；寒性凝滞收引；暑性炎热升散耗气伤津挟湿；湿性重浊黏滞趋下；燥性干涩易伤肺；火性炎上生风动血致肿疡 |
