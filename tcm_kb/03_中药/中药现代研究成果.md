# 中药现代研究成果与标准化、道地药材

> 整理自源文件《03_中药学》第三章3.4、3.5。

## 一、现代药理学研究（简述）

1. **青蒿素（Artemisinin）**：屠呦呦（中国中医科学院中药研究所）在"523任务"（1967年启动的抗疟疾国家项目）中受《肘后备急方》"青蒿一握，以水二升渍，绞取汁"启发，于1971-1972年以低温乙醚提取法获得青蒿素，开创疟疾治疗新纪元；2015年获诺贝尔生理学或医学奖（中国首位）。衍生药双氢青蒿素、蒿甲醚、青蒿琥酯；青蒿素联合疗法（ACT）为WHO全球疟疾治疗指南推荐；近年拓展研究系统性红斑狼疮等适应证。
2. **三氧化二砷（砒霜，As2O3）**：张亭栋等1971年起以民间验方"癌灵注射液"（主要成分砒霜）研究治疗白血病，1973年报道、1979年明确对急性早幼粒细胞白血病（APL，M3型）疗效显著；陈竺、王振义、陈赛娟等阐明其分子机制（降解PML-RARa融合蛋白、诱导白血病细胞分化与凋亡），联合全反式维甲酸的方案使APL成为首个可基本治愈的白血病类型，5年生存率超过90%，获国际广泛认可，是"以毒攻毒"与现代医学结合的典范。
3. **小檗碱（黄连素）**：源于黄连、黄柏、三颗针等，传统清热燥湿药的现代代表；确证抗菌（肠道感染）作用，近20年研究发现其降血糖、调脂、改善胰岛素抵抗、调节肠道菌群及抗动脉粥样硬化等新用途，相关研究发表于国际期刊。
4. **丹参及其制剂**：丹参酮IIA、丹酚酸B等活性成分具抗心肌缺血、改善微循环、抗氧化作用；复方丹参滴丸（丹参、三七、冰片）为冠心病常用中成药，已完成美国FDA国际多中心III期临床试验（天士力集团），是中药国际化标志性事件。
5. **其他重要成果**：靛玉红（青黛提取物，治疗慢性粒细胞白血病）；雷公藤多苷（免疫抑制，治类风湿性关节炎、肾病）；黄芪多糖、人参皂苷（免疫调节、抗肿瘤辅助）；薏苡仁油制剂（康莱特，抗肿瘤辅助）；绞股蓝总苷（调脂）；青黛/雄黄/牛黄复方（砷剂复方）等。
6. **研究意义**：中药现代研究验证了传统功效的物质基础（如麻黄碱平喘、小檗碱抗菌、青蒿素截疟、砷剂治癌），同时推动安全性再评价（马兜铃酸、肝毒性、重金属限量），为循证中医药提供支撑。

## 二、《中国药典》与中药标准化

1. 《中华人民共和国药典》：1953年首版，此后大体每5年修订一次；2020年版（现行版）一部收载中药2711种（含药材饮片、植物油脂和提取物、成方制剂和单味制剂），整体收载品种5911种。
2. 质量标准内容：来源（基原）、性状、鉴别（显微、理化、薄层色谱）、检查（杂质、水分、总灰分、酸不溶性灰分、二氧化硫残留、重金属及有害元素限量、黄曲霉毒素、农药残留）、浸出物、含量测定（指标性成分定量）、炮制、性味与归经、功能与主治、用法与用量、注意等。
3. 配套规范：《中药材生产质量管理规范》（GAP，中药材种植养殖）、《药品生产质量管理规范》（GMP）、《中药炮制规范》（各省）、中药配方颗粒国家标准等。
4. 中药标准化趋势：从"指标成分控制"向"多成分整体控制+生物效价+DNA条形码鉴定"发展；指纹图谱/特征图谱广泛纳入标准。

## 三、道地药材

- **定义**：道地药材（geo-authentic crude drugs）指产于特定产区、历史悠久、品种优良、炮制考究、疗效突出、质量稳定的中药材，是"天、地、人、药"结合的质量概念（"药材好，药才好"）。
- **命名规律**：多以产地冠名（如川芎、广藿香、怀地黄、云三七、怀牛膝、杭白菊）。
- **经典产区与品种举例**：
  - 四大怀药（河南怀庆府）：怀地黄、怀山药、怀牛膝、怀菊花；
  - 浙八味（浙江）：白术、白芍、浙贝母、杭白菊、延胡索、玄参、笕麦冬、温郁金；
  - 川产道地药：黄连、川芎、附子、川贝母、麝香（川麝）；
  - 广药：广藿香、阳春砂仁、广陈皮、巴戟天；
  - 云药：三七、云木香、茯苓；
  - 关药（东北）：人参、鹿茸、五味子、关黄柏、细辛（辽细辛）；
  - 西北药：宁夏枸杞、青海大黄、内蒙古黄芪、甘肃当归（岷归）、新疆甘草；
  - 贵药：天麻、杜仲、吴茱萸（常吴萸）。
- **AI知识库要点**：药材基原与产地直接影响质量与安全（如防己品种混用致马兜铃酸事件），查询时应提示"优先选用道地药材与符合药典标准的饮片"。
