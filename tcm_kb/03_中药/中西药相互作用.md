# 中西药相互作用

> 整理自源文件《03_中药学》第三章3.3及附录中西药联用提示。供AI知识库联合用药风险提示使用。

## 一、常见中西药相互作用表

| 中药/成分 | 相互作用西药 | 机制与后果 | 处理建议 |
|-----------|--------------|-----------|----------|
| 丹参、当归、三七、银杏叶、红花等活血化瘀药 | 华法林、阿司匹林、氯吡格雷等抗凝抗血小板药 | 丹参酮竞争性置换蛋白结合使游离华法林升高；抑制CYP代谢；药效叠加致INR升高、出血风险显著增加（丹参、当归均有明确研究报道） | 尽量避免同用；必须同用时加强INR监测，告知医师 |
| 人参 | 华法林 | 可能诱导代谢、减弱抗凝效果（INR下降） | 同上 |
| 甘草及其制剂（甘草酸） | 噻嗪类利尿剂、呋塞米 | 假性醛固酮增多：排钾增加，低血钾风险 | 监测血钾，补钾 |
| 甘草 | 地高辛 | 低钾血症增强强心苷毒性（心律失常） | 监测血钾及地高辛浓度 |
| 甘草 | 降压药 | 甘草酸潴钠升压，拮抗降压效果 | 监测血压 |
| 麻黄（麻黄碱） | 单胺氧化酶抑制剂、拟交感胺类 | 升压相加，高血压危象风险 | 禁止同用 |
| 含鞣质中药（五倍子、地榆、大黄、诃子等） | 铁剂、钙剂、酶制剂（胃蛋白酶等）、生物碱类、抗生素 | 络合沉淀，吸收减少、酶失活 | 间隔1-2小时以上服用 |
| 朱砂（含汞） | 溴化钾、溴化钠、碘化钾 | 生成有毒汞盐（刺激性汞溴化物等） | 禁止同用 |
| 雄黄（含砷） | 酶制剂、亚硒酸钠 | 砷与酶蛋白巯基结合失活 | 避免同用 |
| 碱性中药（硼砂、海螵蛸、瓦楞子） | 四环素类、奎尼丁 | pH改变影响溶出吸收 | 间隔服用 |
| 含乙醇药酒 | 头孢类、甲硝唑、苯妥英等 | 双硫仑样反应/代谢干扰 | 禁止同用 |
| 苦杏仁、枇杷仁（氰苷） | 中枢抑制药 | 相加抑制 | 避免同用 |

## 二、通用原则

1. 中西药联用一般建议间隔至少1-2小时；
2. 就诊时患者应主动告知医师正在使用的全部中药、西药与保健品；
3. 治疗窗窄的药物（华法林、地高辛、环孢素、抗癫痫药等）联用中药必须监测血药浓度及相关指标。

## 三、AI联用提示要点（处方/咨询校验用）

1. 抗凝抗血小板药（华法林、阿司匹林）联用活血化瘀药（丹参、当归、三七、红花等）→ 出血风险警示；
2. 甘草制剂与利尿剂/地高辛 → 低血钾风险警示；
3. 麻黄与降压药、单胺氧化酶抑制剂 → 相互作用警示（升压相加，高血压危象风险，禁止与单胺氧化酶抑制剂同用）；
4. 含鞣质中药与铁剂、酶制剂等 → 建议间隔1-2小时以上服用；
5. 朱砂忌与溴化物、碘化物同服；雄黄避免与酶制剂、亚硒酸钠同用；药酒（含乙醇）禁与头孢类、甲硝唑同用。
