# 穴位详解·足三阳经（胃经、膀胱经、胆经）

> 本文件收录足三阳经常用穴：足阳明胃经45穴选12穴、足太阳膀胱经67穴选22穴（含八髎）、足少阳胆经44穴选13穴，共47穴。
> 全部针刺操作须由执业针灸医师进行；孕妇禁忌（合谷、昆仑等及腰骶腹部穴）、气胸危险区均已醒目标注（通用警示见 穴位-手三阴经.md）。

## 一、足阳明胃经（45穴，选12穴）

| 穴名 | 定位 | 主治 | 操作与安全提示 |
|---|---|---|---|
| 四白 ST2 | 面部，眶下孔处，目正视瞳孔直下 | 目赤痛痒、目翳、眼睑瞤动、口眼㖞斜、头痛眩晕、面痛（三叉神经痛） | 直刺或斜刺0.3~0.5寸。**不可深刺入眶** |
| 下关 ST7 | 面部，颧弓下缘中央与下颌切迹之间凹陷处（闭口取穴） | 耳聋、耳鸣、聤耳（化脓性中耳炎）、齿痛、口噤、面痛 | 直刺0.5~1寸；**张口时穴位关闭，须闭口取穴** |
| 颊车 ST6 | 下颌角前上方一横指，咬肌隆起处（咀嚼时按压有凹陷） | 口眼㖞斜、齿痛、颊肿、口噤不语 | 直刺0.3~0.5寸，或向地仓透刺 |
| 地仓 ST4 | 口角旁开0.4寸（瞳孔直下） | 口眼㖞斜、流涎、眼睑瞤动、齿痛颊肿 | 斜刺或平刺0.5~0.8寸，可透颊车 |
| 天枢 ST25 | 腹部，脐中旁开2寸 | 腹痛、腹胀、肠鸣泄泻、便秘、痢疾、月经不调、痛经；**大肠募穴**，双向调节肠功能（止泻通便） | 直刺1~1.5寸。**孕妇慎用** |
| 梁丘 ST34 | 大腿前面，髌底上2寸，股外侧肌与股直肌肌腱之间 | 急性胃痛、膝肿痛、下肢不遂、乳痈、血尿；**郄穴，主急性胃痛** | 直刺1~1.5寸 |
| 足三里 ST36 | 小腿前外侧，犊鼻下3寸，胫骨前嵴外一横指 | 一切胃肠病症——胃痛、呕吐、腹胀、泄泻、便秘、疳积；虚劳羸瘦（保健强壮要穴）；下肢痿痹；心悸气短；癫狂；"肚腹三里留"；**实验研究可调节免疫、胃肠、血压、血糖**；保健灸常用 | 直刺1~2寸；强壮保健常用温和灸。**孕妇慎针慎灸**（有激发宫缩的报道） |
| 条口 ST38 | 小腿前外侧，犊鼻下8寸，胫骨前嵴外一横指 | 下肢痿痹、转筋、跗肿、肩臂痛（"条口透承山"治肩周炎） | 直刺1~1.5寸 |
| 上巨虚 ST37 | 犊鼻下6寸，胫骨前嵴外一横指 | 肠鸣、腹痛、泄泻、便秘、肠痈（阑尾炎）、下肢痿痹；**大肠下合穴** | 直刺1~2寸 |
| 下巨虚 ST39 | 犊鼻下9寸，胫骨前嵴外一横指 | 泄泻、痢疾、小腹痛、腰脊痛引睾丸、乳痈、下肢痿痹；**小肠下合穴** | 直刺1~1.5寸 |
| 丰隆 ST40 | 外踝尖上8寸，胫骨前嵴外二横指 | **化痰要穴**——痰多咳嗽、眩晕、头痛、癫狂痫、中风痰阻；下肢痿痹；**络穴，通脾经**，治"无形之痰"（高脂血症、肥胖辅助） | 直刺1~1.5寸 |
| 内庭 ST44 | 足背第2、3趾间，趾蹼缘上方赤白肉际处 | 齿痛、咽喉肿痛、口眼㖞斜、鼻衄、胃病吐酸、腹胀、泄泻、痢疾、便秘、热病、足背肿痛；**荥穴，清胃热**（胃火牙痛首选） | 直刺或斜刺0.3~0.5寸 |

## 二、足太阳膀胱经（67穴，选22穴）

| 穴名 | 定位 | 主治 | 操作与安全提示 |
|---|---|---|---|
| 睛明 BL1 | 面部，目内眦内上方眶内侧壁凹陷中 | 目赤肿痛、流泪、视物不明、目眩、近视、夜盲、色盲；**眼病要穴** | 嘱患者闭目，医者左手轻推眼球向外侧固定，沿眼眶边缘缓慢直刺0.3~0.5寸，**不捻转、不提插（或极轻微）、出针后按压1~2分钟防出血**；禁灸；眼区操作须由熟练医师进行 |
| 攒竹 BL2 | 眉头凹陷中，眶上切迹处 | 头痛、眉棱骨痛、眼睑瞤动、眼睑下垂、口眼㖞斜、目视不明、呃逆（按压） | 平刺或斜刺0.3~0.5寸；禁灸 |
| 风门 BL12 | 背部，第2胸椎棘突下（T2）旁开1.5寸 | 伤风咳嗽、发热头痛、鼻塞、项强、胸背痛；**感冒要穴，灸之预防感冒** | 斜刺0.5~0.8寸。**防气胸，忌深刺、忌向上斜刺过深** |
| 肺俞 BL13 | T3棘突下旁开1.5寸 | 咳嗽、气喘、咯血、骨蒸潮热、盗汗、鼻塞；皮毛病（荨麻疹、痤疮）；**肺之背俞**，咳喘、三伏贴常用 | 斜刺0.5~0.8寸。**防气胸** |
| 膏肓 BL43 | T4棘突下旁开3寸 | 咳嗽、气喘、肺痨、健忘、遗精、盗汗、虚劳羸瘦；**一切虚损诸证，灸法常用** | 斜刺0.5~0.8寸。**防气胸** |
| 心俞 BL15 | T5棘突下旁开1.5寸 | 心痛、惊悸、失眠、健忘、癫痫、咳嗽、吐血、遗精、盗汗；**心之背俞** | 斜刺0.5~0.8寸。**防气胸** |
| 肝俞 BL18 | T9棘突下旁开1.5寸 | 胁痛、黄疸、目赤、目视不明、夜盲、迎风流泪、癫狂痫、脊背痛；**肝之背俞**，肝病、眼病常用 | 斜刺0.5~0.8寸 |
| 胆俞 BL19 | T10棘突下旁开1.5寸 | 黄疸、口苦、胁痛、肺痨、潮热；**胆之背俞** | 斜刺0.5~0.8寸 |
| 脾俞 BL20 | T11棘突下旁开1.5寸 | 腹胀、黄疸、呕吐、泄泻、痢疾、便血、水肿、背痛；贫血、出血性疾病；**脾之背俞**，健脾化湿要穴 | 斜刺0.5~0.8寸 |
| 胃俞 BL21 | T12棘突下旁开1.5寸 | 胃脘痛、呕吐、腹胀、肠鸣、胸胁痛；**胃之背俞** | 斜刺0.5~0.8寸 |
| 肾俞 BL23 | 腰部，L2棘突下旁开1.5寸 | 腰痛、遗尿、遗精、阳痿、月经不调、带下、耳鸣耳聋、水肿、气喘、五劳七伤；**肾之背俞**，补肾要穴，腰痛、生殖系病常用，保健灸常用 | 直刺0.5~1寸。腰部穴，孕妇慎用 |
| 志室 BL52 | 腰部，L2棘突下旁开3寸 | 遗精、阳痿、小便不利、水肿、腰脊强痛 | 直刺0.5~1寸。腰部穴，孕妇慎用 |
| 大肠俞 BL25 | 腰部，L4棘突下旁开1.5寸 | 腰腿痛、腰扭伤、腹胀、泄泻、便秘、痢疾；**大肠之背俞**，腰椎间盘突出常用 | 直刺0.8~1.5寸。腰部穴，孕妇慎用 |
| 上髎 BL31 | 骶部，正对第1骶后孔 | 同次髎，偏重相应盆腔脏器 | 直刺1~1.5寸。**骶部穴，孕妇禁针** |
| 次髎 BL32 | 骶部，正对第2骶后孔中（髂后上棘与督脉之间） | 月经不调、痛经、带下、小便不利、遗精、阳痿、疝气、腰骶痛、下肢痿痹；**八髎穴代表**，妇科与骶尾部痛要穴 | 直刺1~1.5寸。**骶部穴，孕妇禁针** |
| 中髎 BL33 | 骶部，正对第3骶后孔 | 同次髎，偏重相应盆腔脏器 | 直刺1~1.5寸。**骶部穴，孕妇禁针** |
| 下髎 BL34 | 骶部，正对第4骶后孔 | 同次髎，偏重相应盆腔脏器 | 直刺1~1.5寸。**骶部穴，孕妇禁针** |
| 委中 BL40 | 腘横纹中点，股二头肌腱与半腱肌肌腱之间 | 腰背痛（"腰背委中求"）、下肢痿痹、中风昏迷、半身不遂、腹痛、吐泻、小便不利、遗尿、丹毒（点刺放血）；**合穴；刺络放血急性腰扭伤、暑热** | 直刺1~1.5寸；点刺腘静脉出血须医师操作，**有出血倾向者禁用** |
| 秩边 BL54 | 骶部，平第4骶后孔，骶正中嵴旁开3寸 | 腰骶痛、下肢痿痹、痔疾、便秘、小便不利（深刺治前列腺病） | 直刺1.5~3寸（深刺须医师操作）。**骶部穴，孕妇禁针** |
| 承山 BL57 | 小腿后区，腓肠肌两肌腹与肌腱交角处（用力伸足，小腿后面出现"人"字凹陷处） | 痔疾（痔痛要穴）、便秘、腰腿拘急疼痛、脚气、小腿转筋（腓肠肌痉挛） | 直刺1~2寸 |
| 昆仑 BL60 | 踝区，外踝尖与跟腱之间凹陷中 | 后头痛、项强、腰骶疼痛、足踝肿痛、滞产、癫痫；**经穴** | 直刺0.5~0.8寸。**【孕妇禁针】**；针感强，易晕针，体弱者慎 |
| 申脉 BL62 | 踝区，外踝尖直下方凹陷中 | 头痛、眩晕、癫狂痫、失眠、腰腿酸痛、目赤痛、项强；**八脉交会穴通阳跷脉**，配后溪治颈项痛、日间发作癫痫 | 直刺0.3~0.5寸 |
| 至阴 BL67 | 足小趾末节外侧，趾甲根角侧后方0.1寸 | 胎位不正（**艾灸至阴矫正胎位，须孕30周以上在医师指导下进行**）、滞产、头痛、目痛、鼻塞、鼻衄；井穴 | 浅刺0.1寸；**胎位矫正用灸不用针；孕妇未经评估禁针** |

## 三、足少阳胆经（44穴，选13穴）

| 穴名 | 定位 | 主治 | 操作与安全提示 |
|---|---|---|---|
| 风池 GB20 | 颈后区，枕骨之下，胸锁乳突肌上端与斜方肌上端之间的凹陷中 | 头痛、眩晕、目赤肿痛、鼻渊、鼻衄、耳鸣、颈项强痛、感冒、癫痫、中风、热病、疟疾、颈肩综合征；**祛风要穴**，内风外风皆治，高血压头痛、椎动脉型颈椎病常用 | 针尖微下，向鼻尖方向斜刺0.8~1.2寸。**严禁向上深刺或针刺过深（延髓、椎动脉危险区）**，必须由熟练医师操作 |
| 肩井 GB21 | 肩上，第7颈椎棘突（大椎）与肩峰最外侧点连线的中点 | 头项强痛、肩背疼痛、上肢不遂、难产、乳痈、乳汁不下、瘰疬；颈肩综合征要穴（推拿常用拿肩井） | 直刺0.3~0.5寸。**深刺可致气胸，切忌深刺、不可向前内方深刺；【孕妇禁针禁拿】** |
| 日月 GB24 | 胸部，第7肋间隙，前正中线旁开4寸（乳头直下） | 胁肋疼痛、胀满、呕吐、吞酸、呃逆、黄疸；**胆之募穴**，胆囊疾患配胆囊穴 | 斜刺或平刺0.5~0.8寸。**防气胸，右侧深部为肝胆，忌深刺** |
| 带脉 GB26 | 侧腹部，第11肋骨游离端垂线与脐水平线交点 | 月经不调、赤白带下、疝气、腰胁痛；**带脉交会穴**，妇科带下病、腰腹肥胖（减肥）常用 | 直刺0.5~0.8寸。侧腹部穴，孕妇慎用 |
| 五枢 GB27 | 下腹部，髂前上棘前0.5寸，平脐下3寸水平 | 带下、腹痛、疝气、便秘、腰胯痛 | 直刺0.8~1.5寸。**孕妇禁针** |
| 维道 GB28 | 下腹部，髂前上棘前下方，五枢前下0.5寸 | 带下、少腹痛、疝气、阴挺（子宫脱垂）、腰胯痛 | 直刺或向前下方斜刺1~1.5寸。**孕妇禁针** |
| 居髎 GB29 | 髋部，髂前上棘与股骨大转子最凸点连线中点 | 腰腿痹痛、瘫痪、足痿、疝气 | 直刺1~1.5寸 |
| 环跳 GB30 | 臀部，股骨大转子最凸点与骶管裂孔连线的外1/3与内2/3交点处 | 腰腿痛（**坐骨神经痛要穴**）、下肢痿痹、半身不遂；针感多为电击样向下肢放散 | 侧卧伸下腿屈上腿，直刺2~3寸；针感强，注意防晕针 |
| 风市 GB31 | 股部，髌底上7寸，髂胫束后缘（直立垂手中指尖处） | 下肢痿痹、麻木、遍身瘙痒（荨麻疹）、脚气 | 直刺1~2寸 |
| 阳陵泉 GB34 | 小腿外侧，腓骨头前下方凹陷处 | 胁痛、口苦、呕吐、黄疸、下肢痿痹、膝膑肿痛、脚气、肩痛、小儿惊风；**合穴、筋会**——"筋病灸阳陵"，筋脉病（扭伤、痉挛、半身不遂痉挛期）要穴 | 直刺1~1.5寸 |
| 光明 GB37 | 小腿外侧，外踝尖上5寸，腓骨前缘 | 目痛、夜盲、目视不明、乳房胀痛、下肢痿痹；**络穴**（眼科配穴） | 直刺1~1.5寸 |
| 悬钟（绝骨）GB39 | 小腿外侧，外踝尖上3寸，腓骨前缘 | 项强、胸胁胀痛、下肢痿痹、咽喉肿痛、脚气、痔疾；**髓会**，中风后遗症、颈椎病常用 | 直刺0.8~1寸 |
| 丘墟 GB40 | 踝区，外踝前下方，趾长伸肌腱外侧凹陷中 | 颈项痛、胸胁痛、下肢痿痹、外踝肿痛、疟疾；**原穴**；踝扭伤常用 | 直刺0.5~0.8寸 |

## 足三阳经分经主治提要

- 胃经：治前头、口齿、胃肠。
- 胆经：治侧头、耳、肝胆病。
- 膀胱经：治后头、项背腰、脏腑（背俞穴）。
