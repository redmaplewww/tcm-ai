# 穴位详解·经外奇穴（选12穴/组）

> 奇穴不属于十四经系统，但有固定名称与定位，多数对某些病症有特殊疗效。本文件收录常用经外奇穴12穴/组。
> 全部针刺操作须由执业针灸医师进行；孕妇禁忌（下腹、腰部穴）已醒目标注（通用警示见 穴位-手三阴经.md）。

| 穴名 | 定位 | 主治 | 操作与安全提示 |
|---|---|---|---|
| 四神聪 EX-HN1 | 头顶部，百会前后左右各旁开1寸，共4穴 | 失眠、健忘、癫痫、头痛、眩晕、脑发育不全、中风后遗症、帕金森病辅助 | 平刺0.5~0.8寸 |
| 太阳 EX-HN5 | 头部，眉梢与目外眦之间，向后约一横指凹陷处 | 头痛、偏头痛、目赤肿痛、眼睑瞤动、面瘫、三叉神经痛、眩晕 | 直刺或斜刺0.3~0.5寸，或点刺出血（偏头痛放血须医师操作）；**避开颞浅动脉** |
| 安眠 EX-HN17 | 项部，翳风与风池连线中点 | 失眠、头痛、眩晕、心悸、癫狂、癔症、耳鸣；**安神助眠经验穴** | 直刺0.8~1寸。**不宜深刺，方向朝鼻尖，防伤延髓** |
| 子宫穴 EX-CA1 | 下腹部，脐中下4寸（中极）旁开3寸 | 阴挺（子宫脱垂）、月经不调、痛经、崩漏、不孕、疝气 | 直刺0.8~1.5寸。**【孕妇禁针】**（下腹部穴） |
| 定喘 EX-B1 | 背部，第7颈椎棘突下（大椎）旁开0.5寸 | 哮喘、咳嗽、落枕、肩背痛、荨麻疹；**平喘经验穴** | 直刺或斜刺0.5~0.8寸。**防气胸** |
| 夹脊穴（华佗夹脊）EX-B2 | 背腰部，第1胸椎至第5腰椎棘突下旁开0.5寸，一侧17穴 | **相应节段主治**：上胸段治心肺上肢病，下胸段治胃肠肝胆病，腰段治腰腹下肢病；广泛用于脊柱相关疾病、神经根型颈椎病、腰椎间盘突出、带状疱疹后遗神经痛 | 直刺0.3~0.5寸或斜向脊柱方向刺0.5~1寸。**防气胸及脊髓损伤，忌深刺**；腰段孕妇慎用 |
| 腰眼 EX-B7 | 腰部，第4腰椎棘突下旁开约3.5寸凹陷中 | 腰痛、尿频、消渴、虚劳、妇科腰部酸痛 | 直刺1~1.5寸。**【孕妇禁针】**（腰部穴） |
| 十宣 EX-UE12 | 十指尖端，距指甲游离缘0.1寸，左右共10穴 | 昏迷、晕厥、中暑、热病、小儿惊风、指端麻木；**高热、昏迷急救点刺出血** | 浅刺0.1~0.2寸或点刺出血 |
| 八邪 EX-UE9 | 手背，第1~5指间指蹼缘上方赤白肉际处，每侧4穴 | 手背肿痛、手指麻木、蛇串疮（带状疱疹）、烦热、目痛、咬伤（蛇伤急救后世衍用） | 斜刺0.5~0.8寸或点刺出血 |
| 八风 EX-LE10 | 足背，第1~5趾间趾蹼缘上方赤白肉际处，每侧4穴 | 足跗肿痛、脚气、趾麻、毒蛇咬伤（急救排毒） | 斜刺0.5~0.8寸或点刺出血 |
| 胆囊穴 EX-LE6 | 小腿外侧，阳陵泉直下1~2寸压痛处 | 急慢性胆囊炎、胆石症、胆道蛔虫症（胆绞痛辅助）；**诊断性压痛参考穴** | 直刺1~1.5寸 |
| 阑尾穴 EX-LE7 | 小腿前外侧，足三里直下1~2寸（犊鼻下约5~6寸）压痛处 | 急慢性阑尾炎（辅助治疗，**须先外科评估排除手术指征**）、消化不良、下肢痿痹 | 直刺1~1.5寸 |

## 奇穴应用要点

1. **急救类**：十宣、八邪、八风多用点刺出血，用于高热、昏迷、中暑、蛇伤排毒。
2. **诊疗结合类**：胆囊穴、阑尾穴既是治疗穴也是诊断性压痛参考穴，急腹症须先外科评估。
3. **节段主治类**：夹脊穴按相应脊柱节段主治，广泛用于脊柱相关疾病与神经痛。
4. **安神类**：四神聪、安眠为失眠、健忘经验穴，常与百会、神门配用。
