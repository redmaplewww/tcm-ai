# 小儿推拿

> 小儿推拿特定穴多分布于两臂（前臂"三关六腑天河水"线性穴）与头面、手部，手法轻快柔和。操作须由执业医师或经规范培训人员在医师指导下进行。

## 一、外感四大法（感冒基础方）

- **推攒竹（开天门）**：两眉正中至前发际直线，两拇指自下而上交替直推50~100次——疏风解表、开窍醒神。
- **推坎宫（分推坎宫）**：自眉头起沿眉弓向眉梢分推50~100次——外感发热、头痛。
- **揉太阳**：按揉眉后凹陷处50~100次——头痛、发热、目赤。
- **拿风池**：拿捏颈后枕骨下凹陷3~5次或揉30次——发汗解表。

## 二、清热要穴

- **清天河水**：前臂正中，腕横纹（总筋）至肘横纹（曲泽）成一直线，食中二指自腕向肘直推100~300次——清热解表、泻火除烦，用于外感发热、低热、夜啼。
- **退六腑（退下六腑）**：前臂尺侧，肘尖至阴池（腕横纹尺侧）成一直线，自肘向腕直推100~300次——清热凉血解毒，用于高热、实热证（虚寒证、腹泻者慎用）。
- **推三关**（对照）：前臂桡侧，阳池至曲池成一直线，自腕向肘推——温阳散寒、益气活血（虚寒证用），与退六腑一温一清配伍调节寒热。

## 三、消化系统常用

- **补脾经**：拇指螺纹面旋推。
- **清胃经**。
- **揉板门**。
- **运内八卦**。
- **摩腹**：顺时针通便、逆时针止泻。
- **捏脊**：自长强向上捏提至大椎3~5遍，调阴阳、理气血、强身。
- **推下七节骨**：泄泻实证热证；**推上七节骨**：止泻虚证。
- **揉龟尾**。
- **按揉足三里**。

## 四、手法速查表（方向·次数·作用）

| 穴位/线状穴 | 部位与走向 | 方向与次数 | 主要作用 |
|---|---|---|---|
| 攒竹（开天门） | 两眉正中至前发际 | 自下而上直推50~100次 | 疏风解表、开窍醒神 |
| 坎宫 | 眉头沿眉弓至眉梢 | 分推50~100次 | 外感发热、头痛 |
| 太阳 | 眉后凹陷处 | 揉50~100次 | 头痛、发热、目赤 |
| 风池 | 颈后枕骨下凹陷 | 拿3~5次或揉30次 | 发汗解表 |
| 天河水 | 腕横纹（总筋）至肘横纹（曲泽） | 自腕向肘推100~300次 | 清热解表、泻火除烦 |
| 六腑 | 肘尖至阴池（腕横纹尺侧） | 自肘向腕推100~300次 | 清热凉血解毒（高热实热） |
| 三关 | 阳池至曲池（前臂桡侧） | 自腕向肘推 | 温阳散寒、益气活血（虚寒） |
| 脾经 | 拇指螺纹面 | 旋推为补 | 健脾补虚 |
| 七节骨 | 第4腰椎至尾椎骨端（长强） | 推下治实热泄泻，推上止泻（虚证） | 调理大便 |
| 龟尾 | 尾椎骨端 | 揉 | 止泻通便 |
| 脊柱（捏脊） | 自长强向上至大椎 | 捏提3~5遍 | 调阴阳、理气血、强身 |

## 五、适应症与禁忌

- **适应**：小儿感冒发热、咳嗽、泄泻、便秘、厌食、疳积、夜啼、斜颈（早期）等。
- **禁忌（醒目标注）**：急性传染病、严重心脏病、骨折、皮肤破损感染、出血性疾病患儿禁用；饥饿或过饱后不宜立即推拿；操作介质（滑石粉/姜汁/温水）保护皮肤。
