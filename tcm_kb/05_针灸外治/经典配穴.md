# 常用经典配穴举例（38组，供 AI 组穴参考）

> 本表为常用证/症与经典配穴组合，供知识库组穴检索使用。实际处方须由执业针灸医师辨证确定；含孕妇禁忌穴的组合（如痛经方）已标注。
> 配穴理论依据（俞募配伍、原络配穴、八脉交会穴上下配穴等）见 腧穴总论与定位法.md。

## 一、外感与肺系病证

| 证/症 | 配穴 |
|---|---|
| 感冒风寒 | 风池、风门、列缺、合谷 |
| 外感发热 | 大椎、曲池、合谷（少商点刺） |
| 咳嗽哮喘实证 | 尺泽、列缺、肺俞、定喘、丰隆 |
| 虚寒咳喘（灸） | 肺俞、膏肓、定喘、肾俞、关元（三伏贴主穴区） |

| 荨麻疹/湿疹 | 曲池、血海、三阴交、膈俞、风市 |

## 配穴安全提示

1. 痛经方含三阴交、关元——**孕妇禁用**；妊娠期不得使用本组配穴。
2. 关元、气海、神阙方（中风脱证）为急救重灸法，须医师现场操作。
3. 含睛明、风池、肩井等危险区穴位的处方，严格按各穴操作深度与方向执行（见对应穴位文件）。
4. 尿潴留针下腹部穴前必须先排尿或叩诊确认膀胱底，防刺伤充盈膀胱。
