## 三、使用方式

- **检索（RAG-lite）**：`tcm_agent.kb.get_kb().search(query, k)` 按标题/标签/章节加权返回相关章节；
- **精确查询**：`tcm_agent.data.get_herb/get_formula/get_acupoint/get_syndrome/get_disease/get_glossary_term`；
- **推理**：`tcm_agent.reasoning.consult(PatientCase)` 走完整确定性辨证流程。

维护约定：新增文件须带frontmatter并同步更新所在域 `_index.md`；单文件不超过350行，
超限应继续拆分（测试 `tests/test_kb.py::test_kb_tree_structure` 强制校验）。
