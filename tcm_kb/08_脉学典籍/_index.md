# 脉学典籍：从指下感觉到量化判别

本目录汇集脉学经验的四个层次，与 `data/pulses.json` 规则层和 `pulse_rules.py` 判别引擎配套使用。

## 一、目录结构与层次

| 文件 | 层次 | 作用 |
|------|------|------|
| [脉经-二十四脉形](脉经-二十四脉形.md) | 经典定义层 | 西晋·王叔和《脉经》24脉原始定义，脉象术语的源头 |
| [濒湖脉学-脉诀选录](濒湖脉学-脉诀选录.md) | 经验传承层 | 明·李时珍27脉体状诗/相类诗/主病诗选录 |
| [内经-脉学总要](内经-脉学总要.md) | 理论总纲层 | 至数、胃气神根、四时脉的理论源头 |
| [伤寒金匮-脉证提纲](伤寒金匮-脉证提纲.md) | 临床实证层 | 六经病脉证对应，方证-脉象挂钩的源头 |
| [脉图学-量化判别标准](脉图学-量化判别标准.md) | 量化锚点层 | 指感→波形参数→参考阈值的对照表（规则层的依据） |
| [方证脉对应与医案脉证](方证脉对应与医案脉证.md) | 应用检索层 | 常用方剂的脉象指征与结构化脉证案例 |

## 二、使用方式（AI应用要点）

1. **判脉时**：`pulse_rules.py` 规则引擎输出脉名候选后，检索本目录获取经典出处与主病，充实辨证依据。
2. **辨证时**：脉名+症状检索[伤寒金匮-脉证提纲](伤寒金匮-脉证提纲.md)与[方证脉对应](方证脉对应与医案脉证.md)，做方证参考（须医师辨证）。
3. **校准时**：自采数据的阈值校准以[脉图学-量化判别标准](脉图学-量化判别标准.md)为初始值，以临床专家判脉为金标准。
4. **溯源时**：`pulses.json` 中每条规则的 `classical` 字段均可回溯到本目录相应文件。

## 三、重要说明

- 经典条文以通行本为准选录，AI推理引用时应注明出处；
- 脉图学参考阈值为文献近似值，各实验室设备与人群不同，须本地校准；
- 典籍知识服务于四诊合参，不可单独作为诊断处方依据。
