# 问疼痛与头身胸腹不适、问耳目（十问第三、六、七问）

疼痛病机总纲："**不通则痛**"（实证）与"**不荣则痛**"（虚证）。

## 一、疼痛性质辨析表（AI核心规则）

| 疼痛性质 | 特征 | 临床意义 |
|----------|------|----------|
| **胀痛** | 痛而兼胀，走窜不定，时轻时重 | **气滞**（肝郁气滞之胁胀、胃脘胀痛）；头目胀痛多属肝阳上亢或肝火上炎 |
| **刺痛** | 痛如针刺，固定拒按，夜间尤甚 | **血瘀** |
| **隐痛** | 疼痛绵绵、可以忍耐、劳累后加重、喜温喜按 | **虚证**（气血阴阳之虚，不荣则痛）：隐痛见于头部—气血虚；脘腹隐痛—脾胃虚寒 |
| **重痛** | 痛而兼沉重感 | **湿邪困阻**（湿性重浊）；头重痛—风湿上犯 |
| **冷痛** | 痛而兼冷感，得温则减 | **寒证**（寒凝）：实寒（寒邪阻络，痛剧拒按）与虚寒（阳气不足，痛缓喜按） |
| **灼痛** | 痛而兼灼热感，喜凉 | **热证**（火邪窜络或阴虚火旺） |
| **绞痛** | 痛势剧烈如绞 | **实邪闭阻气机**（结石、瘀血、蛔虫、寒邪固闭）：心脉痹阻之真心痛、结石腰腹绞痛、寒凝脘腹绞痛 |
| **掣痛（引痛、彻痛）** | 抽掣牵引作痛、由一处连及他处 | **筋脉失养**或筋脉阻滞不通（肝血虚不能养筋、寒凝经脉） |
| **酸痛** | 痛而兼酸楚感 | 湿邪困阻（湿性黏滞）；亦见于肾虚（腰酸） |
| **闷痛** | 痛而兼闷胀满感 | 气机不畅：胸闷痛—胸痹（心脉痹阻） |
| **走窜痛** | 疼痛部位游走不定 | 气滞（走窜于胸胁脘腹）或风邪偏胜之行痹（走窜肢体关节） |
| **固定痛** | 痛处固定不移 | 血瘀（固定刺痛）或湿邪（固定重着） |

## 二、疼痛虚实鉴别要点

- **实痛**：起病急、痛势剧、拒按、得按痛甚、持续不解。
- **虚痛**：起病缓、痛势绵绵、喜按、得按则舒、时作时止、劳累后加重。

## 三、头痛经络分经（部位→经络→用药引经）

| 头痛部位 | 归经 | 主经用药（引经） |
|----------|------|------------------|
| 后头部连项（枕后） | **太阳经头痛** | 羌活、蔓荆子、川芎 |
| 前额部连眉棱骨 | **阳明经头痛** | 白芷、葛根、知母 |
| 两侧（颞部） | **少阳经头痛** | 柴胡、黄芩、川芎 |
| 巅顶部（头顶） | **厥阴经头痛** | 吴茱萸、藁本 |
| 头痛连齿 | 少阴经头痛 | 细辛、独活 |
| 头痛昏重如裹 | 太阴经（湿困） | 苍术、半夏 |

按性质辨证：头痛遇风寒加重—风寒头痛；胀痛面红—肝阳（火）头痛；昏沉重着—风湿（痰湿）头痛；隐痛劳累加重—血虚/气虚头痛；刺痛固定夜间甚—瘀血头痛。

## 四、其他部位疼痛（胸胁脘腹腰背四肢）

| 部位 | 疼痛特点 | 辨证 |
|------|----------|------|
| 胸痛 | 胸痛憋闷、痛引肩臂内臂（左前胸） | **心脉痹阻**（胸痹、真心痛，**AI应警惕心血管急症**） |
| | 胸痛咳喘、发热咳痰 | 肺热/肺痈（实热） |
| | 胸胁窜痛、随情志波动 | 肝气郁结 |
| | 胁肋灼痛、口苦目黄 | 肝胆湿热 |
| | 胁部隐痛悠悠不休 | 肝阴虚（阴虚） |
| 脘痛（胃脘） | 胃脘灼痛拒按、得凉则舒 | 胃火（实热） |
| | 胃脘冷痛得温则减 | 寒邪犯胃/脾胃虚寒 |
| | 胃脘胀痛连胁、嗳气则舒、随情志变化 | 肝气犯胃 |
| | 胃脘隐痛喜温喜按 | 脾胃虚寒（虚证） |
| | 胃脘刺痛固定 | 瘀阻胃络 |
| 腹痛 | 大腹痛（脘以下耻骨以上正中）多属脾胃；小腹痛（脐下正中）多属膀胱、胞宫；少腹痛（小腹两侧）多属肝经 | 分部归脏 |
| | 腹痛拒按、胀满便秘 | 实证（阳明腑实） |
| | 腹痛喜按、便溏 | 虚证（脾虚） |
| | 绕脐痛、起包块按之可移 | 虫积 |
| 腰痛 | 腰部冷痛沉重、阴雨加重 | 寒湿腰痛 |
| | 腰痛酸软无力、劳累加重 | 肾虚腰痛（腰为肾之府） |
| | 腰部刺痛固定 | 瘀血腰痛 |
| 四肢关节痛 | 游走性（行痹—风胜）；重着（着痹—湿胜）；剧痛遇寒甚（痛痹—寒胜）；红肿灼热（热痹—热胜） | 痹证 |

## 五、问头身胸腹不适（除疼痛外）

| 症状 | 表现与意义 |
|------|-----------|
| **头晕** | 头晕胀痛、烦躁易怒—肝火上炎/肝阳上亢；头晕昏沉、胸闷苔腻—痰湿中阻；头晕耳鸣、腰膝酸软—肾虚精亏；头晕面白、劳累加重—气血亏虚；外伤后头晕刺痛—瘀血阻络 |
| **胸闷** | 胸闷心悸气短—心气虚/心阳不足；胸闷痰多—痰饮停肺；胸闷胁胀太息—肝气郁结 |
| **心悸** | 包括惊悸（因惊而发、时作时止、多虚）与怔忡（无惊自作、持续不宁、多虚重）。心悸气短—心气虚/心阳虚；心悸失眠多梦—心血虚/心阴虚；心悸胸闷刺痛—心脉痹阻；心悸痰多—痰扰心神 |
| **胁胀** | 胁肋胀满不舒、太息—肝气郁结；胁胀口苦厌油—肝胆湿热 |
| **脘痞** | 脘部痞塞胀满。脘痞嗳腐—食滞；脘痞纳呆便溏—脾胃虚弱；脘痞苔腻—湿邪困脾 |
| **腹胀** | 腹胀喜按属虚（脾虚）；腹胀拒按属实（食积、腑实）；腹部胀大如鼓—臌胀（气滞血瘀水停） |
| **身重** | 身重脘闷苔腻—湿困脾阳；身重浮肿—风水（肺失宣降，脾虚水泛） |
| **麻木** | 肢体麻木——气血两虚（不荣）或肝风内动（先兆）、湿痰瘀血阻络（不通） |
| **乏力** | 神疲乏力、少气懒言—气虚；乏力伴畏寒—阳虚；乏力伴面色萎黄—血虚/脾虚 |

## 六、问耳目

| 症状 | 表现 | 辨证 |
|------|------|------|
| 耳鸣 | 突发耳鸣声大如潮、按之不减（实证） | 肝胆火扰（少阳经热）、痰火壅耳 |
| | 渐起耳鸣声细如蝉、按之减轻（虚证） | 肾精亏虚（髓海不足）、肝肾阴虚 |
| 耳聋 | 新病暴聋 | 实证（肝火上炎、风热上扰、伤寒少阳） |
| | 久病渐聋 | 虚证（肾精亏虚，"精脱者耳聋"） |
| 重听/老年耳聋 | 听力渐退 | 肾虚（年老精衰） |
| 目痛 | 目痛红肿 | 肝火上炎/风热上攻 |
| 目眩（头晕眼花） | 兼面红目赤头胀 | 肝阳上亢/肝火上炎 |
| | 兼腰膝酸软耳鸣 | 肝肾阴虚（精血不足） |
| | 兼胸闷恶心苔腻 | 痰湿中阻（清阳不升） |
| 目昏/雀盲 | 视物昏花、夜盲 | 肝血虚/肾精不足（肝开窍于目） |
