# 问饮食口味（十问第五、八问）

## 一、口渴与饮水

| 表现 | 临床意义 |
|------|----------|
| 口不渴 | 不渴—寒证、湿证（津液未伤） |
| 渴喜冷饮、饮量大 | **实热证**（里热炽盛，津液大伤） |
| 渴喜热饮、饮量不多 | 寒证（虚寒）或痰湿内停；真寒假热亦渴喜热饮 |
| 渴不多饮 | **湿热证**（热伤津而湿邪留滞）、**瘀血**（瘀阻气机，津不上承，但欲漱水不欲咽）、阴虚（渴而饮水不多）、温病营分证 |
| 口干但欲漱水不欲咽 | **瘀血内停**（特征性） |
| 渴欲饮水、饮后即吐 | 水饮内停（"水逆"） |
| 多饮多尿、消瘦 | 消渴病（肺胃燥热/肾虚） |

**AI规则**：渴饮是寒热真假鉴别要点之一——真热渴喜冷饮量多；假热（真寒）渴喜热饮量少。

## 二、食欲与食量

| 表现 | 临床意义 |
|------|----------|
| 食欲减退（纳呆） | 脾胃气虚、湿邪困脾；新病纳呆—外感表证或胃气未复 |
| 厌食 | 厌食兼脘腹胀满嗳腐—**食滞胃脘**；厌食油腻兼胁痛黄疸—肝胆湿热 |
| 消谷善饥（易饥多食） | **胃火炽盛**（腐熟太过）；若多食易饥兼消瘦—消渴（中消） |
| 饥不欲食 | **胃阴虚**（虚火扰胃，胃阴不足） |
| 除中 | 久病重病本不能食、突然欲食甚至暴食 | **胃气衰败的假象**（回光返照表现之一，危候） |
| 偏嗜异物（生米、泥土） | 多见于小儿虫积 |
| 食量渐增 | 胃气渐复（病向愈） |
| 食量渐减 | 胃气衰败（病进） |

## 三、口味

| 口味 | 临床意义 |
|------|----------|
| 口淡 | 脾胃气虚、寒证（味觉减退，口中无味） |
| 口苦 | **肝胆火旺（肝火上炎、胆气上溢）、湿热（肝胆湿热）**；热证（心火） |
| 口甜或黏腻 | 脾胃湿热（脾瘅）；口中黏腻—湿浊内停 |
| 口酸 | 肝胃郁热（肝热犯胃）、食滞（嗳腐吞酸） |
| 口涩 | 燥热伤津（热灼津伤）、气阴两虚 |
| 口咸 | **肾虚**（肾液上泛，肾病及骨）；多属肾阳虚或肾阴虚 |
| 口辛 | 肺热（燥热） |

## 四、问饮食口味辨证要点（AI规则）

1. 口渴与否首辨津液：不渴多寒湿，渴喜冷饮多实热。
2. "但欲漱水不欲咽"是瘀血特征性表现。
3. 食欲三问：纳呆（脾胃虚/湿困）、消谷善饥（胃火）、饥不欲食（胃阴虚）——三者虚实寒热各异。
4. 口味直接提示脏腑：口苦肝胆、口甜脾胃湿热、口咸肾虚、口辛肺热、口酸肝胃郁热/食滞。
5. 久病突然能食暴食（除中）为胃气衰败危候，应建议就医。
