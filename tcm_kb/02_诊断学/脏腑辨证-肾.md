# 肾病辨证（6证）

## 一、肾阳虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 素体阳虚、年高肾亏、久病伤肾、房劳过度 |
| 主要症状 | **腰膝酸冷疼痛、畏寒肢冷、下肢尤甚**、**精神萎靡、面色㿠白或黧黑**、头目眩晕、男子阳痿早泄、女子宫寒不孕、性欲减退、夜尿频多、或五更泄泻、或浮肿（腰以下肿甚）尿少 |
| 舌象 | 舌淡胖苔白滑 |
| 脉象 | 沉弱，尺部尤甚 |
| 治法 | 温补肾阳，益火消阴 |
| 代表方 | 金匮肾气丸、右归丸 |

## 二、肾阴虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 素体阴虚、久病伤肾、房劳过度、热病后期耗肾阴 |
| 主要症状 | **腰膝酸软而痛、眩晕耳鸣**、**男子阳强易举、遗精**，女子经少经闭或崩漏、失眠多梦、**五心烦热、潮热盗汗、咽干颧红**、形体消瘦、小便短黄 |
| 舌象 | 舌红少津少苔 |
| 脉象 | 细数 |
| 治法 | 滋阴补肾降火 |
| 代表方 | 六味地黄丸；火旺用知柏地黄丸、左归丸 |

## 三、肾精不足证

| 项目 | 内容 |
|------|------|
| 病因病机 | 禀赋不足、先天发育不良、房劳过度、久病伤精 |
| 主要症状 | **小儿发育迟缓（五迟五软：立行发齿语迟、头项口手足肌肉软）**、囟门迟闭、男子精少不育、女子经闭不孕、**性功能减退**、成人早衰（发脱齿摇、耳鸣耳聋、健忘恍惚、神情呆钝、动作迟缓）、足痿无力 |
| 舌象 | 舌淡 |
| 脉象 | 沉弱或细弱 |
| 治法 | 补肾填精 |
| 代表方 | 左归丸、河车大造丸、五子衍宗丸 |

## 四、肾气不固证

| 项目 | 内容 |
|------|------|
| 病因病机 | 年高肾气亏虚、年幼肾气未充、房劳久病耗伤 |
| 主要症状 | **夜尿频多、小便清长、尿后余沥不尽**、**遗尿、小便失禁**、男子滑精早泄、女子带下清稀量多、胎动易滑（滑胎）、腰膝酸软、神疲乏力 |
| 舌象 | 舌淡苔白 |
| 脉象 | 沉弱 |
| 治法 | 补肾固摄（固摄肾气） |
| 代表方 | 金锁固精丸（遗精）、桑螵蛸散（遗尿）、缩泉丸、寿胎丸（滑胎） |

## 五、肾不纳气证

| 项目 | 内容 |
|------|------|
| 病因病机 | 久咳久喘耗伤肺气由肺及肾、肾气亏虚摄纳无权（肺肾气虚） |
| 主要症状 | **久病咳喘、呼多吸少、气不得续、动则喘甚**、自汗神疲、声音低怯、腰膝酸软；偏阳虚者咳喘加剧、冷汗淋漓、肢冷面青（虚喘） |
| 舌象 | 舌淡苔白，阳虚者舌淡紫 |
| 脉象 | 沉弱 |
| 治法 | 补肾纳气，降气平喘 |
| 代表方 | 人参蛤蚧散、参蚧散、七味都气丸（偏阴虚）、金匮肾气丸合参蛤散 |

## 六、肾虚水泛证

| 项目 | 内容 |
|------|------|
| 病因病机 | 肾阳虚衰、气化无权、水湿泛溢 |
| 主要症状 | **全身浮肿、腰以下尤甚、按之凹陷没指**、**小便短少**、腰膝酸冷、畏寒肢冷、或腹部胀满、或心悸气短喘咳、痰鸣（水气凌心射肺） |
| 舌象 | 舌淡胖嫩有齿痕苔白滑 |
| 脉象 | 沉迟无力 |
| 治法 | 温阳利水 |
| 代表方 | 真武汤、济生肾气丸 |

## 七、肾系辨证要点

**腰膝酸软耳鸣为肾病共性**：

- +虚寒象（畏寒、夜尿多、阳痿） → 肾阳虚
- +虚热象（五心烦热、盗汗、遗精） → 肾阴虚
- +发育迟缓早衰不育 → 肾精不足
- +尿频遗尿滑精 → 肾气不固
- +久喘呼多吸少 → 肾不纳气
- +浮肿尿少 → 肾虚水泛

## 症状→证型快速检索（肾系）

| 核心症状组合（≥2项即可提示） | 高频证型 |
|------------------------------|----------|
| 腰膝酸冷+畏寒+夜尿多/阳痿 | 肾阳虚 |
| 腰膝酸软+五心烦热+盗汗遗精 | 肾阴虚 |
| 发育迟缓/早衰+不育闭经 | 肾精不足 |
| 尿频遗尿+滑精早泄+带下清稀 | 肾气不固 |
| 久喘+呼多吸少+动则喘甚 | 肾不纳气 |
| 浮肿腰以下甚+尿少+畏寒 | 肾虚水泛 |
