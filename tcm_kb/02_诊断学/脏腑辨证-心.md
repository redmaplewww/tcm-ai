# 心病辨证（9证）

脏腑辨证是根据脏腑的生理功能、病理表现，对四诊资料进行归纳分析，推断病变脏腑部位、性质、正邪盛衰的辨证方法，是内伤杂病辨证的**核心体系**，也是AI辨证推理的主引擎。每个证型按"病因病机→症状→舌象→脉象→治法→代表方"结构化呈现（加粗者为核心辨证要点/主症）。

## 一、心气虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 年老体衰、久病、劳倦耗伤心气 |
| 主要症状 | **心悸气短**，活动后加重，**神疲乏力**、自汗、面色淡白 |
| 舌象 | 舌淡苔白 |
| 脉象 | 虚弱 |
| 治法 | 补益心气 |
| 代表方 | 养心汤、七福饮 |

## 二、心阳虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 心气虚进一步发展，损伤心阳 |
| 主要症状 | 心悸怔忡、心胸憋闷或痛、**畏寒肢冷**、气短、自汗、面色㿠白或面唇青紫 |
| 舌象 | 舌淡胖苔白滑 |
| 脉象 | 沉迟无力或结代 |
| 治法 | 温补心阳 |
| 代表方 | 保元汤、桂枝甘草龙骨牡蛎汤 |

## 三、心阳暴脱证

| 项目 | 内容 |
|------|------|
| 病因病机 | 心阳虚衰极致，阳气暴脱 |
| 主要症状 | 冷汗淋漓、四肢厥冷、面色苍白、呼吸微弱、神志模糊或昏迷 |
| 舌象 | 舌淡紫暗 |
| 脉象 | 微细欲绝 |
| 治法 | 回阳固脱（**急救**） |
| 代表方 | 参附汤 |

## 四、心血虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 失血过多、生化不足、思虑暗耗 |
| 主要症状 | **心悸失眠多梦健忘**、**头晕眼花**、面色淡白无华或萎黄、唇甲色淡 |
| 舌象 | 舌淡苔薄白 |
| 脉象 | 细弱 |
| 治法 | 补血养心，益气安神 |
| 代表方 | 归脾汤、四物汤加减 |

## 五、心阴虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 思虑劳心太过、热病久病伤阴 |
| 主要症状 | 心悸心烦、**失眠多梦**、**五心烦热**、潮热盗汗、两颧潮红、口燥咽干 |
| 舌象 | 舌红少津少苔 |
| 脉象 | 细数 |
| 治法 | 滋阴养心，清热安神 |
| 代表方 | 天王补心丹 |

## 六、心火亢盛证

| 项目 | 内容 |
|------|------|
| 病因病机 | 七情化火、六淫化热内传、过食辛辣温补 |
| 主要症状 | **心烦失眠**、**面赤口渴**、口舌生疮糜烂疼痛、小便短赤灼痛（热移小肠）、甚则狂躁谵语 |
| 舌象 | 舌尖红绛起刺苔黄 |
| 脉象 | 数而有力 |
| 治法 | 清心泻火 |
| 代表方 | 导赤散、朱砂安神丸 |

## 七、心脉痹阻证

| 项目 | 内容 |
|------|------|
| 病因病机 | 瘀血、痰浊、阴寒、气滞阻滞心脉 |
| 主要症状 | **心悸怔忡、心胸憋闷疼痛、痛引肩背内臂**，时作时止。瘀阻—刺痛舌紫暗有瘀斑；痰阻—闷痛尤甚体胖痰多苔腻；寒凝—剧痛得温则减畏寒肢冷；气滞—胀痛随情志波动 |
| 舌象 | 舌暗或有瘀斑（瘀阻）、苔白腻（痰阻） |
| 脉象 | 涩或结代 |
| 治法 | 活血化瘀/通阳泄浊/辛温散寒/行气活血（分型施治） |
| 代表方 | 血府逐瘀汤（瘀）、瓜蒌薤白半夏汤（痰）、枳实薤白桂枝汤（寒）、柴胡疏肝散（气滞）（**胸痛剧烈持续应先排除心梗**） |

## 八、痰蒙心神证（痰迷心窍）

| 项目 | 内容 |
|------|------|
| 病因病机 | 湿浊酿痰、情志不遂气郁生痰、痰浊蒙蔽心神 |
| 主要症状 | **神识痴呆、意识模糊**、甚则昏不知人、喉有痰声、胸闷呕恶、或精神抑郁、喃喃自语、举止失常（癫证）、突然昏仆痰鸣（痫证） |
| 舌象 | 舌苔白腻 |
| 脉象 | 滑 |
| 治法 | 豁痰开窍 |
| 代表方 | 涤痰汤、苏合香丸（寒闭）；滚痰丸 |

## 九、痰火扰心证

| 项目 | 内容 |
|------|------|
| 病因病机 | 五志化火炼液为痰、外感热邪灼津成痰，痰火内扰心神 |
| 主要症状 | **发热失眠、心烦神昏谵语**、面赤气粗、胸闷痰黄、甚则狂躁妄动、打人毁物、不避亲疏（狂证） |
| 舌象 | 舌红苔黄腻 |
| 脉象 | 滑数 |
| 治法 | 涤痰泻火开窍 |
| 代表方 | 温胆汤加黄连（黄连温胆汤）、礞石滚痰丸、安宫牛黄丸（热闭） |

## 十、心系辨证要点

- 心悸+气短乏力 → 心气虚
- +畏寒肢冷 → 心阳虚
- +失眠多梦面白 → 心血虚
- +烦热盗汗 → 心阴虚
- +口舌生疮 → 心火
- +胸痛引肩背 → 心脉痹阻（**先排心血管急症**）
- +神昏痰鸣 → 痰蒙/痰火扰心
