# 望舌（舌诊）——AI问诊高频核心

## 一、舌诊基础

- 舌质（舌体）：反映脏腑虚实、气血盛衰——候五脏病变之"本体"。
- 舌苔：反映胃气盛衰、邪气性质与深浅——候六腑病变之"表"。
- 舌面分候脏腑（传统）：舌尖候心肺、舌中候脾胃、舌边候肝胆、舌根候肾。
- **正常舌象：淡红舌、薄白苔**（舌体柔软灵活，色淡红明润，苔薄白均匀，干湿适中，又称"桃花舌"），提示气血调和、胃气充足。
- 望舌顺序：先看舌质（色→形→态），再看舌苔（色→质），综合判断。
- 进食、染苔（牛奶白苔、橘子黄苔）、刮舌后等会影响判断，AI应提示用户自然光线下拍摄。

## 二、望舌质——舌色

| 舌色 | 特征 | 临床意义 |
|------|------|----------|
| 淡白舌 | 较正常浅淡，甚至全无血色 | 主虚证、寒证。气血两虚（淡白无华）；阳虚寒湿（淡白湿润胖嫩）。多见于贫血、营养不良、慢性失血 |
| 淡红舌 | 淡红润泽 | 正常舌象；见于病人则病轻浅，气血未伤 |
| 红舌 | 较正常红，甚者鲜红 | 主热证。舌红苔黄—实热；舌红少苔或有裂纹—虚热（阴虚火旺）；舌尖红—心火亢盛；舌边红—肝胆火盛 |
| 绛舌 | 较红舌更深，深红色 | 主热入营血（温病营血分证）、阴虚火旺重症。外感病见绛舌为热入营血；久病绛舌少苔为阴虚火旺 |
| 紫舌 | 紫暗色，或现瘀点瘀斑 | 主瘀血、寒凝。紫暗湿润为寒凝血瘀（阳虚）；紫绛干枯为热盛血瘀（热灼血凝）；淡紫或青紫湿润—气虚气滞血瘀；舌有瘀点瘀斑—内有瘀血 |

## 三、望舌质——舌形

| 舌形 | 特征 | 临床意义 |
|------|------|----------|
| 老舌 | 舌质纹理粗糙、坚敛苍老 | 主实证 |
| 嫩舌 | 纹理细腻、浮胖娇嫩 | 主虚证 |
| 胖大舌 | 舌体宽大 | 主水湿内停、痰湿热毒。淡白胖嫩多属脾肾阳虚、痰湿内停；红胖大多属脾胃湿热、痰热；舌鲜红肿胀—心脾积热 |
| 齿痕舌 | 舌边有牙齿压痕，多与胖大并见 | 主脾虚湿盛。淡白湿润齿痕—阳虚水湿；淡红齿痕—脾气虚 |
| 瘦薄舌 | 舌体瘦小而薄 | 主气血两虚、阴虚火旺。瘦薄淡白—气血两虚；瘦薄红绛干燥—阴虚火旺、津液耗伤 |
| 裂纹舌 | 舌面有明显裂沟 | 主热盛伤阴、血虚不润、脾虚湿浸。红绛裂纹—热盛伤阴；淡白裂纹—血虚；健康人先天裂纹舌无症状不作病论 |
| 点刺舌 | 芒刺、红点突起 | 主脏腑热极或血分热盛。舌尖点刺—心火亢盛；舌边点刺—肝胆火盛 |

## 四、望舌质——舌态

| 舌态 | 特征 | 临床意义 |
|------|------|----------|
| 痿软舌 | 舌体软弱无力，伸卷不灵 | 主气血俱虚、阴液亏耗。久病淡白痿软—气血俱虚；红绛痿软—阴虚火旺 |
| 强硬舌 | 舌体板硬强直、运动不灵、语言謇涩 | 主热入心包、高热伤津、痰浊内阻、中风或中风先兆（**AI遇此应建议急诊**） |
| 歪斜舌 | 伸舌偏向一侧 | 主中风或中风先兆（**建议急诊**） |
| 颤动舌 | 舌体不自主颤抖 | 主肝风内动。久病淡白颤动—血虚生风；红绛颤动—热极生风；亦见于酒精中毒 |
| 吐弄舌 | 舌伸口外不即回（吐）、反复舔口唇（弄） | 多见于小儿，主心脾有热、热毒攻心；弄舌亦见于智力发育不全 |
| 短缩舌 | 舌体卷短紧缩，不能伸出 | 危重证候。寒凝筋脉、痰浊内阻、热盛伤津、气血俱虚均可致（**建议急诊**） |

## 五、望舌苔——苔色

| 苔色 | 特征 | 临床意义 |
|------|------|----------|
| 白苔 | 苔色白 | 主表证、寒证。薄白而润—正常或风寒表证；薄白而干—风热表证初起或津伤；白厚腻—湿浊、痰饮、食积；白厚腻干—湿浊化热；积粉苔（白如积粉）—外感秽浊湿邪与热毒相结（瘟疫/湿热秽浊） |
| 黄苔 | 苔色黄 | 主热证、里证。薄黄—风热表证或热邪入里之轻证；黄腻—湿热、痰热、食积化热；黄厚干燥—里热炽盛、伤津；焦黄燥裂—热极津枯 |
| 灰黑苔 | 苔灰黑 | 主里热或里寒的重证（病重）。灰黑干燥—热极伤阴（里热炽盛）；灰黑润滑—阳虚寒湿内盛（里寒）；注意染苔（橄榄、铁剂可使苔黑） |

## 六、望舌苔——苔质

| 苔质 | 特征 | 临床意义 |
|------|------|----------|
| 厚苔 | 透过舌苔不能见到舌体 | 主邪盛入里、内有痰湿食积。苔由薄变厚—病进；由厚变薄—病退 |
| 薄苔 | 透过舌苔隐约可见舌体 | 正常或病邪轻浅（表证初起） |
| 润苔 | 苔干湿适中 | 正常或津液未伤 |
| 滑苔 | 苔面水分过多、伸舌欲滴 | 主寒证、湿证、阳虚水泛（水湿内停） |
| 燥苔 | 苔面干燥、扪之无津 | 主津液已伤；高热、大汗、吐泻后多见。燥裂—热盛伤津重症 |
| 腻苔 | 苔质颗粒细腻致密、刮之难去 | 主湿浊、痰饮、食积。白腻—寒湿/痰湿；黄腻—湿热/痰热 |
| 腐苔 | 苔质颗粒疏松粗大、如豆腐渣、刮之易去 | 主食积胃肠、痰浊内蕴（胃气败伤，邪有余） |
| 剥落苔 | 舌苔部分或全部剥落 | 主胃气阴两伤、胃阴枯竭。花剥苔（地图舌）—气阴两伤/阴虚；镜面舌（全部剥落、光滑如镜）—胃阴干涸、胃气将绝（重证）；小儿花剥苔伴过敏体质 |
| 无苔 | 全舌无苔、光亮如镜（镜面舌） | 胃阴枯竭、胃气大伤，病重 |

## 七、舌象综合辨证速查表（舌质×舌苔组合）

| 舌象组合 | 证候判断 |
|----------|----------|
| 淡红舌薄白苔 | 正常或病轻 |
| 淡白舌薄白苔 | 气血不足兼表寒 |
| 淡白胖嫩齿痕苔白滑 | 脾肾阳虚、水湿内停 |
| 红舌薄黄苔 | 风热表证/里热初起 |
| 红舌黄厚腻苔 | 湿热内蕴（脾胃湿热、肝胆湿热） |
| 红绛舌少苔/无苔 | 阴虚火旺、热入营血 |
| 镜面舌 | 胃阴枯竭、气阴大伤 |
| 红舌起芒刺 | 脏腑热极（心火、肝胆火） |
| 青紫舌（或瘀点瘀斑）苔润 | 寒凝血瘀/气滞血瘀 |
| 紫绛舌苔黄燥 | 热盛血瘀、热入血分 |
| 白厚腻苔 | 寒湿、痰湿内阻 |
| 灰黑苔润滑 | 阳虚寒湿极盛 |
| 灰黑苔干燥起裂 | 热极伤阴、真阴耗竭 |

## 八、舌诊AI应用要点

1. 舌质候五脏病之本体，舌苔候六腑与胃气，二者必须合参。
2. 危重舌态（强硬、歪斜、短缩）出现时应建议用户立即急诊。
3. 判断前先排除染苔（食物、药物颜色干扰）与进食影响，建议自然光线拍摄。
4. 舌象是寒热真假鉴别的最可靠依据（舌红苔黄燥为真热；舌淡苔白滑为真寒）。
