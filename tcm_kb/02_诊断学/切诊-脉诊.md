# 脉诊：寸口诊法、平脉、28脉、相兼脉

## 一、寸口诊法与寸关尺分候脏腑

- 寸口（气口）脉：腕后桡动脉搏动处，分寸、关、尺三部。以掌后高骨（桡骨茎突）定关，关前为寸，关后为尺。
- 诊脉用三指定位，布指疏密与身高成比例；小儿一指三部。
- 诊脉要求"平息"：医生以自己一次正常呼吸（一息）数患者脉动次数。
- 指力三法：**举**（轻取）、**按**（重取）、**寻**（中取/左右推寻）。

| 手 | 寸 | 关 | 尺 |
|----|----|----|----|
| 左手 | **心**（心包） | **肝**（胆） | **肾**（小肠、膀胱） |
| 右手 | **肺**（胸中） | **脾**（胃） | **肾/命门**（大肠） |

口诀：**左心肝肾、右肺脾命（门）**。

## 二、正常脉象（平脉）

- **一息四五至**（一次呼吸4-5跳，约60-90次/分，成年人静息状态）。
- 三部有脉，不浮不沉，不大不小，从容和缓，节律一致，尺脉沉取有力。
- 平脉有**胃、神、根**三特点：
  - **有胃**：从容、和缓、流利（胃气充足）；
  - **有神**：柔和有力、节律整齐；
  - **有根**：尺脉沉取应指有力（肾气不绝）。
- 生理变异：年龄（小儿脉数、老人脉稍弦）、性别（女性稍快）、季节（春稍弦、夏稍洪、秋稍浮、冬稍沉）、体型（胖人稍沉、瘦人稍浮）、运动员（迟缓有力）、酒后/运动后/情绪激动（数）等。

## 三、常见28脉：脉象特征与主病

脉象分六类总纲：**浮脉类主表、沉脉类主里、迟脉类主寒、数脉类主热、虚脉类主虚、实脉类主实。**

### 3.1 浮脉类（主表证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **浮** | 轻取即得，重按稍减而不空（如水漂木） | **表证**；亦见于虚阳外越（久病浮而无根为危候）。浮有力为表实，浮无力为表虚 |
| **洪** | 脉体宽大，充实有力，来盛去衰（如波涛汹涌） | **热盛**（阳明气分大热、邪热亢盛） |
| **濡** | 浮而细软，重按无力 | 虚证、湿证（脾虚湿盛、诸虚劳损） |
| **散** | 浮散无根，至数不齐，按之则无 | 元气离散、脏气衰微（危候） |
| **芤** | 浮大中空，如按葱管 | **失血、伤阴**（大失血后血容量骤减） |
| **革** | 浮而搏指，中空外坚，如按鼓皮 | 精血虚寒（亡血、失精、半产漏下） |

### 3.2 沉脉类（主里证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **沉** | 轻取不应，重按始得（如石投水） | **里证**。沉有力为里实，沉无力为里虚 |
| **伏** | 重按推筋按骨始得，甚则伏而不见 | 邪闭、厥证、痛极（邪气内伏） |
| **弱** | 沉细无力 | **气血不足**（阳气虚衰、气血两虚） |
| **牢** | 沉按实大弦长，坚牢不移 | 阴寒积聚（癥瘕积聚、痞块） |

### 3.3 迟脉类（主寒证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **迟** | 一息不足四至（<60次/分） | **寒证**。迟有力为实寒（寒积），迟无力为虚寒（阳虚）；运动员生理性迟缓有力不作病论 |
| **缓** | 一息四至，脉来怠缓（从容和缓为平人；病理见脉势弛缓） | 湿证、脾虚（湿性黏滞）；亦见于正常胃气 |
| **涩** | 往来艰涩不畅，如轻刀刮竹，与滑相反 | **血瘀、精伤血少、气滞**（实涩—气滞血瘀；虚涩—伤精血少） |
| **结** | 迟而时一止，止无定数（不规则间歇） | **阴盛气结、寒痰瘀血**；亦见于气血虚衰（脏气衰微） |
| **代** | 迟而中止，止有定数（有规律间歇），良久复来 | **脏气衰微**（危候）、风证痛证、七情惊恐、跌打损伤 |

### 3.4 数脉类（主热证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **数** | 一息五至以上（>90次/分） | **热证**。数有力为实热，数无力为虚热（阴虚内热）；亦见于正常运动、情绪、小儿 |
| **疾** | 一息七至以上（>140次/分），较数更急 | 热极、阳极阴竭（元气将脱，危候） |
| **促** | 数而时一止，止无定数 | 阳盛实热、气滞血瘀痰饮（实热郁滞）；促而无力为虚脱之象 |
| **动** | 脉短如豆，滑数有力，关部尤明显 | 痛证、惊恐（阴阳相搏） |

### 3.5 虚脉类（主虚证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **虚** | 三部举按均无力，脉来迟缓松软 | **虚证**（气血两虚，尤多见于气虚） |
| **细** | 脉细如线，但应指明显 | **气血两虚**、湿证（湿邪阻压脉道）；诸虚劳损 |
| **微** | 极细极软，似有似无，按之欲绝 | **气血大虚、阳气衰微**（亡阳、暴脱，危候） |
| **短** | 首尾俱短，不及本位 | 气虚（短而无力）或气郁（短而有力） |

### 3.6 实脉类（主实证）

| 脉名 | 脉象特征 | 主病 |
|------|----------|------|
| **实** | 三部举按均有力，充实有力 | **实证**（实热、积滞、瘀血、痰浊壅盛）；久病见实脉为孤阳外脱之逆象 |
| **滑** | 往来流利，如珠走盘，应指圆滑 | **痰饮、食滞、实热**；青壮年气血充盛及**孕妇**可见生理性滑脉（"孕脉"） |
| **紧** | 脉来绷紧有力，状如转绳，左右弹指 | **寒证、痛证、宿食**（寒主收引，脉道拘急） |
| **弦** | 端直以长，如按琴弦，从中直过，挺然指下 | **肝胆病、痛证、痰饮、疟疾**；春季健康人微弦为平；老年脉弦为肾虚、动脉硬化之象 |
| **长** | 脉体超过本位，首尾端直 | 阳证、热证、实证；长而和缓为平人（气血充足） |

（28脉全目：浮、洪、芤、革、散、濡、沉、伏、牢、迟、缓、涩、结、代、数、疾、促、动、虚、细、微、短、实、滑、紧、弦、长，加缓/涩归类交叉，教材常为：浮沉迟数、洪微散虚、实滑弦紧、芤革牢濡、弱细伏动、促结代疾、长短缓涩共28种。）

## 五、相兼脉与主病规律

疾病中常多种脉象并见，称相兼脉。主病规律：**等于各脉主病的叠加（合参）**。

| 相兼脉 | 主病 |
|--------|------|
| 浮紧 | 表寒证（风寒束表） |
| 浮缓 | 表虚证（太阳中风） |
| 浮数 | 表热证（风热犯表） |
| 浮滑 | 表证夹痰（风痰） |
| 沉迟 | 里寒证 |
| 沉数 | 里热证 |
| 沉紧 | 里寒证、痛证（寒凝） |
| 沉滑 | 痰饮内停、食积 |
| 沉涩 | 血瘀（里实血瘀） |
| 弦数 | 肝火上炎、肝胆湿热 |
| 弦紧 | 寒滞肝脉、痛证（寒凝肝脉） |
| 弦滑 | 肝郁夹痰、痰饮、肝胆痰热（眩晕、中风先兆） |
| 弦细 | 肝肾阴虚、血虚肝郁 |
| 滑数 | 痰热、湿热、食积化热 |
| 洪数 | 气分热盛（阳明大热） |
| 细数 | 阴虚火旺、血虚有热 |
| 弦涩 | 气滞血瘀（肝郁血瘀） |
| 沉弦 | 肝郁气滞、痛证 |
| 迟缓 | 脾阳虚、寒湿 |
| 结、代、促 | 合参判断心律失常之寒热虚实，久病见之多属脏气衰微 |

## 六、脉诊AI应用要点

1. 六纲脉（浮沉迟数虚实）为第一层判断：浮表沉里、迟寒数热、虚实定正邪盛衰。
2. 弦脉为肝胆病、痛证、痰饮主脉，肝系诸证多见。
3. 结（止无定数）、代（止有定数）须区分；代脉、微脉、散脉、疾脉为危重脉象，AI识别应建议就医。
4. 相兼脉主病=各组成脉主病叠加，如弦数=肝胆病+热证。
5. 孕妇见滑脉为生理现象（"孕脉"），不作病论。
