# 腑病辨证（六腑证候，9证）

## 一、胃阴虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 热病后期胃阴耗伤、气郁化火灼伤胃阴、嗜食辛辣 |
| 主要症状 | **胃脘隐隐灼痛、饥不欲食**、口燥咽干、干呕呃逆、脘痞不舒、大便干结、形体消瘦 |
| 舌象 | 舌红少津少苔 |
| 脉象 | 细数 |
| 治法 | 滋养胃阴 |
| 代表方 | 益胃汤、沙参麦冬汤、麦门冬汤 |

## 二、胃火炽盛证（胃热）

| 项目 | 内容 |
|------|------|
| 病因病机 | 嗜食辛辣厚味、五志化火犯胃、热邪内犯 |
| 主要症状 | **胃脘灼痛拒按、消谷善饥**、**口臭、牙龈肿痛溃烂出血**、口渴喜冷饮、大便秘结、小便短黄 |
| 舌象 | 舌红苔黄燥 |
| 脉象 | 滑数 |
| 治法 | 清泻胃火 |
| 代表方 | 清胃散、玉女煎（兼阴虚） |

## 三、寒邪犯胃证（胃寒）

| 项目 | 内容 |
|------|------|
| 病因病机 | 过食生冷、脘腹受凉 |
| 主要症状 | **胃脘冷痛剧烈、得温则减、遇寒加重**、恶心呕吐、吐后痛缓、口淡不渴或泛吐清水 |
| 舌象 | 舌苔白润 |
| 脉象 | 弦紧或沉紧 |
| 治法 | 温胃散寒止痛 |
| 代表方 | 良附丸、理中汤、吴茱萸汤 |

## 四、食滞胃脘证

| 项目 | 内容 |
|------|------|
| 病因病机 | 饮食不节、暴饮暴食 |
| 主要症状 | **脘腹胀满疼痛拒按、嗳腐吞酸、呕吐酸馊食物、吐后胀痛得减**、矢气便溏酸臭、厌食 |
| 舌象 | 舌苔厚腻 |
| 脉象 | 滑 |
| 治法 | 消食导滞，和胃降逆 |
| 代表方 | 保和丸、枳实导滞丸 |

## 五、胃气上逆证

| 项目 | 内容 |
|------|------|
| 病因病机 | 各种原因致胃失和降 |
| 主要症状 | 呃逆嗳气频作、恶心呕吐 |
| 舌象 | 苔薄白或腻 |
| 脉象 | 弦 |
| 治法 | 和胃降逆 |
| 代表方 | 旋覆代赭汤、橘皮竹茹汤（胃虚有热） |

## 六、小肠实热证

| 项目 | 内容 |
|------|------|
| 病因病机 | 心火下移小肠 |
| 主要症状 | 心烦口舌生疮、**小便赤涩灼痛、尿血** |
| 舌象 | 舌尖红苔黄 |
| 脉象 | 数 |
| 治法 | 清心利小肠 |
| 代表方 | 导赤散 |

## 七、大肠湿热证

| 项目 | 内容 |
|------|------|
| 病因病机 | 感受湿热、饮食不洁 |
| 主要症状 | **腹痛、下利赤白脓血、里急后重（痢疾）**或暴注下泄、色黄臭秽、肛门灼热、身热口渴 |
| 舌象 | 舌红苔黄腻 |
| 脉象 | 滑数或濡数 |
| 治法 | 清热化湿解毒 |
| 代表方 | 葛根芩连汤（热泻）、白头翁汤（湿热痢）、芍药汤 |

## 八、大肠津亏证

| 项目 | 内容 |
|------|------|
| 病因病机 | 热病伤津、年老阴亏、失血产后 |
| 主要症状 | **大便燥结、干如羊屎、数日一行**、口干咽燥、口臭头晕 |
| 舌象 | 舌红少津苔黄干 |
| 脉象 | 细涩 |
| 治法 | 润肠通便 |
| 代表方 | 麻子仁丸、润肠丸、五仁丸 |

## 九、膀胱湿热证

| 项目 | 内容 |
|------|------|
| 病因病机 | 感受湿热、蕴结膀胱 |
| 主要症状 | **尿频尿急、排尿灼痛、小便短赤**（热淋）、或尿血（血淋）、或尿有砂石（石淋）、小腹胀痛 |
| 舌象 | 舌红苔黄腻 |
| 脉象 | 滑数 |
| 治法 | 清利膀胱湿热 |
| 代表方 | 八正散；石淋用石韦散 |

> 附：胆郁痰扰证归入肝病辨证（详见[脏腑辨证-肝](脏腑辨证-肝.md)）。

## 症状→证型快速检索（腑系）

| 核心症状组合（≥2项即可提示） | 高频证型 |
|------------------------------|----------|
| 胃隐痛灼热+饥不欲食+干呕 | 胃阴虚 |
| 胃灼痛+消谷善饥+口臭龈肿 | 胃火炽盛 |
| 胃冷痛剧+得温则减 | 寒邪犯胃 |
| 脘胀痛+嗳腐吞酸+吐后痛减 | 食滞胃脘 |
| 口舌生疮+小便赤涩灼痛 | 小肠实热 |
| 腹痛泄泻脓血+里急后重 | 大肠湿热（痢疾） |
| 大便干如羊屎+口干咽燥 | 大肠津亏 |
| 尿频急涩痛+短赤 | 膀胱湿热（淋证） |
