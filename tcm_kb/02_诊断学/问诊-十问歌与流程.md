# 问诊总纲：十问歌与问诊流程（问诊AI最核心）

## 一、十问歌全文

**通行版（明代张景岳《景岳全书·传忠录》首创，清代陈修园《医学实在易》增补）：**

> 一问寒热二问汗，三问头身四问便，
> 五问饮食六胸腹，七聋八渴俱当辨，
> 九问旧病十问因，再兼服药参机变。
> 妇人尤必问经期，迟速闭崩皆可见，
> 再添片语告儿科，天花麻疹全占验。

（AI问诊版末句或作"妇人尤必问经期，小儿当问麻疹斑"，意义相同。）

## 二、十问歌逐句解释（AI问诊流程设计对照）

| 序 | 问项 | 问什么 | 判断目标 |
|----|------|--------|----------|
| 一 | 问寒热 | 怕冷？发热？同时出现还是单独？热势高低、时间规律 | 辨表里、寒热 |
| 二 | 问汗 | 有汗无汗？汗出时间（醒着/睡着）、部位、性质 | 辨表里虚实、阴阳盛衰、津液存亡 |
| 三 | 问头身 | 头痛头晕？身痛麻木？疼痛部位与性质 | 辨病位（经络脏腑）、气血状态 |
| 四 | 问便 | 大便次数、质地、颜色、排便感；小便量、次、颜色、排尿感 | 辨脏腑寒热虚实（脾胃、肾、膀胱） |
| 五 | 问饮食 | 食欲、食量、口味、口渴与饮水偏好 | 辨脾胃功能、津液盛衰、寒热 |
| 六 | 问胸腹 | 胸闷心悸？胁胀脘痞腹胀？疼痛拒按喜按 | 辨气机阻滞、病位在脏在腑 |
| 七 | 问耳（聋） | 耳鸣耳聋？突发渐发？ | 辨肝肾（胆） |
| 八 | 问渴 | 口渴否？喜冷饮热饮？渴饮程度 | 辨津液存亡、寒热真假 |
| 九 | 问旧病 | 既往病史、手术史、过敏史 | 了解体质与病机基础 |
| 十 | 问因 | 发病诱因（外感、饮食、情志、劳倦）、诊治经过 | 病因辨证、避免重复用药 |
| 附 | 问服药 | 已服何药、疗效、不良反应 | "参机变"——指导处方调整 |
| 附 | 问经带（女） | 月经周期、经期、量、色、质、痛经；带下色质量味 | 妇科辨证必问 |
| 附 | 问儿科 | 出生情况、喂养、生长发育、传染病接触史（麻疹水痘等） | 儿科特点 |

## 三、AI问诊流程设计

问诊应按以下顺序展开，避免诱导性提问，覆盖十问全部要点后进入辨证：

```
主诉采集（最主要不适 + 持续时间）
    ↓
现病史（十问歌逐项展开：寒热、汗、头身、二便、饮食口味、胸腹、耳目、睡眠、情志）
    ↓
既往史（旧病、手术、过敏）
    ↓
个人史（情志、饮食起居、劳倦房劳）
    ↓
经带史（女）/ 儿科史（小儿）
    ↓
服药史（已服中西药、疗效、不良反应 → "参机变"）
    ↓
进入辨证（八纲 → 脏腑/气血/六经/卫气营血）
```

## 五、问诊注意（AI规则）

1. 避免诱导性提问，用开放式问题采集主诉。
2. 十问全部覆盖后再进入辨证，防止遗漏关键证据（尤其汗、二便、口渴等易漏项）。
3. 妇人必问经期，迟速闭崩皆可见；小儿当问麻疹斑（出疹性热病鉴别）。
4. 问因（外感、饮食、情志、劳倦）直接指导病因辨证与去除诱因的医嘱。
5. 已服药者须问疗效与反应，据疗效反推证型（"参机变"）。
