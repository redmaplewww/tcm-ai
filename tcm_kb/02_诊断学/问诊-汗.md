# 问汗（十问第二问）

汗为津液所化。"**阳加于阴谓之汗。**"

问汗要点：有汗无汗、汗出时间、汗出部位、汗出性质及伴随症状。

## 一、表证无汗/有汗辨表虚实

- 表证无汗 + 恶寒重 — **表实寒**（风寒表实证，麻黄汤证）。
- 表证有汗 + 恶风 — **表虚**（太阳中风，桂枝汤证）。

## 二、特殊汗出（全身汗证分类，AI重点）

| 汗证 | 表现 | 临床意义 |
|------|------|----------|
| **自汗** | 经常日间汗出不止，活动后尤甚 | **气虚、阳虚**（卫气不固、腠理不密）；常伴神疲乏力、气短懒言、畏风 |
| **盗汗** | 睡时汗出，醒则汗止 | **阴虚**（虚热蒸津外泄）；常兼颧红、五心烦热；盗汗+自汗并见—阴阳两虚/气阴两虚 |
| **绝汗（脱汗）** | 病情危重时大汗淋漓或汗出如珠、淋漓不止，兼四肢厥冷、脉微欲绝、呼吸急促 | **阳气欲脱**之危象（亡阳），见于心衰、休克（**AI应立即建议急救**） |
| **战汗** | 先恶寒战栗，后汗出 | 伤寒邪正剧争之转折点：战汗后热退脉静—邪去正复（向愈）；汗后烦躁脉疾—正气欲脱（危） |

## 三、局部汗出

| 汗证 | 表现 | 临床意义 |
|------|------|----------|
| **头汗** | 仅头面部汗出 | 上焦热盛（头面蒸腾）；中焦湿热（湿邪郁蒸，兼苔腻）；虚阳上越（久病头汗、气喘乏力）；进食头汗多为生理或胃热 |
| **半身汗** | 身体一侧（左或右、上或下）汗出 | 风痰/瘀痰阻络（中风先兆或中风后遗症、痿证）；营卫不调 |
| **手足心汗** | 手足心汗出明显 | 阴经郁热（阴虚内热）；脾胃湿热；阳明腑实 |
| **黄汗** | 汗色发黄染衣 | 湿热交蒸 |

## 四、问汗辨证要点（AI规则）

1. 先问"平时容易出汗吗？什么时候出？"——区分自汗（醒时/气虚阳虚）与盗汗（睡中/阴虚）。
2. 表证问有汗无汗——定表实（无汗）与表虚（有汗恶风）。
3. 汗出部位单问头汗、半身汗、手足心汗——分别提示上焦热盛/中风先兆/阴虚湿热。
4. 危重病人大汗淋漓伴肢冷脉微，为绝汗亡阳，应立即建议急救。
5. 汗与寒热合参：自汗+畏风乏力=气虚；盗汗+潮热颧红=阴虚；大汗+壮热口渴=里热炽盛。
