# 脏腑兼证辨证（13证）与脏腑证型快速检索矩阵

## 一、心脾两虚证（心脾气血两虚）

| 项目 | 内容 |
|------|------|
| 病因病机 | 思虑过度劳伤心脾、慢性失血、饮食失调 |
| 主要症状 | **心悸怔忡、失眠多梦、健忘**+**食少腹胀便溏、神疲乏力**、面色萎黄或㿠白、头晕、或皮下出血、月经量多色淡、妇女经少经闭 |
| 舌象 | 舌淡苔白 |
| 脉象 | 细弱 |
| 治法 | 补益心脾（益气补血，健脾养心） |
| 代表方 | 归脾汤 |

## 二、心肾不交证

| 项目 | 内容 |
|------|------|
| 病因病机 | 肾水亏于下、心火亢于上、水火不济 |
| 主要症状 | **心烦失眠、心悸多梦、彻夜不眠**+**腰膝酸软、眩晕耳鸣**、遗精、五心烦热、潮热盗汗、咽干 |
| 舌象 | 舌红少苔 |
| 脉象 | 细数 |
| 治法 | 交通心肾（滋阴降火） |
| 代表方 | 交泰丸、天王补心丹、黄连阿胶汤 |

## 三、心肾阳虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 心阳虚与肾阳虚并见 |
| 主要症状 | 心悸怔忡、畏寒肢冷、肢体浮肿、小便不利、唇甲青紫、腰膝冷痛 |
| 舌象 | 舌淡紫苔白滑 |
| 脉象 | 沉微 |
| 治法 | 温补心肾，化气行水 |
| 代表方 | 真武汤合保元汤/苓桂术甘汤 |

## 四、心肝血虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 血虚失养心神与筋目 |
| 主要症状 | 心悸失眠多梦健忘+眩晕耳鸣、面白无华、两目干涩视物模糊、肢体麻木、爪甲不荣、月经量少 |
| 舌象 | 舌淡苔白 |
| 脉象 | 细弱 |
| 治法 | 补血养肝，宁心安神 |
| 代表方 | 酸枣仁汤、四物汤加减 |

## 五、心肺气虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 久咳耗肺气及心气、年老体衰 |
| 主要症状 | 心悸咳喘、气短乏力、动则尤甚、自汗、胸闷、痰液清稀、面色淡白 |
| 舌象 | 舌淡苔白 |
| 脉象 | 弱或结代 |
| 治法 | 补肺益气，养心 |
| 代表方 | 补肺汤、保元汤 |

## 六、肝胃不和证（肝气犯胃）

| 项目 | 内容 |
|------|------|
| 病因病机 | 肝郁横逆犯胃、胃失和降 |
| 主要症状 | **胃脘胁肋胀满疼痛、走窜不定、随情志波动**、嗳气吞酸、呃逆呕吐、情绪抑郁或烦躁易怒、纳呆 |
| 舌象 | 苔薄白或薄黄 |
| 脉象 | 弦 |
| 治法 | 疏肝理气，和胃止痛 |
| 代表方 | 柴胡疏肝散、四逆散；吞酸重加左金丸 |

## 七、肝脾不调证（肝郁脾虚）

| 项目 | 内容 |
|------|------|
| 病因病机 | 肝郁乘脾、脾失健运 |
| 主要症状 | **胸胁胀满窜痛、善太息、情志抑郁或急躁**+**腹胀纳呆、腹痛欲泻、泻后痛减（痛泻）**、便溏不爽、肠鸣矢气、或大便溏结不调 |
| 舌象 | 舌淡红苔薄白或腻 |
| 脉象 | 弦或弦缓 |
| 治法 | 疏肝健脾（柔肝实脾） |
| 代表方 | 逍遥散、痛泻要方 |

## 八、肝火犯肺证（木火刑金）

| 项目 | 内容 |
|------|------|
| 病因病机 | 肝火循经上逆犯肺 |
| 主要症状 | **胸胁灼痛、急躁易怒**+**咳嗽阵作、痰黄黏稠甚则咳血**、烦热口苦、头胀头晕 |
| 舌象 | 舌红苔薄黄 |
| 脉象 | 弦数 |
| 治法 | 清肝泻肺，止咳化痰 |
| 代表方 | 黛蛤散合泻白散 |

## 九、肝肾阴虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 肝肾阴液俱虚、虚火内扰（乙癸同源、精血同源） |
| 主要症状 | **头晕目眩、耳鸣健忘、两目干涩视物模糊**+**腰膝酸软、胁痛**、五心烦热、颧红盗汗、失眠多梦、口燥咽干、男子遗精、女子经少 |
| 舌象 | 舌红少苔 |
| 脉象 | 细数 |
| 治法 | 滋补肝肾 |
| 代表方 | 六味地黄丸；目涩昏花用杞菊地黄丸；胁痛阴虚用一贯煎 |

## 十、脾肾阳虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 脾阳虚久及肾、肾阳虚不能温脾、水湿内停 |
| 主要症状 | **畏寒肢冷、腰膝腹部冷痛**+**久泻久痢、五更泄泻、完谷不化**、或浮肿尿少（下利清谷）、面色㿠白、小便清长 |
| 舌象 | 舌淡胖苔白滑 |
| 脉象 | 沉迟无力 |
| 治法 | 温补脾肾 |
| 代表方 | 附子理中丸、金匮肾气丸；五更泻用四神丸；水肿用真武汤、实脾饮 |

## 十一、肺肾阴虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 燥热虫毒耗伤肺阴、久咳及肾、房劳伤肾 |
| 主要症状 | **干咳少痰或痰中带血**+**腰膝酸软、骨蒸潮热**、盗汗颧红、口燥咽干、声音嘶哑、男子遗精、女子月经不调 |
| 舌象 | 舌红少苔 |
| 脉象 | 细数 |
| 治法 | 滋肾补肺（滋阴降火） |
| 代表方 | 百合固金汤、麦味地黄丸 |

## 十二、肺脾气虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 久咳肺虚及脾、脾虚土不生金 |
| 主要症状 | **久咳气短、痰多清稀**+**食少腹胀便溏、神疲乏力**、面色㿠白、自汗易感冒、甚则浮肿 |
| 舌象 | 舌淡苔白 |
| 脉象 | 弱 |
| 治法 | 补脾益肺（培土生金） |
| 代表方 | 六君子汤、参苓白术散、玉屏风散 |

## 十三、心肝火旺证

| 项目 | 内容 |
|------|------|
| 病因病机 | 情志化火、心肝火并炽 |
| 主要症状 | 心烦失眠、急躁易怒、面红目赤、口苦咽干、头痛眩晕、便秘尿赤、或狂躁 |
| 舌象 | 舌红苔黄 |
| 脉象 | 弦数 |
| 治法 | 清心泻肝 |
| 代表方 | 龙胆泻肝汤合导赤散 |
