# 六经辨证（外感伤寒辨证，张仲景《伤寒论》）

六经辨证以太阳、阳明、少阳、太阴、少阴、厥阴六经概括外感病的演变阶段。三阳病（太阳、阳明、少阳）多实证、热证；三阴病（太阴、少阴、厥阴）多虚证、寒证。

## 一、六经病提纲与分证

### 1.1 太阳病

| 项目 | 内容 |
|------|------|
| 提纲 | "太阳之为病，脉浮，头项强痛而恶寒" |
| 主要表现 | 恶寒发热、头项强痛、脉浮。中风证：发热汗出恶风、脉浮缓（桂枝汤）；伤寒证：恶寒无汗、身痛、脉浮紧（麻黄汤） |
| 病机 | 风寒袭表，营卫失和（太阳主一身之表，为六经藩篱） |
| 治法/代表方 | 解肌祛风（桂枝汤）/发汗解表（麻黄汤） |

### 1.2 阳明病

| 项目 | 内容 |
|------|------|
| 提纲 | "阳明之为病，胃家实是也" |
| 主要表现 | 经证：**壮热、大汗、大渴、脉洪大**（白虎汤）；腑证：**日晡潮热、腹胀便秘、烦躁谵语、脉沉实**（承气汤类） |
| 病机 | 邪热入里，胃肠燥热（经证无形热盛；腑证燥屎内结） |
| 治法/代表方 | 清热生津（白虎汤）/峻下热结（大承气汤） |

### 1.3 少阳病

| 项目 | 内容 |
|------|------|
| 提纲 | "少阳之为病，口苦、咽干、目眩也" |
| 主要表现 | **往来寒热、胸胁苦满、默默不欲饮食、心烦喜呕**、口苦咽干目眩、脉弦 |
| 病机 | 邪犯少阳，胆火内郁，枢机不利（半表半里） |
| 治法/代表方 | 和解少阳（小柴胡汤） |

### 1.4 太阴病

| 项目 | 内容 |
|------|------|
| 提纲 | "太阴之为病，腹满而吐，食不下，自利益甚，时腹自痛" |
| 主要表现 | **腹满呕吐、食不下、腹泻（自利）、时腹自痛**、口不渴、畏寒、舌淡胖苔白 |
| 病机 | 脾阳虚弱，寒湿内盛 |
| 治法/代表方 | 温中散寒，健脾燥湿（理中汤、四逆辈） |

### 1.5 少阴病

| 项目 | 内容 |
|------|------|
| 提纲 | "少阴之为病，脉微细，但欲寐也" |
| 主要表现 | **脉微细、但欲寐（精神萎靡似睡非睡）**。寒化证：畏寒蜷卧、下利清谷、四肢厥冷、脉微欲绝（四逆汤）；热化证：心烦不得卧、口燥咽干、舌红少苔脉细数（黄连阿胶汤） |
| 病机 | 心肾阳衰（寒化）或阴虚火旺（热化），为疾病危重阶段 |
| 治法/代表方 | 回阳救逆（四逆汤）/滋阴清热（黄连阿胶汤） |

### 1.6 厥阴病

| 项目 | 内容 |
|------|------|
| 提纲 | "厥阴之为病，消渴，气上撞心，心中疼热，饥而不欲食，食则吐蛔，下之利不止" |
| 主要表现 | **上热下寒（寒热错杂）**：消渴、气上撞心、心中疼热、饥而不欲食、吐蛔；或厥热胜复（四肢厥冷与发热交替） |
| 病机 | 阴尽阳生、寒热错杂、肝胃气机逆乱 |
| 治法/代表方 | 寒温并用，清上温下（乌梅丸）；厥证用四逆散/当归四逆汤 |

## 二、传变、合病、并病

| 概念 | 定义 | 举例 |
|------|------|------|
| 循经传 | 按六经次序相传（太阳→阳明→少阳→三阴） | 太阳病不解内传阳明 |
| 越经传 | 隔一经或隔两经相传 | 太阳病不愈直传少阳 |
| 表里传 | 相表里之经相传 | 太阳传少阴 |
| 直中 | 外邪不经三阳直犯三阴 | 直中太阴（起病即腹冷痛下利） |
| **合病** | 两经或三经症状**同时出现**（起病即见） | 太阳阳明合病（发热恶寒兼下利或喘）、三阳合病 |
| **并病** | 一经病证未罢又出现另一经病证（**先后出现**） | 太阳并阳明 |

传经与否的判断依据：正气强弱、邪气盛衰、治疗当否。

## 三、六经辨证AI应用要点

1. 三阳病多实热、三阴病多虚寒——第一层先分阳证阴证。
2. 太阳病提纲三要素：脉浮、头项强痛、恶寒；中风（汗出脉缓）与伤寒（无汗脉紧）鉴别对应表虚表实。
3. 少阳病识别要点：寒热往来+口苦+胸胁苦满+脉弦（与八纲半表半里证同一内涵）。
4. 少阴病为危重阶段（脉微细、但欲寐），AI识别应建议就医。
5. 合病=同时出现，并病=先后出现，直中=起病即见三阴症状。
