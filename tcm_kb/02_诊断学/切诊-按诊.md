# 按诊：按肌肤、按手足、按脘腹

按诊是切诊的组成部分，与脉诊互补，通过触按肌肤、手足、脘腹获取寒热、润燥、痞满、压痛等体征。

## 一、按肌肤

| 触感 | 意义 |
|------|------|
| 肌肤灼热 | 实热证（阳证） |
| 肌肤寒冷 | 寒证；冷汗淋漓肢厥—亡阳（危） |
| 身灼热而肢厥（身热肢冷） | 真热假寒（热深厥深） |
| 初扪不热久扪灼热 | 身热不扬—湿热（湿温病） |
| 肌肤湿润 | 汗出或湿盛 |
| 肌肤干燥 | 津液已伤 |
| 肌肤甲错 | 血瘀、阴伤（干血劳） |
| 肌肤肿胀，按之凹陷不起 | 水肿（按之凹陷即起为气肿） |

## 二、按手足

| 表现 | 意义 |
|------|------|
| 手足俱冷 | 阳虚寒盛（寒证） |
| 手足俱热 | 阳盛热炽（热证） |
| 手足心热甚于手足背 | 阴虚内热（五心烦热） |
| 手背热甚 | 外感发热 |
| 小儿足冷 | 阳气不足或惊风先兆 |

## 三、按脘腹

| 部位/触感 | 意义 |
|-----------|------|
| 脘腹痞满（按之柔软、无痛） | 虚证痞证（脾胃气虚、气滞） |
| 脘腹硬满疼痛、拒按 | 实证（结胸、腑实、食积、瘀血） |
| 喜按 | 虚证（脾胃虚寒） |
| 拒按 | 实证 |
| 腹部包块固定不移、痛有定处 | 癥积（血瘀，属脏） |
| 包块聚散不定、痛无定处 | 瘕聚（气滞，属腑） |
| 腹中条索状物、按之游走 | 虫积（蛔虫） |
| 右少腹拒按（麦氏点） | 肠痈（**阑尾炎，建议急诊**） |
| 全腹硬满如板、压痛反跳痛 | 脏腑穿孔（**急腹症，立即急诊**） |

## 四、按诊要点（AI规则）

1. 喜按属虚、拒按属实——脘腹按压反应是虚实鉴别的重要体征。
2. 身灼热而肢厥为"热深厥深"（真热假寒），须结合舌脉重按辨别真假。
3. 初扪不热、久扪灼热为"身热不扬"，湿热（湿温病）特征。
4. 按之凹陷不起为水肿，凹陷即起为气肿。
5. 腹部剧痛拒按、板状腹、麦氏点压痛均为急腹症征象，AI应立即建议急诊。
