# 八纲辨证（含寒热真假、虚实真假鉴别）

八纲：**表、里、寒、热、虚、实、阴、阳**。前六纲为具体纲领，**阴阳为总纲**（表、热、实属阳；里、寒、虚属阴）。八纲辨证是各种辨证的总纲，指导辨证的第一层判断（病位深浅—表里；疾病性质—寒热；邪正盛衰—虚实；类别归属—阴阳）。

## 一、表证与里证（辨病位）

| 鉴别项 | 表证 | 里证 |
|--------|------|------|
| 定义 | 六淫邪气经皮毛、口鼻侵入，正气（卫气）抗邪于肤表浅层 | 病变部位在脏腑、气血、骨髓 |
| 寒热 | 恶寒发热**并见** | 但寒不热或但热不寒（寒热单见） |
| 主症 | 头身疼痛、鼻塞流涕、喷嚏、咽痒咳嗽 | 脏腑症状突出（咳喘、心悸、腹痛、呕泻、失眠等） |
| 舌象 | 舌苔薄，舌质变化不明显 | 舌质舌苔有明显变化 |
| 脉象 | 浮脉 | 沉脉或其他 |
| 病势 | 起病急、病位浅、病程短 | 病位深、病程较长 |
| 常见证 | 风寒束表证、风热犯表证 | 各类脏腑证、里寒里热证 |

表里鉴别关键：**发热恶寒同时并见为表证；但热不寒或但寒不热为里证。**

## 二、寒证与热证（辨病性）

| 鉴别项 | 寒证 | 热证 |
|--------|------|------|
| 寒热喜恶 | 恶寒喜暖、四肢不温 | 发热喜凉、面红目赤 |
| 口渴 | 口不渴或渴喜热饮、饮量少 | 口渴喜冷饮、饮量大 |
| 面色 | 面色㿠白 | 面红 |
| 神态 | 静而少言、蜷卧 | 躁动不安 |
| 二便 | 小便清长、大便溏薄 | 小便短赤、大便干结 |
| 痰涕 | 痰涕清稀 | 痰涕黄稠 |
| 舌象 | 舌淡苔白润 | 舌红苔黄干 |
| 脉象 | 迟或紧 | 数或洪滑 |

病机：寒证—感受寒邪或阳虚阴盛（"阴盛则寒，阳虚则寒"）；热证—感受热邪或阳盛阴虚（"阳盛则热，阴虚则热"）。

## 三、虚证与实证（辨邪正盛衰）

| 鉴别项 | 虚证 | 实证 |
|--------|------|------|
| 病程 | 久病、内伤、禀赋不足 | 新病、暴病、外感初中期 |
| 体质 | 形体虚弱、精神萎靡 | 形体壮实、声高气粗 |
| 声息 | 声低息微、少气懒言 | 声高气粗、甚则谵语 |
| 疼痛 | 隐痛、喜按、时作时止 | 剧痛、拒按、持续 |
| 腹诊 | 腹软喜按、按之舒适 | 腹硬满拒按 |
| 舌象 | 舌质娇嫩、少苔无苔 | 舌质苍老、苔厚腻 |
| 脉象 | 虚细无力 | 实洪有力 |
| 常见证 | 气、血、阴、阳虚及脏腑虚损 | 风寒暑湿燥火邪盛、痰饮、瘀血、食积、虫积 |

## 四、阴证与阳证（辨证总纲）

| 鉴别项 | 阴证 | 阳证 |
|--------|------|------|
| 总属 | 里证、寒证、虚证 | 表证、热证、实证 |
| 神态 | 精神萎靡、沉静少言、目光晦暗 | 兴奋躁动、声高多言、目光明亮 |
| 面色 | 苍白或晦暗 | 红赤 |
| 寒热 | 畏寒肢冷、不发热 | 身热恶热 |
| 二便 | 便溏溲清 | 便秘溲赤 |
| 舌脉 | 舌淡苔白、脉沉迟无力 | 舌红苔黄、脉浮数有力 |

## 五、八纲相兼证候

| 证型 | 表现 | 舌脉 |
|------|------|------|
| **表寒证** | 恶寒重发热轻、无汗、头身疼痛、鼻塞流清涕、口不渴 | 舌淡红苔薄白润，脉浮紧 |
| **表热证** | 发热重恶寒轻、有汗或少汗、咽喉肿痛、口微渴、涕黄 | 舌尖红苔薄白干，脉浮数 |
| **里寒证** | 畏寒肢冷、面白、腹痛喜温喜按、便溏尿清 | 舌淡苔白润，脉沉迟 |
| **里热证** | 壮热面赤、烦渴饮冷、便秘尿赤 | 舌红苔黄燥，脉洪数或滑数 |
| **里虚寒（虚寒证）** | 畏寒肢冷、神疲乏力、便溏尿清、自汗 | 舌淡胖，脉沉迟无力 |
| **里虚热（虚热证）** | 五心烦热、潮热盗汗、颧红咽干 | 舌红少苔，脉细数 |
| **里实寒（实寒证）** | 脘腹冷痛拒按、绞痛、便秘或寒积 | 苔白滑，脉沉紧或弦紧 |
| **里实热（实热证）** | 壮热、烦渴、腹胀便秘、口臭 | 舌红苔黄厚干，脉洪数有力 |

## 六、半表半里证（少阳证）

- 寒热往来（恶寒与发热交替）、胸胁苦满、心烦喜呕、默默不欲饮食、口苦、咽干、目眩。
- 脉弦。治疗小柴胡汤（和解少阳）。
- 识别要点：**寒热往来+口苦+胸胁苦满+脉弦**。

## 七、寒热真假与虚实真假（重证识别，AI安全关键）

### 7.1 真热假寒（阳盛格阴，"热深厥亦深"）

- 病机：阳热内盛郁闭于里，阳气不能外达四肢，格阴于外。
- **真象（本质，需重按细察）**：壮热、口渴喜冷饮、咽干口臭、小便短赤、大便燥结、舌红苔黄燥、脉滑数有力（沉取有力）。
- **假象（表象）**：四肢厥冷（胸腹灼热）、脉沉伏但重按有力。
- 治法：清泻里热（白虎汤、承气汤类）。

### 7.2 真寒假热（阴盛格阳、戴阳证）

- 病机：阴寒极盛于内，格拒衰极之虚阳浮越于上/外。
- **真象（本质）**：四肢厥逆、下利清谷、小便清长、精神萎靡、舌淡苔白滑润、脉微细欲绝。
- **假象（表象）**：身热但**欲盖衣被**、面红但**如妆浮游不定（颧红娇嫩）**、口渴但**喜热饮且饮量不多**、脉大但**按之无力**、烦躁但疲惫欲寐。
- 治法：回阳救逆、引火归元（通脉四逆汤、白通汤类）。

### 7.3 真实假虚（"大实有羸状"）

- 病机：实邪壅滞（热结、痰食、瘀血）阻滞气机，反见似虚之象。
- 真象：腹满硬痛拒按、便秘、舌苔厚浊、脉沉实有力。
- 假象：沉默少言、倦怠乏力、肢体不想动（但强询之下并非真虚）。

### 7.4 真虚假实（"至虚有盛候"）

- 病机：正气虚甚（脾虚等），运化无力，反见似实之象。
- 真象：神疲乏力、脉虚无力、舌淡嫩。
- 假象：腹部胀满，但**时胀时减、喜温喜按**；气喘但气怯声低；便意频频但努挣乏力。

### 7.5 真假鉴别五大要点（AI规则）

1. **舌象最可靠**：舌红苔黄燥为真热；舌淡苔白滑为真寒。
2. **脉象重按**：假象之脉浮大但重按无力；真热之脉沉取滑数有力。
3. **口渴饮水**：真热渴喜冷饮量多；假热渴喜热饮量少。
4. **二便**：便干尿赤为热；便溏尿清长为寒。
5. **整体与局部**：假象多现于四肢、肌肤、面色（表层）；本质多反映于舌脉沉取、二便、精神状态。

## 八、八纲与阴虚、阳虚及亡阴亡阳

| 证型 | 表现 | 舌脉 |
|------|------|------|
| 阴虚证 | 形体消瘦、五心烦热、潮热盗汗、颧红咽干、眩晕失眠 | 舌红少苔少津，脉细数 |
| 阳虚证 | 畏寒肢冷、神疲乏力、面白、自汗、便溏尿清、腰膝冷痛 | 舌淡胖苔白滑，脉沉迟无力 |
| 亡阳证 | 冷汗淋漓、面色苍白、四肢厥冷、呼吸微弱、脉微欲绝 | 舌淡白润（急危，回阳救逆——四逆汤类） |
| 亡阴证 | 汗热味咸而黏、面赤颧红、肌肤温热、烦躁不安、脉细数疾 | 舌红少津（急危，救阴敛阳——生脉散类） |
