# 望诊：望神、望色、望形态、望头面五官、望排出物、小儿指纹

望诊居四诊之首，包括望神、望色、望形态、望头面五官颈项皮肤、望舌（另见舌诊专篇）、望排出物、望小儿指纹。

## 一、望神

神是机体生命活动的外在表现，以目光、面色、表情、言语、反应为观察重点。

| 神的类型 | 表现 | 临床意义 |
|----------|------|----------|
| **得神（有神）** | 目光明亮灵活、面色荣润、表情自然、神志清楚、反应灵敏、呼吸平稳 | 正气未伤，病轻，预后良好 |
| **少神（神气不足）** | 倦怠乏力、精神不振、嗜睡懒言、目光呆滞、面色少华 | 正气不足，轻证或恢复期；多见于虚证、素体虚弱 |
| **失神（无神）** | 目光晦暗瞳神呆滞、面色晦暗暴露、精神萎靡、反应迟钝、甚则神昏谵语、循衣摸床、撮空理线 | 正气大伤，精气衰竭，病重，预后不良 |
| **假神（回光返照）** | 久病重病患者突然精神转佳、颧红如妆、突然能食、突然言语清亮 | 阴阳离决的先兆，濒危征象（**AI识别到此应建议立即就医**） |
| **神乱** | 焦虑恐惧、狂躁不安、淡漠痴呆、猝然昏仆（癫、狂、痫） | 精神情志类疾病 |

### 假神与重病好转的鉴别

好转是**逐渐的、全身性的**；假神是**突然的、局部的、与整体病情不符的**。

## 二、望色（望面色）

面色分为常色（红黄隐隐、明润含蓄）与病色。五色主病总表：

| 面色 | 主病 | 机制与表现 |
|------|------|-----------|
| **青色** | 寒证、痛证、瘀血、惊风 | 寒凝气滞、经脉瘀阻。青黑主寒痛；青灰晦暗主瘀血（心胸痛）；小儿眉间鼻柱唇周发青主惊风先兆 |
| **赤色** | 热证（实热/虚热） | 满面通红为实热（阳明热盛）；午后两颧潮红娇嫩为阴虚火旺（虚热） |
| **黄色** | 虚证、湿证 | 萎黄主脾胃气虚、气血不足；黄而鲜明如橘子色主湿热黄疸（阳黄）；黄而晦暗如烟熏主寒湿黄疸（阴黄） |
| **白色** | 虚证、寒证、失血 | 㿠白虚浮主阳虚；淡白无华主气血两虚；苍白主失血或阳气暴脱 |
| **黑色** | 肾虚、瘀血、水饮 | 面黑而暗淡主肾阳虚；黑而干焦主肾阴虚；黧黑（面色黧黑）主瘀血；眼眶黑主肾虚水饮或血瘀 |

## 三、望形态

| 项目 | 表现 | 意义 |
|------|------|------|
| 形体强壮 | 骨骼粗大、胸廓宽厚、肌肉充实、皮肤润泽 | 气血旺盛，抗病力强 |
| 形体虚弱 | 骨骼细小、胸廓狭窄、肌肉瘦削、皮肤枯槁 | 气血不足，抗病力弱 |
| 形胖 | 胖而能食为形气有余（多痰湿）；胖而食少为形盛气虚（多痰、多气虚、易中风） | "肥人多痰湿" |
| 形瘦 | 瘦而食多为中焦有火；瘦而食少为中气虚弱；大肉消瘦（恶病质）为精气衰竭 | "瘦人多火（阴虚）" |
| 动静姿态 | 喜动多阳证、热证、实证；喜静多阴证、寒证、虚证 | 阳主动，阴主静 |
| 特殊姿态 | 蹒跚步态（行走摇摆）主肾虚或中风后遗症；半身不遂主中风；四肢抽搐主肝风内动；循衣摸床、撮空理线为失神危象 | |

## 四、望头面五官颈项皮肤（提要）

| 部位 | 常见异常 | 意义 |
|------|----------|------|
| 头形/囟门 | 小儿囟门迟闭（解颅）主肾精不足；囟陷主津亏失水（虚）；囟填主实热（火毒上攻） | 肾、虚实证 |
| 头发 | 发黄稀疏易落主精血不足；突然片状脱发（斑秃）主血虚受风；青年白发主肾虚或血热 | 肾其华在发、发为血之余 |
| 目 | 目赤肿痛主实热（肝火上炎）；白睛黄染主黄疸；目眶凹陷主津液耗伤；瞳仁散大主肾精耗竭危候；眼睑淡白主血虚 | 肝开窍于目 |
| 口唇 | 唇色淡白主血虚；唇色深红主热；青紫主瘀血/寒凝；口角流涎主脾虚湿盛或中风 | 脾开窍于口其华在唇 |
| 齿龈 | 牙齿干燥主胃阴伤；龈肿出血主胃火；龈肉萎缩、齿根暴露主肾虚 | 齿为骨之余、龈为胃之络 |
| 鼻 | 鼻流清涕主风寒表证；流浊涕主风热或鼻渊（胆经郁热） | 肺开窍于鼻 |
| 咽喉 | 咽红肿痛主肺胃热盛；乳蛾（扁桃体肿大化脓）主肺胃热毒；咽部嫩红肿痛不显主阴虚火旺 | |
| 颈项 | 瘿瘤（颈前肿块）主肝郁气结痰凝；瘰疬（颈侧结核串珠）主肺肾阴虚痰火；颈脉怒张主心血瘀阻/水肿 | |
| 皮肤 | 斑（平铺于皮下、抚之不碍手、压之不褪色）多主热入营血或气不摄血；疹（高出皮面、抚之碍手、压之褪色）多主风热郁表；疮疡红肿热痛为阳证痈，漫肿无头皮色不变为阴证疽 | |

## 五、望排出物（提要）

排出物总规律：**清稀者多虚证、寒证；黄稠秽臭者多实证、热证。**

| 排出物 | 清稀（寒/虚） | 黄稠臭秽（热/实） |
|--------|----------------|---------------------|
| 痰 | 白痰清稀—寒痰/风寒犯肺；痰多色白易咯—痰湿阻肺 | 黄稠—热痰/痰热壅肺；痰中带血丝—燥热伤肺或阴虚火旺 |
| 涕 | 清涕—风寒 | 浊涕—风热；腥臭浊涕—鼻渊 |
| 呕吐物 | 清稀无臭—胃寒 | 黄稠酸臭—胃热；夹不消化食物—食滞 |
| 大便 | 溏薄—脾虚；清稀如水—寒湿泄泻；完谷不化—脾肾阳虚 | 黄褐臭秽—湿热泄泻；脓血便—湿热痢疾 |
| 小便 | 清长—寒证/肾阳虚 | 短赤—热证/湿热 |

## 六、望小儿指纹

适用于3岁以内小儿，观察食指掌侧桡侧缘浅表络脉（指纹），分为三关：

| 关位 | 位置 | 指纹到达的意义 |
|------|------|----------------|
| 风关 | 食指第一节（近掌侧） | 邪浅病轻 |
| 气关 | 食指第二节 | 邪入经络，病重 |
| 命关 | 食指第三节 | 邪入脏腑，病危 |
| 透关射甲 | 指纹直达指尖 | 病危重 |

### 指纹辨证纲领

**浮沉分表里，红紫辨寒热，淡滞定虚实，三关测轻重。**

- 纹色鲜红—外感表寒；紫红—里热；青色—疼痛、惊风；淡白—脾虚、虚证；紫黑—血络郁闭（病重）。
- 指纹浮露—病在表；沉滞—病在里。
