# 肝病辨证（11证，含肝风内动四型）

## 一、肝气郁结证

| 项目 | 内容 |
|------|------|
| 病因病机 | 情志抑郁、突然精神刺激 |
| 主要症状 | **胸胁或少腹胀闷窜痛、善太息（叹气）**、**情志抑郁易怒**、或咽部异物感（梅核气）、或颈部瘿瘤、或胁下痞块、妇女乳房胀痛、月经不调、痛经、经前加重 |
| 舌象 | 舌苔薄白 |
| 脉象 | 弦 |
| 治法 | 疏肝解郁，理气畅中 |
| 代表方 | 柴胡疏肝散、逍遥散（兼脾虚） |

## 二、肝火上炎证（肝火炽盛）

| 项目 | 内容 |
|------|------|
| 病因病机 | 肝郁化火、五志过极化火、火热之邪内侵 |
| 主要症状 | **头晕胀痛、面红目赤、口苦口干**、**急躁易怒**、耳鸣如潮（暴发）、失眠多梦、胁肋灼痛、便秘尿黄、或耳内流脓、或吐血衄血 |
| 舌象 | 舌红苔黄 |
| 脉象 | 弦数 |
| 治法 | 清肝泻火 |
| 代表方 | 龙胆泻肝汤 |

## 三、肝阳上亢证

| 项目 | 内容 |
|------|------|
| 病因病机 | 肝阴不足阴不制阳、肝肾阴虚阳亢于上（本虚标实：上盛下虚） |
| 主要症状 | **眩晕耳鸣、头目胀痛**、**头重脚轻、面红目赤**、烦躁易怒、失眠多梦、腰膝酸软、头重足轻、步履不稳 |
| 舌象 | 舌红少津 |
| 脉象 | 弦细数或弦有力 |
| 治法 | 平肝潜阳，滋阴降火 |
| 代表方 | 天麻钩藤饮、镇肝熄风汤 |

## 四、肝风内动四型

### 4.1 肝阳化风证

| 项目 | 内容 |
|------|------|
| 病因病机 | 肝阳亢极化风 |
| 主要症状 | **眩晕欲仆、头摇肢颤、语言謇涩**、手足麻木、步履不正、甚则突然昏倒、口眼㖞斜、半身不遂（中风） |
| 舌象 | 舌红 |
| 脉象 | 弦细数 |
| 治法 | 镇肝熄风，育阴潜阳 |
| 代表方 | 镇肝熄风汤、天麻钩藤饮 |

### 4.2 热极生风证

| 项目 | 内容 |
|------|------|
| 病因病机 | 高热燔灼肝经 |
| 主要症状 | **高热+四肢抽搐、颈项强直、两目上视、角弓反张**、牙关紧闭 |
| 舌象 | 舌红绛苔黄燥 |
| 脉象 | 弦数 |
| 治法 | 清热凉肝，息风止痉 |
| 代表方 | 羚角钩藤汤 |

### 4.3 阴虚动风证

| 项目 | 内容 |
|------|------|
| 病因病机 | 肝肾阴液枯竭、筋脉失养 |
| 主要症状 | 手足蠕动、眩晕耳鸣、五心烦热、潮热颧红、口燥咽干 |
| 舌象 | 舌红少津无苔 |
| 脉象 | 细数 |
| 治法 | 滋阴降火，柔肝息风 |
| 代表方 | 大定风珠、三甲复脉汤 |

### 4.4 血虚生风证

| 项目 | 内容 |
|------|------|
| 病因病机 | 肝血亏虚、筋脉失养 |
| 主要症状 | 手足震颤、肌肉瞤动、肢体麻木、关节拘急不利、爪甲不荣、面白无华 |
| 舌象 | 舌淡苔白 |
| 脉象 | 细弱 |
| 治法 | 养血熄风 |
| 代表方 | 四物汤加味、当归补血汤、阿胶鸡子黄汤 |

## 五、肝血虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 脾胃生化不足、失血过多、久病耗血 |
| 主要症状 | **眩晕耳鸣、面白无华**、**爪甲不荣脆裂、夜盲、视物模糊、眼睛干涩**（肝开窍于目）、肢体麻木、关节拘急、手足震颤、肌肉瞤动、妇女月经量少色淡甚则闭经 |
| 舌象 | 舌淡苔白 |
| 脉象 | 细弱 |
| 治法 | 补血养肝 |
| 代表方 | 四物汤、补肝汤、当归补血汤 |

## 六、寒滞肝脉证

| 项目 | 内容 |
|------|------|
| 病因病机 | 感受寒邪凝滞肝脉（肝经绕阴器抵少腹） |
| 主要症状 | **少腹牵引睾丸坠胀冷痛、或阴囊收缩引痛**、受寒则甚、得温则缓、或巅顶冷痛、干呕吐涎沫 |
| 舌象 | 舌淡苔白润 |
| 脉象 | 沉紧或弦紧 |
| 治法 | 暖肝散寒，行气止痛 |
| 代表方 | 暖肝煎、天台乌药散、吴茱萸汤（巅顶痛） |

## 七、肝胆湿热证

| 项目 | 内容 |
|------|------|
| 病因病机 | 感受湿热之邪、嗜酒肥甘酿生湿热、蕴结肝胆 |
| 主要症状 | **胁肋胀痛灼热、或胁下痞块**、**身目发黄（阳黄：黄而鲜明）**、口苦厌油、恶心呕吐、腹胀纳呆、发热、小便短赤、或阴部瘙痒湿疹、带下黄臭（湿热下注）、或寒热往来 |
| 舌象 | 舌红苔黄腻 |
| 脉象 | 弦数或弦滑 |
| 治法 | 清利肝胆湿热 |
| 代表方 | 龙胆泻肝汤、茵陈蒿汤（黄疸） |

## 八、胆郁痰扰证

| 项目 | 内容 |
|------|------|
| 病因病机 | 情志不遂、气郁生痰、痰热内扰胆腑 |
| 主要症状 | **惊悸失眠、烦躁不宁、胆怯易惊、时时惊醒**、胸胁闷胀、善太息、头晕目眩、口苦呕恶 |
| 舌象 | 舌苔黄腻或白腻 |
| 脉象 | 弦滑 |
| 治法 | 理气化痰，和胃利胆 |
| 代表方 | 温胆汤、黄连温胆汤 |

## 九、肝系辨证要点

- 胀闷窜痛+情志抑郁+脉弦 → 肝郁
- +红赤口苦急躁 → 肝火
- +腰膝酸软头重脚轻 → 肝阳上亢
- +抽搐震颤 → 肝风
- +目涩爪枯面白 → 肝血虚
- +胁痛黄疸苔黄腻 → 肝胆湿热

## 症状→证型快速检索（肝系）

| 核心症状组合（≥2项即可提示） | 高频证型 |
|------------------------------|----------|
| 胁胀窜痛+太息+情志抑郁 | 肝气郁结 |
| 头胀痛面红+急躁易怒+口苦 | 肝火上炎 |
| 眩晕+头重脚轻+腰膝酸软 | 肝阳上亢 |
| 抽搐+高热 | 热极生风 |
| 抽搐震颤+面色苍白 | 血虚生风 |
| 目干涩+夜盲+爪甲枯+肢麻 | 肝血虚 |
| 少腹牵引睾丸冷痛 | 寒滞肝脉 |
| 胁痛+黄疸（鲜明）+苔黄腻 | 肝胆湿热 |
| 惊悸失眠+胆怯易惊+口苦苔腻 | 胆郁痰扰 |
