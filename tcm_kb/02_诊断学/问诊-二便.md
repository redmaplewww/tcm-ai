# 问二便（十问第四问）

## 一、问大便

### 1.1 便次异常

| 项目 | 表现 | 临床意义 |
|------|------|----------|
| 便秘 | 实秘：热秘（面赤口臭苔黄—胃肠积热）、冷秘（畏寒肢冷、得温则缓—阴寒凝滞）、气秘（欲便不出、嗳气频作、胁胀—气滞） | 实秘三型 |
| | 虚秘：气虚（便不干硬但努挣乏力、汗出气短）、血虚（面色无华、头晕—血虚肠燥）、阴虚（大便干结如羊屎、口干咽燥—肠燥津亏）、阳虚（冷秘—畏寒、小便清长） | 虚秘四型 |
| 泄泻 | 湿热泄泻（暴泻黄褐臭秽、肛门灼热） | 湿热 |
| | 寒湿泄泻（清稀如水、腹痛肠鸣） | 寒湿 |
| | 伤食泄泻（嗳腐酸臭、泻后痛减） | 食滞 |
| | 脾虚泄泻（时溏时泻、食后即泻、迁延反复） | 脾虚 |
| | 五更泄泻（黎明即泻、腰膝酸冷） | **脾肾阳虚/命门火衰** |
| | 肝郁泄泻（腹痛即泻、泻后痛减、随情绪） | 肝郁乘脾（痛泻要方证） |

### 1.2 便质异常

| 表现 | 临床意义 |
|------|----------|
| 完谷不化（食物不化） | 脾肾阳虚（久病）、食滞（新病） |
| 溏结不调（时干时稀） | 肝郁脾虚；先干后溏—脾虚 |
| 脓血便 | 湿热痢疾 |
| 便血 | 远血（色黑如柏油）—胃脘出血（瘀阻胃络）；近血（色鲜红）—痔疮、直肠湿热 |

### 1.3 排便感异常

| 表现 | 临床意义 |
|------|----------|
| **里急后重**（腹痛窘迫、时时欲便、肛门重坠、便出不爽） | **湿热痢疾**（湿热壅滞大肠） |
| 排便不爽（滞涩不畅） | 湿热蕴结（大肠湿热）、肝郁乘脾、食滞 |
| 滑泻失禁（大便失禁） | 脾肾虚衰、肛门失约（久病虚极之危候） |
| 肛门气坠（肛门下坠感） | **中气下陷**（脾虚气陷，常伴脱肛、内脏下垂） |

## 二、问小便

| 项目 | 表现 | 临床意义 |
|------|------|----------|
| 尿量 | 尿量增多（清长） | 虚寒（肾阳虚、不能固摄水液）、消渴（肾消） |
| | 尿量减少 | 热证（汗吐下伤津）、水肿（肺脾肾功能失常，水湿内停）、癃闭 |
| 尿次 | 小便频数短赤急迫 | 膀胱湿热（淋证） |
| | 小便频数清长夜间尤甚 | 肾气不固（夜尿频多） |
| | 癃（点滴而出）闭（点滴不出） | 实证：湿热蕴结（尿黄赤）、瘀血结石阻塞尿道；虚证：肾阳虚衰（气化无力）、脾气虚（中气不足） |
| 排尿感 | 小便涩痛 | 湿热下注（淋证：热淋、石淋、血淋） |
| | 余沥不尽（尿后余沥） | **肾气不固**（老年肾亏）、前列腺病（肾虚血瘀） |
| | 小便失禁 | 肾气不固、脾虚气陷（膀胱失约） |
| | 遗尿（睡中不自主排尿） | 肾气不足、膀胱虚寒（小儿多见） |

## 三、二便问诊辨证要点（AI规则）

1. 大便先问次数与质地，再问颜色、气味与排便感。
2. 泄泻六型速记：湿热（暴泻臭秽肛灼）、寒湿（清稀如水）、伤食（嗳腐泻后痛减）、脾虚（迁延反复）、五更泻（脾肾阳虚）、肝郁（痛泻随情绪）。
3. 里急后重+脓血便=湿热痢疾；肛门坠胀+脱肛下垂=中气下陷。
4. 小便频数短赤急迫为膀胱湿热；清长夜多为肾气不固/肾阳虚。
5. 二便是寒热真假鉴别要点：便干尿赤为热；便溏尿清长为寒。

## 相关证型（syndromes.json）

大肠湿热证、大肠津亏证、膀胱湿热证、小肠实热证、中气下陷证、肾气不固证、脾肾阳虚证、脾气虚证、湿热蕴脾证。
