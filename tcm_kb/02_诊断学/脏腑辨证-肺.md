# 肺病辨证（8证）

## 一、肺气虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 久咳耗伤肺气、脾虚生化不足（土不生金） |
| 主要症状 | **咳喘无力、气短不足以息、动则益甚**、**咳痰清稀**、声低懒言、自汗畏风、易感冒、神疲体倦 |
| 舌象 | 舌淡苔白 |
| 脉象 | 弱 |
| 治法 | 补益肺气 |
| 代表方 | 补肺汤、玉屏风散（预防感冒） |

## 二、肺阴虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 燥热灼肺、久咳劳嗽耗伤肺阴 |
| 主要症状 | **干咳无痰或痰少而黏不易咯出**、甚则痰中带血、**口燥咽干、声音嘶哑**、形体消瘦、五心烦热、潮热盗汗、颧红 |
| 舌象 | 舌红少津少苔 |
| 脉象 | 细数 |
| 治法 | 滋阴润肺 |
| 代表方 | 百合固金汤、沙参麦冬汤 |

## 三、风寒犯肺证

| 项目 | 内容 |
|------|------|
| 病因病机 | 外感风寒袭肺 |
| 主要症状 | **咳嗽、咯痰稀白**、鼻塞流清涕、恶寒发热（微）、头身疼痛、无汗 |
| 舌象 | 舌淡红苔薄白 |
| 脉象 | 浮紧 |
| 治法 | 宣肺散寒，止咳化痰 |
| 代表方 | 三拗汤、杏苏散、小青龙汤（外寒内饮） |

## 四、风热犯肺证

| 项目 | 内容 |
|------|------|
| 病因病机 | 外感风热袭肺 |
| 主要症状 | **咳嗽、痰稠色黄**、鼻流浊涕、发热重恶寒轻、咽喉肿痛、口微渴、舌尖红 |
| 舌象 | 舌尖红苔薄黄 |
| 脉象 | 浮数 |
| 治法 | 疏风清热，宣肺止咳 |
| 代表方 | 桑菊饮、银翘散 |

## 五、燥邪犯肺证

| 项目 | 内容 |
|------|------|
| 病因病机 | 秋季燥邪犯肺（温燥/凉燥） |
| 主要症状 | **干咳无痰或痰少而黏、不易咯出**、唇舌咽鼻干燥（燥胜则干）、或痰中带血丝、微有发热恶寒（温燥兼烦热） |
| 舌象 | 舌红苔白而干（凉燥苔薄白干） |
| 脉象 | 浮数或浮紧（凉燥） |
| 治法 | 清肺润燥（温燥）/轻宣润肺（凉燥） |
| 代表方 | 桑杏汤（温燥）、杏苏散（凉燥）、清燥救肺汤（燥热重症） |

## 六、痰湿阻肺证（痰浊阻肺）

| 项目 | 内容 |
|------|------|
| 病因病机 | 脾虚生湿、聚湿成痰、上渍于肺（"脾为生痰之源，肺为贮痰之器"）、久咳伤肺 |
| 主要症状 | **咳嗽痰多、色白易咯、质黏稠**、胸闷、甚则气喘痰鸣 |
| 舌象 | 舌淡苔白腻 |
| 脉象 | 滑 |
| 治法 | 燥湿化痰，宣降肺气 |
| 代表方 | 二陈汤、三子养亲汤 |

## 七、痰热壅肺证

| 项目 | 内容 |
|------|------|
| 病因病机 | 邪热犯肺煎津成痰、痰热互结壅肺 |
| 主要症状 | **咳嗽气喘息粗、痰黄稠量多**、甚则鼻翼煽动、或咳吐脓血腥臭痰（肺痈）、发热口渴、胸闷胸痛、小便短赤 |
| 舌象 | 舌红苔黄腻 |
| 脉象 | 滑数 |
| 治法 | 清热化痰，宣肺平喘 |
| 代表方 | 清金化痰汤；肺痈用千金苇茎汤、桔梗汤 |

## 八、风水相搏证（风袭水停）

| 项目 | 内容 |
|------|------|
| 病因病机 | 风邪袭肺、宣降失常、水湿泛溢肌肤 |
| 主要症状 | **眼睑头面先肿、迅及全身**、小便短少、来势迅速、多伴恶寒发热咽痛（风水） |
| 舌象 | 舌苔薄白 |
| 脉象 | 浮 |
| 治法 | 疏风宣肺，利水消肿 |
| 代表方 | 越婢加术汤、麻黄连翘赤小豆汤 |

## 九、肺系辨证要点

**痰的性状是关键**：

| 痰象 | 辨证 |
|------|------|
| 清稀白痰 | 属寒/虚（风寒犯肺、肺气虚、痰湿阻肺） |
| 黄稠痰 | 属热（风热犯肺、痰热壅肺） |
| 干咳少痰 | 属燥/阴虚（燥邪犯肺、肺阴虚） |
| 痰多易咯 | 属痰湿（痰湿阻肺） |

## 症状→证型快速检索（肺系）

| 核心症状组合（≥2项即可提示） | 高频证型 |
|------------------------------|----------|
| 咳喘无力+痰清稀+易感冒 | 肺气虚 |
| 干咳+咽干+潮热盗汗 | 肺阴虚 |
| 咳嗽+清涕+恶寒 | 风寒犯肺 |
| 咳嗽+黄痰+咽痛发热 | 风热犯肺 |
| 干咳+口鼻干燥（秋季） | 燥邪犯肺 |
| 痰多色白易咯+胸闷 | 痰湿阻肺 |
| 咳喘痰黄稠+发热 | 痰热壅肺 |
| 眼睑头面先肿+小便短少+表证 | 风水相搏 |
