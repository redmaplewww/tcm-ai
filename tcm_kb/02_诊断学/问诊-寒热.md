# 问寒热（十问第一问）

寒热产生的总病机："**阳盛则热，阴盛则寒；阳虚则寒，阴虚则热。**"问寒热可判断病邪性质（寒/热）与阴阳盛衰。

## 一、寒热四种基本类型

| 类型 | 表现 | 临床意义 |
|------|------|----------|
| **恶寒发热** | 自觉怕冷，加衣被或近火取暖不能缓解，同时体温升高 | **外感表证**（外邪袭表，卫阳被遏）。恶寒重发热轻—表寒证（风寒束表）；发热重恶寒轻—表热证（风热犯表）；发热轻而恶风、有汗—太阳中风（表虚） |
| **但寒不热** | 只怕冷而不发热 | **里寒证**。新病畏寒—寒邪直中脏腑（实寒）；久病畏寒喜暖、加衣可缓—阳虚（虚寒） |
| **但热不寒** | 只发热不怕冷 | **里热证**（详见下表壮热、潮热、微热） |
| **寒热往来** | 恶寒与发热交替发作 | **半表半里证**（少阳病：往来寒热、胸胁苦满、口苦咽干目眩）；若寒战与高热交替、发有定时—疟疾 |

**表里鉴别关键**：发热恶寒同时并见为表证；但热不寒或但寒不热为里证。

## 二、但热不寒细分（AI重点）

| 类型 | 特征 | 临床意义 |
|------|------|----------|
| **壮热** | 高热（39℃以上）持续不退，不恶寒，反恶热，大汗，大渴 | 里实热证炽盛（阳明经证/温病气分证） |
| **潮热** | 发热如潮汐，按时而至或按时热甚 | 见下分三类 |
| ├ 阳明潮热（日晡潮热） | 热势较高，日晡（下午3-5时，申时）热甚，兼腹胀便秘 | **阳明腑实证**（燥屎内结） |
| ├ 湿温潮热 | 午后热甚，身热不扬（初扪不热、久扪灼手），兼头身困重、脘痞苔腻 | **湿温病**（湿热交蒸） |
| └ 阴虚潮热 | 午后或入夜低热，兼五心烦热、颧红盗汗 | **阴虚证**（阴虚内热） |
| **微热** | 发热不高（37-38℃）或仅自觉发热 | 多见于内伤病，按病机分下列四类 |
| ├ 阴虚发热 | 长期低热，兼颧红、五心烦热、盗汗 | 阴虚 |
| ├ 气虚发热 | 长期低热，兼疲乏、少气懒言、自汗，**劳累后加重** | 气虚（清阳不升、阴火内生），治宜甘温除热（补中益气汤） |
| ├ 血虚发热 | 低热兼面色萎黄、唇甲色淡、头晕心悸 | 血虚 |
| └ 气郁发热 | 情志不舒时发热或加重，兼胸闷、急躁易怒、叹气 | 气郁化火（肝郁） |

### 附：小儿夏季热

小儿夏季长期发热兼口渴多尿、无汗，秋凉自愈——气阴不足、暑气熏灼。

## 三、寒热问诊要点（AI规则）

1. 先问"怕冷吗？发热吗？"——确定寒热有无。
2. 再问"怕冷和发热同时有，还是只有一样？"——同时并见为表证，单见为里证，交替为半表半里。
3. 发热者追问热势（高热/低热）、时间规律（日晡、午后、入夜、午后身热不扬）。
4. 恶寒者追问"加衣被能否缓解"——能缓解为畏寒（阳虚里寒），不能缓解为恶寒（表证或实寒）。
5. 微热长期不退者，按阴虚/气虚/血虚/气郁四分法追问伴随症状。
