# 问睡眠与问情绪（AI问诊高频）

## 一、问睡眠

### 1.1 失眠（不寐）

| 睡眠异常 | 细分 | 辨证 |
|----------|------|------|
| **失眠（不寐）** | 不易入睡（入睡困难），兼心烦多梦、腰膝酸软、潮热盗汗 | **心肾不交**（阴虚火旺，水火不济） |
| | 睡后易醒、醒后难再入睡，兼心悸健忘、纳呆乏力、面色萎黄 | **心脾两虚**（气血不足，心神失养） |
| | 时时惊醒、睡中易惊悸、兼眩晕口苦、苔黄腻 | **胆郁痰扰**（痰热内扰，胆胃不和）；若平素胆怯易惊、气短倦怠—心胆气虚 |
| | 彻夜不眠、烦躁不安，兼面赤口渴、便秘溲赤、舌红苔黄 | **痰火扰心**/肝火扰神（实热） |
| | 失眠急躁易怒、胁胀太息 | 肝郁化火 |
| | 失眠多梦、五心烦热、盗汗颧红 | 心阴虚/阴虚火旺 |
| | 脘腹胀满不适而失眠（"胃不和则卧不安"） | 食滞胃脘 |

### 1.2 嗜睡

| 睡眠异常 | 细分 | 辨证 |
|----------|------|------|
| **嗜睡** | 困倦嗜睡、头脑昏沉、苔腻 | 痰湿困脾（湿浊内盛） |
| | 饭后困倦嗜睡、纳呆便溏 | 脾气虚弱（中气不足，清阳不升） |
| | 精神萎靡、昏睡倦怠、畏寒蜷卧 | 心肾阳衰（病重） |
| | 小儿睡中惊惕或嗜睡与烦躁交替 | 惊风先兆 |

**口诀**：不易入睡责之心肾（不交），睡后易醒责之心脾（两虚），时时惊醒责之胆（痰扰），彻夜不眠责之痰火（扰心）。

## 二、问情绪（七情状态评估）

七情（怒喜思忧悲恐惊）过极致病，直接伤及相应脏腑：**怒伤肝、喜伤心、思伤脾、忧伤肺、恐伤肾。**

| 情志表现 | 提示证候 |
|----------|----------|
| 烦躁易怒、面红目赤、失眠 | 肝火上炎 |
| 情志抑郁、善太息、胸胁胀闷、月经不调 | 肝气郁结 |
| 悲忧欲哭（脏躁） | 心肺阴虚（甘麦大枣汤证） |
| 思虑难解、纳呆便溏、失眠健忘 | 心脾两虚（思伤脾） |
| 惊惕不安、胆怯易惊 | 心胆气虚、胆郁痰扰 |
| 恐惧不安、腰膝酸软 | 肾气虚（恐伤肾） |
| 喜笑不休 | 心火亢盛（喜伤心） |
| 情志异常+经期相关 | 肝郁气滞（经前紧张） |

## 三、情志致病的病机特点

情志既是病因又是症状：长期情志不遂可致气机郁滞——**气郁→化火→伤阴→血瘀痰凝**。AI问诊应重点询问发病前情志诱因。

七情影响气机：怒则气上、喜则气缓、悲则气消、恐则气下、惊则气乱、思则气结。

## 四、睡眠情志问诊要点（AI规则）

1. 失眠四分法速记：入睡困难问心肾，易醒问心脾，惊醒问胆，彻夜不眠问痰火。
2. 失眠必问伴随：心烦？多梦？潮热盗汗？纳呆乏力？口苦苔腻？脘腹胀满？
3. 情志评估覆盖怒（易怒）、郁（抑郁太息）、思（思虑难解）、悲（悲忧欲哭）、恐（恐惧不安）、惊（胆怯易惊）、喜（喜笑不休）。
4. 情志异常与月经周期相关者提示肝郁气滞（经前紧张）。
5. 小儿睡中惊惕、嗜睡与烦躁交替为惊风先兆，应建议及时就医。

## 相关证型（syndromes.json）
