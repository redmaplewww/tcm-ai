# 脾病辨证（6证）

## 一、脾气虚证

| 项目 | 内容 |
|------|------|
| 病因病机 | 饮食不节、劳倦思虑过度、久病耗伤 |
| 主要症状 | **食少纳呆、腹胀、食后尤甚**、**便溏**、肢体倦怠、神疲乏力、少气懒言、面色萎黄或㿠白、或浮肿、形体消瘦 |
| 舌象 | 舌淡苔白 |
| 脉象 | 缓弱 |
| 治法 | 益气健脾 |
| 代表方 | 四君子汤、六君子汤、参苓白术散（兼湿） |

## 二、脾阳虚证（脾胃虚寒）

| 项目 | 内容 |
|------|------|
| 病因病机 | 脾气虚进一步发展、过食生冷、过用寒凉药 |
| 主要症状 | **腹痛绵绵、喜温喜按、畏寒肢冷**、食少腹胀、大便清稀、甚则完谷不化、或肢体浮肿、白带清稀量多 |
| 舌象 | 舌淡胖或有齿痕苔白滑 |
| 脉象 | 沉迟无力 |
| 治法 | 温中健脾 |
| 代表方 | 理中汤、附子理中汤、小建中汤 |

## 三、中气下陷证（脾虚气陷）

| 项目 | 内容 |
|------|------|
| 病因病机 | 脾气虚甚、升举无力、清阳不升 |
| 主要症状 | **脘腹重坠作胀、食后益甚、便意频数、肛门重坠**、或**久泄不止、脱肛、子宫下垂、胃肾下垂**、小便浑浊如米泔、气短乏力、头晕目眩 |
| 舌象 | 舌淡苔白 |
| 脉象 | 缓弱 |
| 治法 | 益气升阳，举陷固脱 |
| 代表方 | 补中益气汤 |

## 四、脾不统血证

| 项目 | 内容 |
|------|------|
| 病因病机 | 脾气虚弱、统血无权、血溢脉外 |
| 主要症状 | **便血、尿血、肌衄（皮下紫斑）、齿衄、鼻衄**、妇女月经过多、崩漏，兼食少便溏、神疲乏力、面色萎黄 |
| 舌象 | 舌淡苔白 |
| 脉象 | 细弱 |
| 治法 | 益气摄血，健脾统血 |
| 代表方 | 归脾汤、黄土汤（便血） |

## 五、寒湿困脾证

| 项目 | 内容 |
|------|------|
| 病因病机 | 冒雨涉水久居湿地、过食生冷、寒湿内侵 |
| 主要症状 | **脘腹痞闷胀痛、口腻纳呆**、**头身困重**、泛恶欲呕、口淡不渴、便溏、或肌肤面目发黄晦暗如烟熏（阴黄）、或浮肿尿少 |
| 舌象 | 舌淡胖苔白腻 |
| 脉象 | 濡缓 |
| 治法 | 温中散寒，健脾化湿 |
| 代表方 | 胃苓汤、平胃散、实脾饮（水肿） |

## 六、湿热蕴脾证（脾胃湿热）

| 项目 | 内容 |
|------|------|
| 病因病机 | 感受湿热、嗜食肥甘厚腻酒酪、湿郁化热 |
| 主要症状 | **脘腹痞闷、纳呆呕恶、口苦口黏腻**、便溏不爽（黏滞臭秽）、肢体困重、或身热起伏、汗出热不解、或身目鲜黄（阳黄）、皮肤发痒、尿黄 |
| 舌象 | 舌红苔黄腻 |
| 脉象 | 濡数 |
| 治法 | 清热利湿 |
| 代表方 | 甘露消毒丹、茵陈蒿汤（黄疸）、连朴饮 |

## 七、脾系辨证要点

- **食少、腹胀、便溏+乏力** 是脾气虚标配
- +冷痛畏寒 → 脾阳虚
- +下坠脱垂 → 中气下陷
- +出血 → 脾不统血
- +头身重、苔腻 → 湿（**白腻寒湿 / 黄腻湿热**）

## 症状→证型快速检索（脾系）

| 核心症状组合（≥2项即可提示） | 高频证型 |
|------------------------------|----------|
| 食少腹胀便溏+乏力萎黄 | 脾气虚 |
| 腹冷痛喜温喜按+畏寒 | 脾阳虚 |
| 脘腹坠胀+脱肛/内脏下垂+便意频 | 中气下陷 |
| 出血（皮下/便血/崩漏）+食少乏力 | 脾不统血 |
| 脘闷纳呆+头身困重+苔白腻 | 寒湿困脾 |
| 脘痞口苦黏腻+苔黄腻+便溏不爽 | 湿热蕴脾 |
