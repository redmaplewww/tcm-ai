# 中医诊断学总览与看病流程

## 一、中医诊断学的基本内容

中医诊断学是研究如何运用四诊方法收集病情资料、并进行辨证判断的学科，包含三大部分：

| 部分 | 内容 |
|------|------|
| 诊法（四诊） | 望诊、闻诊、问诊、切诊（合称"望闻问切"） |
| 辨证 | 八纲辨证、脏腑辨证、气血津液辨证、六经辨证、卫气营血辨证、三焦辨证、病因辨证、经络辨证 |
| 病案书写 | 记录四诊资料、辨证结论、治法方药 |

《难经》："望而知之谓之神，闻而知之谓之圣，问而知之谓之工，切而知之谓之巧。"

### 四诊简介表

| 诊法 | 手段 | 核心观察对象 |
|------|------|--------------|
| 望诊 | 医生视觉观察 | 全身神色形态、局部表现、舌象、小儿指纹、排出物 |
| 闻诊 | 听声音 + 嗅气味 | 语声、呼吸、咳嗽、心音；口气、汗气、痰涕、二便气味 |
| 问诊 | 询问患者/家属 | 寒热、汗、头身、二便、饮食、胸腹、耳目、睡眠、情志、经带、旧病等 |
| 切诊 | 脉诊 + 按诊 | 寸口脉象；肌肤、手足、脘腹的寒热、润燥、痞满、压痛 |

## 二、诊断三大原则

### 2.1 整体审察

- 人是有机整体：局部病变可反映整体状态，内在脏腑病变可表现于外（"有诸内必形诸外"）。
- 人与外界环境统一：四时气候、地域、社会心理因素均影响疾病。
- 诊断时既要察局部，又要审整体；既要察病，又要审人所处的环境与情志状态。

### 2.2 四诊合参

- 四诊从不同角度收集资料，各有价值、不可互相替代。
- 望、闻、问、切任一诊的资料都不完整，临床必须四诊并用、综合分析。
- 舌脉与症状矛盾时（如"舍脉从症""舍症从脉"），须结合全部资料判断真假。
- AI问诊系统虽以问诊为主，仍应尽量采集用户可自述/上传的舌象照片、声音、面色信息，模拟四诊合参。

### 2.3 病证结合

- "病"指疾病全过程的规律性概括；"证"指疾病某一阶段的病位、病性概括。
- 诊断既要辨病（如感冒、消渴、不寐），更要辨证（如风寒束表证、心脾两虚证），病证结合才能全面指导治疗。

## 三、"看病"的完整流程（问诊AI流程设计参照）

```
挂号分科（自述主诉初步分诊）
    ↓
四诊收集资料（望神色形态舌象 → 闻声音气味 → 问十问 → 切脉按诊）
    ↓
辨证分析（八纲定性位 → 脏腑/气血/六经/卫气营血定位 → 确立证型）
    ↓
确立治则治法（如"疏肝解郁""滋阴降火"，遵循虚则补之、实则泻之、寒者热之、热者寒之）
    ↓
处方/施治（选择代表方剂加减，或针灸、推拿等；注意配伍禁忌与体质）
    ↓
医嘱（饮食宜忌、起居调摄、情志调节、服药方法）
    ↓
随访复诊 → 调方（效不更方/效亦更方、不效则重新辨证、中病即止）
```

### 辨证论治三要素（AI推理链核心）

1. **辨证**：将四诊资料归纳为某证型（证据→证型的映射）。
2. **论治**：据证确立治法（证型→治法的映射）。
3. **处方**：据治法选方遣药（治法→方剂的映射）。
