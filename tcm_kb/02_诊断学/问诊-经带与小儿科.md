# 问经带（女科必问）、问小儿、问旧病病因家族史

## 一、问月经

| 项目 | 异常表现 | 临床意义 |
|------|----------|----------|
| 周期 | 月经先期（提前7天以上） | 血热（量多色深红质稠—实热；量少色红质稀—虚热）；气虚不固（量多色淡质稀—脾气虚、肾气虚） |
| | 月经后期（推迟7天以上） | 血寒（量少色暗有块—实寒；量少色淡—虚寒）、血虚（量少色淡）、气滞（量少色暗、经前乳胀胁痛） |
| | 先后不定期 | **肝郁气滞**（量时多时少、乳胀胁痛）或脾肾虚损 |
| | 闭经 | 血虚、肾精不足、气滞血瘀、痰湿阻滞、寒凝血瘀 |
| 经期 | 经期延长 | 血热（虚热）、气虚（脾不统血）、瘀血阻滞 |
| | 经期缩短 | 血虚、肾精不足 |
| 经量 | 月经过多 | 血热、气虚（脾不统血）、血瘀 |
| | 月经过少 | 血虚、肾虚、寒凝、痰湿、血瘀 |
| | 崩漏（非经期大出血/淋漓不尽） | 血热、肾虚（肾阴/阳虚）、脾虚（脾不统血）、血瘀 |
| 经色经质 | 色淡红质稀 | 血虚、气虚（虚寒） |
| | 色深红质稠 | 热证（实热、虚热） |
| | 色紫暗有块 | 血瘀、寒凝 |
| 痛经 | 经前或经期小腹胀痛 | 气滞（肝郁气滞，胀痛拒按） |
| | 经期小腹冷痛、得热则减 | 寒凝血瘀（实寒）；小腹隐痛喜温喜按—虚寒（气血虚弱） |
| | 经后小腹隐痛 | 气血两虚（不荣则痛） |

## 二、问带下

| 带下 | 表现 | 临床意义 |
|------|------|----------|
| 白带 | 量多色白质稀、无臭 | 脾虚湿困（脾气虚）、肾阳虚（下元虚寒） |
| 黄带 | 量多色黄质黏稠、臭秽 | **湿热下注**（肝经湿热、脾虚湿热） |
| 赤带 | 带下夹血、色红黏稠 | 肝郁化热（血热）、湿热伤络；带下五色杂见臭秽难闻需排除恶性病变（**AI应提示就医检查**） |

## 三、问小儿

| 问项 | 内容 | 意义 |
|------|------|------|
| 出生情况 | 是否足月、顺产难产、出生体重、有无窒息缺氧 | 先天禀赋（肾精）充足与否 |
| 喂养 | 母乳/人工喂养、辅食添加、食欲 | 脾胃后天之本发育状态 |
| 生长发育 | 抬头、坐、爬、走、说话、出牙、囟门闭合时间 | 判断肾精与发育 |
| 传染病接触史 | 麻疹、水痘、腮腺炎、百日咳等接触史及预防接种史 | 出疹性热病鉴别（"天花麻疹全占验"） |
| 儿科特有症状 | 发热伴惊风先兆（眉间青、嗜睡烦躁交替）、食积（夜卧不安、便臭） | 小儿"脏腑娇嫩、形气未充；脾常不足、肝常有余" |

## 四、问旧病、问病因、问家族史、问服药

| 问项 | 内容 | 辨证意义 |
|------|------|----------|
| 问旧病（既往史） | 既往患病、手术、外伤、输血、过敏史 | 体质判断、病机传变基础（如哮喘病史提示痰饮伏肺） |
| 问病因（发病诱因） | 外感六淫（受凉、淋雨）、内伤七情（生气、忧郁）、饮食不节（暴食、嗜酒）、劳倦房劳、外伤 | 直接指导**病因辨证**与去除诱因的医嘱 |
| 问家族史 | 家族遗传病、传染病（肺痨）、体质倾向 | 遗传体质（如过敏体质、消渴家族史） |
| 问服药（参机变） | 已服中西药、疗效反应、不良反应 | 避免重复/冲突用药；据疗效反推证型 |

## 五、AI问诊要点

1. 女性用户必问经期：周期、经期、量、色、质、痛经（"妇人尤必问经期，迟速闭崩皆可见"）。
2. 月经辨证速记：先期多热或气虚，后期多寒/血虚/气滞，先后不定期多肝郁，色淡质稀属虚寒，色深红质稠属热，紫暗有块属瘀。
3. 带下三色辨：白带虚寒（脾肾阳虚），黄带湿热下注，赤带肝郁血热；五色杂见臭秽提示就医排除恶性病变。
4. 小儿问诊重点：出生、喂养、生长发育、传染病接触史；警惕惊风先兆（眉间青、嗜睡烦躁交替）。
5. 旧病、病因、家族史、服药史是完整辨证与用药安全的必要信息。

## 相关证型（syndromes.json）

肝气郁结证（经前乳胀、先后不定期）、脾不统血证（崩漏、月经过多）、血瘀证（痛经色紫暗有块）、血寒证（月经后期、痛经得热减）、湿热下注（黄带）、肾阳虚证（白带清稀）。
