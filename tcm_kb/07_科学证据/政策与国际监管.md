# 政策与国际地位

> 本章收录WHO层面的传统医学政策（含ICD-11争议）、中国国内政策、主要国家/地区监管框架对比、ISO/TC 249国际标准化进展，以及主流医学界对中医药的态度光谱。

## 一、WHO层面

### 1.1 WHO传统医学战略

- **WHO传统医学战略2014-2023**（2013年第66届世界卫生大会发布），三大目标：
  1. 建设可信的证据基础；
  2. 加强监管保证质量与安全；
  3. 推动传统与补充医学（T&CM）整合入国家卫生体系并实现全民健康覆盖。
- WHO同时发布了针灸、阿育吠陀、推拿等疗法的**实践基准（benchmarks）**。
- **2025年WHO发布新一轮传统医学战略（2025-2034）**，延续并深化该框架。

### 1.2 ICD-11纳入传统医学章节

- 2019年5月第72届世界卫生大会审议通过ICD-11；其中**第26章"传统医学病证（Module 1）"**首次纳入传统医学章节（以中医药术语体系为主，另含暂缓纳入的部分），**2022年1月1日正式生效**，共约150余个病证编码（部分资料称含传统医学相关编码总数约400个）。
- **争议（必须呈现）**：批评者（含《Nature》《JAMA》社论与多国学者）认为此举赋予未经证实医学体系以科学正当性；WHO回应强调该章节**仅用于可选的双编码（optional dual coding）**，服务于统计、报销与药物安全监测，**不构成疗效认可**。
- **客观结论**：纳入ICD-11体现的是**统计学与国际政策层面的接纳，而非科学结论**。

## 二、中国国内政策

### 2.1 《中华人民共和国中医药法》

- 2016年12月25日全国人大常委会通过，**2017年7月1日施行**——中国首部中医药专门法律。
- 要点：
  - 法律层面确认中医药地位与"中西医并重"方针；
  - 中医诊所由审批改**备案制**；
  - 确有专长人员考核准入路径；
  - **经典名方目录免临床试验直接简化注册**；
  - 中药材质量监测与追溯体系；中药保护制度等。
- 该法的"简化审批"条款在学界亦有关于证据标准的讨论（平衡记录）。

### 2.2 战略规划与配套政策

- **《中医药发展战略规划纲要（2016-2030年）》**（国务院2016年2月印发）：首个国家层面中医药发展战略规划，目标到2020年中医药产业成为国民经济重要支柱之一，2030年实现中医药继承创新发展等。
- 配套政策：《"健康中国2030"规划纲要》（2016）、中医药"一带一路"发展规划、三药三方疫情应用（2020）后的循证评价项目等。

## 三、国际监管路径差异（对比表）

| 国家/地区 | 监管框架 | 要点 |
|---|---|---|
| **美国** | DSHEA（1994膳食补充剂健康与教育法） | 草药按**膳食补充剂（食品类别）**管理：上市前无需证明安全有效（新膳食成分NDI需备案），不得作疾病治疗声称；FDA仅在上市后监测与执法（个别中药以新药路径申报，如复方丹参滴丸IND） |
| **欧盟** | 2004/24/EC传统草药指令（THR） | 传统草药**简化注册**：需30年用药史（欧盟境内至少15年），无需临床试验数据但需药学质量与安全性档案；2011年过渡期结束全面生效；英国脱欧后延续THR体系 |
| **日本** | 药品（医疗用汉方）+OTC双轨 | 1975年《一般用汉方制剂承认基准》收录约210首处方；1976年起提取物制剂纳入医保，**医疗用汉方现约148种处方**（GMP标准化生产）；津村（Tsumura，1893年创立）占医疗用汉方处方约129/148，为绝对龙头；一般用OTC汉方另有约200余种 |
| **韩国** | 韩医（한의학）制度 | 韩医师执照体系独立，韩医院与西医院并立；草药按《药事法》药品管理，有韩医药进医保的制度安排 |
| **澳大利亚** | 2012年起对中医师实行国家注册 | 中药按列表管理（部分毒剧药限注册中医师使用）；同时是针灸批评学术力量较强（如Ernst学派合作者、NIH/NCCIH评估）的地区之一 |
| **中国** | 《中医药法》+药品管理法 | 中药按药品注册（含"古代经典名方"简化路径）、中药注射剂重点监控、中医医疗机构与人员独立序列 |

## 四、国际标准化：ISO/TC 249

- **ISO/TC 249（中医药技术委员会）**2009年成立（秘书处设在上海），截至2026年已发布**137项中医药国际标准**（另有多项在研），覆盖中药材质量与检测（重金属、农残检测方法）、针灸针等器具、煎药设备、术语、信息分类等领域。
- 代表性标准：一次性无菌针灸针（**ISO 17218**，首批发布之一）、人参种子种苗、中药重金属限量等。
- 意义定位：主要是**贸易与质量层面**的标准化，**不涉及疗效判定**。
- **国际针灸教育与实践**：WHO曾发布针灸培训指南（1999）；多国（澳、加部分省、欧洲部分国家）对针灸师实行注册/执照制度；国际针灸研究界（如SPRINT、STRICTA报告规范）在推动试验报告标准化。

## 五、主流医学界态度光谱（客观描述）

- **否定端**：认为中医药理论与多数疗法未通过科学检验，应整体退出医疗体系（少数声音，如部分科普作家、个别医学期刊社论）。
- **怀疑但个案开放**：默认否定，但对有严格RCT支持的个案（青蒿素、针刺镇痛机制）予以承认（主流欧美医学期刊与多数临床指南的现实立场）。
- **整合医学（Integrative Medicine）派**：主张在保证证据与安全的前提下将部分传统疗法纳入常规医疗（哈佛、约翰霍普金斯等设有整合医学中心；美国NCCIH每年资助替代医学研究）。
- **制度性支持**：中国官方与产业界、日韩传统医药产业（制度化程度最高的国家实践）。
- **知识库建议**：回答用户"中医是否科学"类问题时，呈现该光谱并强调**分层命题框架**（详见"争议与多方观点"文件）。
