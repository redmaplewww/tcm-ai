# 验证成果：砷剂治疗APL与其他代表性现代研究成果

> 本章收录除青蒿素外获得国际关注或进入现代临床验证的中药研究成果，含砷剂治疗急性早幼粒细胞白血病（APL）、小檗碱代谢调节研究及多种单成分/复方制剂的国际化历程。正反证据并列呈现。

## 一、三氧化二砷（砒霜）治疗急性早幼粒细胞白血病（APL）

### 1.1 发现史

- **民间起点**：1971年前后，哈尔滨医科大学**张亭栋**等人在调查民间验方（据称源自一位民间医生，后经韩太云等制成"癌灵注射液"，含三氧化二砷及微量氯化亚汞）的基础上开展研究。
- **1973年**：张亭栋与韩太云发表第一篇论文，报告"癌灵"治疗慢性粒细胞白血病等病例。
- **1979年**：张亭栋等在《黑龙江医药》发表论文，明确"癌灵1号"的有效成分为**As₂O₃（三氧化二砷）**，并指出其对急性早幼粒细胞白血病（APL，FAB分型M3型）效果最好。此后张亭栋团队持续发表APL治疗案例（1980年代），但初期国际影响有限。
- **走向世界**：1996年起，上海血液学研究所**陈竺、陈赛娟**等与哈尔滨同行合作，在《Blood》等国际期刊发表砷剂治疗APL的分子机制与临床研究，引起国际血液学界重视。

### 1.2 全反式维甲酸（ATRA）与联合方案

- **王振义**院士（上海瑞金医院）1980年代首创**全反式维甲酸（ATRA）诱导分化治疗APL**，单用ATRA显著提高完全缓解率但复发率高。
- 陈竺、王振义等提出**ATRA + As₂O₃联合方案**。临床实践证明两药联合可使约**90%的APL患者达到5年无病生存**，且未见明显长期毒性（中国教育和科研计算机网2011年报道；相关临床研究发表于2000年代）。
- APL由此从"最凶险的白血病"（传统化疗下死亡率高，常死于DIC）变为**第一种基本可治愈的急性髓系白血病**。

### 1.3 作用机制

- **PML-RARα融合蛋白**：APL的分子标志是t(15;17)染色体易位产生的PML-RARα融合蛋白，其阻断早幼粒细胞分化。
- ATRA与砷剂分别结合该融合蛋白的RARα部分与PML部分，**协同诱导PML-RARα降解**，解除分化阻滞；砷剂同时促进凋亡。
- 该研究被视为**靶向治疗与"以毒攻毒"传统理念结合**的经典范例。陈竺团队的相关机制研究发表于《Science》《Blood》等期刊（如2000年前后Zhu Chen等关于砷剂直接靶向PML结构域的工作）。

### 1.4 国际认可

- 美国FDA于**2000年批准**注射用三氧化二砷（商品名Trisenox，Cephalon公司）用于复发/难治性APL；欧洲药监机构随后亦予批准。
- **2020年未来科学大奖"生命科学奖"**授予张亭栋与王振义，表彰其发现三氧化二砷和全反式维甲酸对APL的治疗作用。
- **争议提示**：砷剂本身是传统"毒药"，其成功同样被双方引用——支持者视为"以毒攻毒"科学化的证明；批评者指出其成功恰恰来自放弃复方、提纯单成分并用现代方法验证。

## 二、小檗碱（黄连素，Berberine）：代谢调节研究

小檗碱是黄连、黄柏等中药的主要生物碱，长期以来在中国作为非处方止泻药使用。近二十余年其代谢调节作用成为研究热点。

### 2.1 降糖作用

- 临床研究（如2004年起中国多家中心发表的RCT与荟萃分析）显示小檗碱可降低2型糖尿病患者空腹血糖与糖化血红蛋白，疗效与二甲双胍**大致相当**（王琰等《药学学报》2018年综述指出两者效果相当、机制有多个类似之处——均可激活AMPK、均为mTOR抑制剂）。
- 《Nature》子刊与国内期刊均发表过相关机制研究（如Jia Wei等关于小檗碱调脂的早期研究，2003-2004年前后）。

### 2.2 "低生物利用度悖论"与肠道菌机制

小檗碱口服吸收差（生物利用度低）但疗效确切，提示其主要作用部位在**肠腔与肠道菌群**层面：

- 抑制肠道DPP-Ⅳ、促进肠道L细胞分泌**GLP-1**（北大医院等团队研究，2016年前后发表于国际期刊）。
- 调节肠道菌群结构（赵立平课题组等的工作）。
- 2025年中科院上海药物所王琰/蒋建东团队报道**"小檗碱—肠道拟杆菌—琥珀酸—肝脏AMPD2"轴**改善高尿酸血症，提出"药物—菌群—代谢物—宿主靶点"完整通路。

### 2.3 其他研究

调脂（通过稳定LDL受体mRNA）、改善胰岛素抵抗、抗炎等。

### 2.4 客观提示

- 小檗碱在国际主流内分泌指南中**尚未被推荐为一线降糖药**。
- 多数支持性RCT在中国进行，存在结局偏倚与发表偏倚的可能（详见"循证方法学问题"文件）。
- 其证据等级仍低于二甲双胍。

## 三、其他有代表性的现代研究成果

### 3.1 复方丹参滴丸的美国FDA临床试验历程

- 复方丹参滴丸（丹参、三七、冰片）由天士力集团研发，用于冠心病稳定型心绞痛。
- **历程**：1997年获FDA IND批准（中国复方药首例）；2010年前后完成II期；**2016年底宣布完成FDA III期随机、双盲、国际多中心临床试验**（T89-07-03试验等），是首个完成FDA III期的复方中药。
- **公司方公布的数据**：可显著增加稳定性心绞痛患者最大运动耐受时间（TED）；高、低剂量组相对安慰剂显著降低每双周心绞痛发作次数约27%，减少硝酸甘油用量约25%。
- **争议（必须并列呈现）**：科学网等平台有评论指出，其主要终点（第四周TED）的统计结果仅为"临界显著"（p值接近0.05边界），**"完成III期"不等于"FDA批准上市"**；截至2025年，该药仍未获FDA新药批准，天士力仍在推进后续试验（另一项新适应症III期在进行中）。该案例常被双方引用：支持者视其为中药走向国际严格标准的重要尝试；批评者认为其宣传口径超过实际数据。

### 3.2 康莱特注射液

- 康莱特注射液（薏苡仁油）由**李大鹏**院士团队研发，用于肿瘤辅助治疗。
- **历程**：1999年向FDA递交IND；2001年通过IND审查；2004年在美国完成I期临床试验；2015年完成治疗胰腺癌的II期临床试验并获FDA同意进入III期（据浙江中医药大学等资料）；2003年获俄罗斯批准作为肺癌治疗药物上市。
- **争议**：有财经媒体报道（新浪财经2015年等）指出，康莱特"单独用药"的试验已被终止，进入III期的是其与吉西他滨等化疗药的**联合用药**方案；网络评论（如知乎专栏）质疑其临床试验设计与宣传表述。截至2025年未见其通过FDA III期获批的公开信息。

### 3.3 穿心莲内酯（Andrographolide）

- 穿心莲内酯是穿心莲的主要二萜类成分，具有抗炎、抗病毒（上呼吸道感染）、抗肿瘤等活性的大量实验研究。
- 代表性机制研究：韩晶岩团队（北京大学，发表于《Engineering》2024年的综述）通过活体荧光微循环观察系统证实穿心莲内酯可减少白细胞与肺细静脉黏附、抑制炎症介质释放，从而改善LPS诱导的肺微循环障碍；另有研究提示其衍生物（如14-去氧穿心莲内酯）可通过抑制GSK-3β等通路发挥抗炎与器官保护作用。
- **客观提示**：相关证据多来自细胞与动物实验，高质量人体RCT数量有限。

### 3.4 雷公藤甲素（Triptolide）与自身免疫病

- 雷公藤多苷/雷公藤甲素用于类风湿关节炎、IgA肾病、肾病综合征等自身免疫/炎症性疾病，国内有较多临床使用与研究。
- **机制研究**：抑制多种炎性细胞因子、调节T淋巴细胞与抗原提呈细胞、减少致病性IgA产生（PMC 2022年综述）；厦门大学团队发现其可通过tRXRα调控p38与PI3K/AKT通路。
- **治疗窗窄**：毒性较大（生殖毒性、肝毒性、骨髓抑制等，详见"安全性事件"文件）、水溶性差，大量研究致力于结构改造与前药开发。国际上曾开展多项临床试验但尚未成为主流免疫抑制剂。

### 3.5 天麻素、丹参酮、黄芪多糖等

- **天麻素**：天麻的主要成分。《天麻素制剂临床应用中国专家共识（2021）》指出其可改善缺血性卒中患者血液流变学、保护神经细胞、改善血管内皮功能；用于后循环缺血、眩晕等的证据以国内研究为主。
- **丹参酮**（丹参酮IIA等）：抗炎、抗氧化、改善微循环的实验研究广泛；丹参及其活性成分的药理研究文献量巨大，但国际多中心RCT证据有限。
- **黄芪多糖**：免疫调节（巨噬细胞活化、T细胞应答等）实验研究较多，常用于辅助免疫研究的材料，临床证据级别总体不高。
- 丹参滴丸中的丹参、三七成分研究亦带动了丹酚酸、三七皂苷类成分的药理学发展。

## 四、小结（成功案例的共性）

上述案例的共同路径是：**从传统经验材料出发 → 提取/分离单一或确定的活性成分 → 现代药理学与临床验证 → 国际化**。

- **支持者**认为这证明传统医学是"宝库"。
- **批评者**认为这证明的是现代药物化学方法有效，而中医理论本身在这些发现中并非必要条件。
- 两种观点均应在知识库中并存。
